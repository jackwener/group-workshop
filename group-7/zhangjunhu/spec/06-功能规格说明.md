# 4. Main 内容区（三态渲染）

> 对齐 `05` US-002（问答提交）、US-003（历史记录）。描述三种条件下显示什么。

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | "请创建或选择一个会话开始" |
| **B 新会话** | 有会话 && 无记录 | 显示"请输入研报相关问题，如：某公司的最新评级和目标价" |
| **C 对话历史** | 有记录 | 显示问答记录卡片（流式渲染），包含问题、回答、来源标签、时间戳 |

### 4.1 流式回复行为（对齐 US-002 AC）

> 问答回复采用 **SSE（Server-Sent Events）** 流式返回，前端逐字/逐段渲染。

| 阶段 | 前端行为 |
|------|----------|
| 发送请求 | 按钮变为"发送中…"（disabled），在对话区追加"回答中…"占位卡片 |
| 流式接收 | 逐步替换占位卡片内容，实时显示文字（打字机效果） |
| 接收完成 | 完整渲染回答卡片，显示来源标签 + 耗时 |
| 接收出错 | 显示错误提示，移除占位卡片 |

### 4.2 记录卡片中的来源标签逻辑

> 根据 `answer_source` 和 `llm_used` 组合显示不同标签。

| `answer_source` | `llm_used` | 显示文本 | 样式 |
|-----------------|------------|----------|------|
| `copaw` | `true` | CoPaw | 绿色/蓝色标签 |
| `bailian` | `true` | 百炼 | 绿色/蓝色标签 |
| `demo` | `false` | 离线演示 | 灰色标签 |

### 4.3 股票标记与触发查询（对齐 US-004）

> 研报回答中涉及的股票产品显式标记为可点击链接。

| 交互 | 行为 |
|------|------|
| 股票标记识别 | 回答文本中匹配到股票名称/代码时，渲染为高亮可点击标签 |
| 点击股票标签 | 打开新的会话窗口，自动发起该股票信息查询 |
| 重复点击同一股票 | 复用已打开的股票查询窗口，不重复创建 |

### 4.4 历史记录搜索（对齐 US-003）

> 支持基于关键词搜索定位历史问答记录。

| 元素 | 行为 |
|------|------|
| 搜索输入框 | 位于 Main 区顶部或 Sidebar 内，placeholder "搜索历史记录…" |
| 搜索触发 | 输入关键词后实时过滤/请求匹配结果 |
| 搜索结果 | 高亮匹配关键词，点击跳转到对应会话和记录位置 |

### 4.5 相似性提问检测（对齐 US-003 AC-003-02）

> 用户在新会话中提问时，若存在历史相似提问，优先展示历史记录。

| 阶段 | 行为 |
|------|------|
| 提问前检测 | 发送 query 前，检查历史中是否有相似问题 |
| 发现相似 | 展示相似历史记录卡片 + 确认按钮"查看历史 / 发起新提问" |
| 用户选择"查看历史" | 跳转到对应历史会话和记录 |
| 用户选择"发起新提问" | 正常发送 ask 请求 |

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 错误提示："请输入问题" |
| `INVALID_QUERY` | 400 | 错误提示："问题过长" |
| `SESSION_NOT_FOUND` | 400 | 错误提示："会话不存在，请重新选择" |
