## 1. 背景与问题

> 描述用户遇到的问题，至少写 2~3 条痛点。参考：信息获取、历史记录、可追溯性、系统可用性。

| 痛点 | 来源 |
|------|------|
| 信息分散：研报、新闻、数据分布在多个系统，无统一问答入口 | 用户访谈 |
| 效率低：研报的内容多、内容长，且需要关联不同数据源的数据，格式可能存在不统一 | 邮件沟通 |
| 易用性：没有界面，在不同数据之间切换比较复杂、耗时，且数据对比不直观 | 邮件沟通 |
| 研报获取难：研报来源多样（PDF、HTML、网页链接），缺乏统一导入与管理入口 | 用户访谈 |
| 对比效率低：同一股票不同券商研报的关键指标对比需手动整理，无法快速导出 | 用户访谈 |
| 缺乏溯源：问答结果中的关键信息缺少与原文/产品详情的关联，无法快速验证 | 邮件沟通 |
| 舆情盲区：投研决策缺少实时舆情信息辅助，对市场情绪变化感知滞后 | 用户访谈 |

## 2. 提案概要

> 用 3~5 句话概括要做什么。参考格式："在 XXX 应用内交付 YYY 能力"。要素：会话式问答 · 能力降级 · 可追溯

在OA系统首页增加研报问答入口，支持多种格式研报导入（PDF、HTML、网页链接）及AI自动拉取线上研报；支持问答式提取研报关键数据并横向对比指标（可导出Excel）；对问答结果中涉及的股票进行高亮标记并支持点击跳转产品详情；同时集成舆情监控，在回答中展示相关股票的最新舆情信息。

## 3. 范围边界

> 明确"做什么"和"不做什么"，避免范围蔓延。各写 3~4 条。

| 做（范围内） | 不做（范围外） |
|-------------|---------------|
| 会话管理：创建、列表、删除 | 多租户/行级数据权限 |
| 研报导入：支持 PDF、HTML 文件上传及网页链接解析 | 研报原文编辑与润色 |
| AI 拉取线上研报：按需从配置源自动获取最新研报 | 全网无差别爬虫抓取 |
| 研报关键信息提取，支持指标横向对比并导出 Excel | 复杂金融建模与量化分析 |
| 信息溯源：问答结果中关键信息高亮，支持跳转原文及产品详情 | 第三方交易系统集成 |
| 股票信息查询与产品详情跳转 | 实时行情推送与交易下单 |
| 舆情监控：回答中展示相关股票最新舆情 | 全量舆情数据存储与分析平台 |

## 4. 成功标准（可度量）

> 写出 3~4 条可量化的验收标准。句式：用户在 X 分钟内完成 XXX 全链路 / 未配置外部模型时返回 XXX

| 标准 | 度量方式 |
|------|----------|
| 主路径可走通 | 用户在 3 分钟内完成"新建会话 → 提问 → 查看历史"全链路 |
| 研报导入可用 | 用户上传 PDF/HTML 或粘贴网页链接后，系统在 30 秒内完成解析并可用于问答 |
| 关键内容完整 | 关键内容完整，不丢，关键指标不缺失，横向对比标准一致 |
| 对比可导出 | 横向对比结果可一键导出为 Excel，格式规范、数据完整 |
| 信息可溯源 | 问答结果中股票名称高亮可点击，跳转至产品详情页 |
| 股票信息一键查询 | 用户点击可查看股票信息及最新舆情 |
| 舆情信息及时 | 舆情数据时效性 ≤ 24 小时 |

## 5. 风险（简表）

> 列出 2~3 个主要风险。常见方向：外部依赖不可用、数据存储并发、模块间契约延期。

 风险 | 影响 | 应对 |
|------|------|------|
| 外部 LLM 不可用 | 问答功能降级 | 三级降级：CoPaw → 百炼 → Demo 模式兜底 |
| 不同券商研报格式差异大 | 解析困难 | 版本基于部分研报格式，遇到新格式持续更新 |
| 研报文件过大或格式异常 | 上传/解析失败 | 限制单文件 50MB，异常文件给出明确错误提示 |
| 舆情数据源不稳定 | 舆情信息缺失 | 多源聚合 + 缓存兜底，无舆情时显示"暂无最新舆情" |
