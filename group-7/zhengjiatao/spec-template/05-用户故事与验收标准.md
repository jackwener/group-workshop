> **本文只做一件事**：按用户能理解的子场景拆成多条 **User Story**，并为每条写清 **REQ-ID**、**验收标准（AC）**。

## 字段说明 — 每条 UserStory 必须包含以下字段

| 字段 | 填写说明 | 数据来源 ← | 流向下游 → |
|------|----------|------------|-----------|
| **需求编号** | 唯一编号，如 REQ-M1QA-001 | ← `02` 采集编号 | → `14` 追踪矩阵首列 |
| **故事** | 作为【角色】，我希望【行为】，以便【价值】 | ← `04` PRD 场景拆解 | → `06` FSD 功能点 |
| **优先级** | P0（必须）/ P1（应该）/ P2（可选） | ← `03` §4 成功标准 | → `12` 里程碑排期 |
| **来源** | 对应 03/04 哪一条需求 | ← `03` 范围 · `04` 场景 | |
| **前置条件** | 触发该故事的前提状态 | ← `04` 用户流程 | → `13` 测试前置 |
| **功能对齐** | 对应功能规格 + 非功能约束 | | → `06` FSD · `07` NFR |
| **设计对齐** | 对应架构、接口、数据、安全 | | → `08` 架构 · `09` API · `10` Data · `11` 安全 |
| **验证对齐** | 对应测试用例 + 追踪矩阵行 | | → `13` TC · `14` 追踪矩阵行 |
| **验收标准** | AC，每条可独立验证 | ← 故事 + `07` NFR | → `13` 测试用例依据 |

## US-001（P0）会话管理

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-001 |
| **故事** | 作为投研分析师，我希望创建、查看、删除会话，以便让AI助手完成不同的任务，互不干扰 |
| **优先级** | P0 |
| **来源** | ← 03 §3 提案、会话管理 / 04 §3 SC-01 |
| **前置条件** | 用户已登录系统 |
| **功能对齐** | → 06 §3 Sidebar · 07 §5.1 |
| **设计对齐** | → 08 §2 · 09 /sessions API · 10 Session表 · 11 §2 |
| **验证对齐** | → 13 TC-001 · 14 第1行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-001-01 | 支持创建会话，新创建的会话是独立，不带其他历史消息的 |
| AC-001-02 | 支持删除会话，删除后的会话不可查看 |
| AC-001-03 | 查看会话，可查看本人会话，无法查看其他人的会话 |

## US-002（P0）问答提交

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-002 |
| **故事** | 作为投研分析师，我希望可以向AI提交问题，以便让AI知道用户需求，并触发AI运行，流式响应用户问题 |
| **优先级** | P0 |
| **来源** | ← 03 §3 提案、AI问答 / 04 §3 SC-02 |
| **前置条件** | 已创建会话 |
| **功能对齐** | → 06 §5 输入区 · 07 §1.2 |
| **设计对齐** | → 08 §4 · 09 /ask API · 10 QARecord表 · 11 §5 |
| **验证对齐** | → 13 TC-002 · 14 第2行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-002-01 | 可向AI发送消息，自动保存到会话历史 |
| AC-002-02 | AI可流式响应消息内容，内容及自动保存到会话历史 |
| AC-002-03 | 支持1-500字符的问题输入，超长或为空时返回明确错误 |

## US-003（P0）历史记录

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-003 |
| **故事** | 作为投研分析师，我希望可以查看历史的会话记录，以便回顾历史内容，方便核对验证 |
| **优先级** | P0 |
| **来源** | ← 03 §3 提案 / 04 §3 SC-03 |
| **前置条件** | 已有问答记录 |
| **功能对齐** | → 06 §4 Main内容区 · 07 §5.1 |
| **设计对齐** | → 08 §2 · 09 /sessions/{id}/records API · 10 QARecord表 · 11 §2 |
| **验证对齐** | → 13 TC-003 · 14 第3行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-003-01 | 可以查看历史会话记录，不同会话数据互相隔离，数据倒序排列 |
| AC-003-02 | 历史会话支持复制：点击复制按钮可将单条问答的query和answer复制到剪贴板 |
| AC-003-03 | 历史会话支持导出：可将整个会话的问答记录导出为JSON/TXT格式文件 |
| AC-003-04 | 首次问答自动命名：当query_count从0变为1时，会话标题自动更新为query前20字 |
