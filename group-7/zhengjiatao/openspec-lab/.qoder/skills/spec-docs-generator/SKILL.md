# Spec文档全周期生成Skill

## 核心原则

### 1. 单一真源原则
- **09 API** 是接口契约真源，其他文档只引用不另起别名
- **10 数据模型** 是存储契约真源，字段定义以此为准
- **05 UserStory** 是需求验收真源，AC必须可独立验证

### 2. 四轮螺旋写作顺序

```
轮次1（起点）: 03立项提案 → 04PRD
                ↓
轮次2（锚定）: 05UserStory ↔ 09API（互相校准）
                ↓
轮次3（展开）: 08架构 → 10数据模型 → 06FSD → 07NFR → 11安全
                ↓
轮次4（收口）: 12实施计划 → 13测试策略 → 14追溯矩阵
```

### 3. 上游引用原则
所有填写内容必须标注来源：`来源 = 文档编号 [章节/条款]`

### 4. 跨文档一致性原则
- 字段名拼写：以09为准（大小写敏感）
- 枚举值：以08降级链为准
- 约束数值：以07为底线
- 安全状态：以07第4章为准
