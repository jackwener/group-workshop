## 1. 概念模型

```
Session（会话）1 ── * QARecord（问答记录）
   │                      │
   │  session_id (PK)     │  record_id (PK)
   │  title               │  session_id (FK → Session)
   │  query_count         │  query / answer / llm_used
   │  created_at          │  model / response_time_ms
   │  updated_at          │  answer_source / timestamp
   │                      │
Report（研报）1 ── * Analysis（分析结果）
   │
   │  report_id (PK)
   │  title / filename
   │  file_size / status
   │  uploaded_at / analyzed_at
```

> **核心关系**：一个 Session 可包含零到多条 QARecord。外键通过 `session_id` 字段逻辑引用。

## 2. 存储引擎

| 项 | 说明 |
|----|------|
| 引擎 | JSON 文件（`json` 标准库） |
| 编码 | UTF-8，缩进 2 空格 |
| 读写模式 | RMW（全量读入 → 修改 → 全量写回） |
| 并发安全 | 无锁，不支持并发写入 |
| 文件布局 | `{DATA_DIR}/sessions.json` + `qa_records.json` + `reports.json` |

## 3. 实体定义 — Session

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `session_id` | `string` (UUID) | 是 | **PK** | 会话唯一标识 |
| `title` | `string` | 是 | ≤100 字符 | 默认"新会话"，首次问答自动重命名 |
| `created_at` | `string` (ISO-8601) | 是 | UTC+Z | 创建时间 |
| `updated_at` | `string` (ISO-8601) | 是 | UTC+Z | 最后更新时间 |
| `query_count` | `integer` | 是 | ≥ 0 | 累计问答次数 |

## 4. 实体定义 — QARecord

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `record_id` | `string` | 是 | **PK**，`rec_{ts}` | 基于时间戳生成 |
| `session_id` | `string` (UUID) | 是 | **FK** → Session | 所属会话 |
| `query` | `string` | 是 | 1–500 字符 | 用户提问原文 |
| `answer` | `string` | 是 | — | LLM/Demo 返回的答案 |
| `llm_used` | `boolean` | 是 | — | 是否使用真实 LLM |
| `model` | `string`\|`null` | 是 | — | 模型标识 |
| `response_time_ms` | `integer` | 是 | SLO < 5000 | 响应耗时（ms） |
| `answer_source` | `string` | 是 | 枚举 | `copaw`\|`bailian`\|`demo` |
| `timestamp` | `string` (ISO-8601) | 是 | UTC+Z | 回答时间 |

## 5. Storage 方法清单

> 列出 Storage 类的全部公开方法。每个方法标注关联的 TC 编号（来自 `13`）。

### 5.1 会话管理

| 方法 | 签名 | 行为 | 关联 TC |
|------|------|------|---------|
| `create_session` | `(session_id: str, title: str) → dict` | 创建新会话，title默认"新会话"，query_count初始为0 | TC-001-01 |
| `get_sessions` | `(page: int, page_size: int) → list` | 返回分页会话列表，按updated_at倒序 | TC-001-02 |
| `delete_session` | `(session_id: str) → bool` | 删除会话 + **级联删除**该会话下所有问答记录 | TC-001-03 |
| `update_session` | `(session_id: str, title: str) → dict` | 更新会话标题，同时更新updated_at字段 | TC-001-04 |
| `get_session_by_id` | `(session_id: str) → dict\|None` | 根据ID获取单个会话详情，不存在返回None | TC-001-05 |

### 5.2 问答记录管理

| 方法 | 签名 | 行为 | 关联 TC |
|------|------|------|---------|
| `add_record` | `(session_id: str, query: str, answer: str, llm_used: bool, model: str\|None, response_time_ms: int, answer_source: str) → dict` | 写入问答记录，同时更新对应会话的query_count和updated_at | TC-002-01 |
| `get_records_by_session` | `(session_id: str, page: int, page_size: int) → list` | 按session_id分页查询问答记录，按timestamp倒序 | TC-002-02 |
| `delete_records_by_session` | `(session_id: str) → int` | 删除指定会话下的所有问答记录，返回删除数量 | TC-002-03 |
| `get_record_by_id` | `(record_id: str) → dict\|None` | 根据ID获取单条记录详情 | TC-002-04 |

### 5.3 研报管理

| 方法 | 签名 | 行为 | 关联 TC |
|------|------|------|---------|
| `create_report` | `(report_id: str, title: str, filename: str, file_size: int) → dict` | 创建研报记录，status初始为pending | TC-003-01 |
| `get_reports` | `(page: int, page_size: int, status: str\|None) → list` | 分页查询研报列表，支持按status筛选，按uploaded_at倒序 | TC-003-02 |
| `get_report_by_id` | `(report_id: str) → dict\|None` | 根据ID获取单个研报详情 | TC-003-03 |
| `delete_report` | `(report_id: str) → bool` | 删除研报记录及关联文件 | TC-003-04 |
| `update_report_status` | `(report_id: str, status: str, analysis: dict\|None) → dict` | 更新研报分析状态和结果，analyzed_at在status=analyzed时自动更新 | TC-003-05 |
| `get_analysis_by_report` | `(report_id: str) → dict\|None` | 获取研报分析结果 | TC-003-06 |

## 6. 关键业务逻辑

**示例 — 首次问答自动命名**：

```python
if session["query_count"] == 1:
    session["title"] = query[:20] + ("..." if len(query) > 20 else "")
```

> **规则**：仅首次问答（query_count 从 0 → 1）触发，后续不再自动更名。

| 逻辑 | 触发条件 | 行为 |
|------|----------|------|
| 首次问答自动命名 | `query_count` 从 0 → 1 | 标题 = query 前 20 字 + `...` |
| 级联删除 | 删除 Session | 同步删除所有关联 QARecord |
| 会话更新同步 | 新增问答记录 | 同步更新对应 Session 的 `query_count` + 1 和 `updated_at` 为当前时间 |
| 研报分析缓存 | 研报上传完成 | 后台异步触发分析任务，分析结果写入 `analysis` 字段，status 更新为 analyzed |
| 分析结果复用 | 查询已分析研报 | 直接返回缓存的 analysis 数据，不再重复调用 LLM |
| 文件清理 | 删除研报 | 同步删除上传的原始文件及分析缓存 |
| 分页默认值 | 查询未传分页参数 | page 默认 1，page_size 默认 20，最大 100 |
| 时间戳生成 | 创建新记录 | created_at / uploaded_at / timestamp 统一使用 ISO-8601 UTC 格式 |

## 7. API 响应 DTO 概要

> 详细端点定义见 `09`。此处列出关键 DTO 与存储字段的映射关系。

| API 端点 | 核心 DTO 字段 | 额外注入 |
|----------|---------------|----------|
| `POST /ask` | answer, llm_used, model, response_time_ms, answer_source | `traceId` |
| `POST /sessions` | session_id, title, created_at, query_count | `traceId` |
| `GET /sessions` | sessions[] (含 session_id, title, created_at, updated_at, query_count) | `traceId`, total, page, page_size |
| `GET /sessions/{id}/records` | records[] (含 record_id, query, answer, timestamp, llm_used, model, answer_source) | `traceId`, session_id, total |
| `POST /reports` | report_id, title, filename, file_size, uploaded_at, status | `traceId` |
| `GET /reports` | reports[] (含 report_id, title, filename, status, uploaded_at, analyzed_at) | `traceId`, total |
| `POST /reports/{id}/analyze` | report_id, status, analysis (含 company, key_metrics, summary) | `traceId` |
| `GET /health` | status, timestamp, services, metrics | `traceId` |
| `POST /export` | export_id, status, download_url, expires_at | `traceId` |

## 8. 数据一致性约束

| 约束 | 说明 | 校验时机 |
|------|------|----------|
| 会话ID唯一性 | session_id 全局唯一，重复创建报错 | create_session |
| 外键完整性 | QARecord.session_id 必须对应存在的 Session | add_record |
| 状态流转 | Report.status: pending → analyzing → analyzed/failed | update_report_status |
| 字段类型一致性 | 所有字段类型与 09 API 响应字段类型保持一致 | 序列化/反序列化 |

## 9. Storage 类接口定义

```python
class Storage:
    # 会话管理
    def create_session(self, session_id: str, title: str) -> dict: ...
    def get_sessions(self, page: int, page_size: int) -> list: ...
    def get_session_by_id(self, session_id: str) -> dict | None: ...
    def update_session(self, session_id: str, title: str) -> dict: ...
    def delete_session(self, session_id: str) -> bool: ...
    
    # 问答记录管理
    def add_record(self, session_id: str, query: str, answer: str,
                   llm_used: bool, model: str | None,
                   response_time_ms: int, answer_source: str) -> dict: ...
    def get_records_by_session(self, session_id: str, 
                               page: int, page_size: int) -> list: ...
    def get_record_by_id(self, record_id: str) -> dict | None: ...
    def delete_records_by_session(self, session_id: str) -> int: ...
    
    # 研报管理
    def create_report(self, report_id: str, title: str, 
                      filename: str, file_size: int) -> dict: ...
    def get_reports(self, page: int, page_size: int, 
                    status: str | None) -> list: ...
    def get_report_by_id(self, report_id: str) -> dict | None: ...
    def delete_report(self, report_id: str) -> bool: ...
    def update_report_status(self, report_id: str, status: str,
                             analysis: dict | None) -> dict: ...
    def get_analysis_by_report(self, report_id: str) -> dict | None: ...
```
