## 1. 页面总体布局

> 画出你的应用的页面结构（ASCII / 手绘均可）。SPA 通常分：Header + Sidebar + Main + Input Area。

**示例 — 布局结构**：

```
┌──────────────────────────────────────────┐
│  header: 标题 + [能力状态芯片]             │
├────────────┬─────────────────────────────┤
│  sidebar   │  main-content（三态渲染）     │
│  历史会话   │  A) 空状态                    │
│  [+新建]   │  B) 常见问题网格              │
│  session1  │  C) 对话历史列表              │
│  session2  │                              │
│            │  input-area: textarea + 发送  │
└────────────┴─────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────┐
│  header: 投研问答助手 + [能力状态芯片] + [研报管理入口]        │
├────────────┬────────────────────────────────────────────────┤
│  sidebar   │  main-content（三态渲染）                        │
│  历史会话   │  A) 空状态：提示创建会话                          │
│  [+新建]   │  B) 常见问题：研报查询快捷入口网格                   │
│  session1  │  C) 对话历史：问答记录列表（用户/助手气泡）          │
│  session2  │                                                 │
│  ...       │  input-area: textarea + 发送按钮 + 清空按钮        │
└────────────┴────────────────────────────────────────────────┘
```

**布局说明**：
- **Header**: 左侧显示应用标题"投研问答助手"，中间显示能力状态芯片（CoPaw/百炼/离线演示），右侧提供研报管理入口按钮
- **Sidebar**: 左侧边栏展示历史会话列表，支持新建、删除、选中会话操作
- **Main Content**: 主内容区根据状态显示空状态/常见问题/对话历史
- **Input Area**: 底部固定输入区域，包含问题输入框、发送按钮、清空按钮

## 3. Sidebar 会话管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表 + 默认选中第一个 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 插入列表头部 + 自动选中 |
| 删除会话 | 点击 × | `DELETE /sessions/<id>` | 确认弹窗 → 从列表移除 |
| 选中会话 | 点击会话项 | `GET /sessions/<id>/records` | 高亮选中项 + 加载该会话问答记录到主内容区 |

### 3.1 选中会话交互详情

| 步骤 | 行为 | 说明 |
|------|------|------|
| 1. 触发 | 用户点击 Sidebar 中的会话项 | 会话项显示 hover 效果 |
| 2. 状态变更 | `currentSession` 更新为选中会话 | 原选中项取消高亮，新选中项添加激活样式 |
| 3. API 调用 | `GET /api/v1/agent/sessions/{id}/records` | 携带 `page=1&page_size=20` 查询参数 |
| 4. 加载中 | Main 内容区显示 loading 状态 | 显示骨架屏或 loading 动画 |
| 5. 成功响应 | 渲染问答记录列表 | 按时间倒序排列，最新记录在底部 |
| 6. 空记录处理 | 若 `records` 为空数组 | 自动切换至 **B 常见问题** 状态 |
| 7. 错误处理 | 若返回 404 `SESSION_NOT_FOUND` | 提示"会话不存在或已删除"，刷新会话列表 |

## 4. Main 内容区（三态渲染）

> 对齐 `05` US-002（问答提交）、US-003（历史记录）。描述三种条件下显示什么。

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | "请创建或选择一个会话开始" |
| **B 常见问题** | 有会话 && 无记录 | 显示常见问题快捷入口网格 |
| **C 对话历史** | 有记录 | 问答记录列表，每条记录以卡片形式展示 |

### 4.1 B 状态 — 常见问题网格详情

**触发条件**：`currentSession !== null && records.length === 0`

**布局结构**：
```
┌─────────────────────────────────────────────┐
│  欢迎使用投研问答助手                        │
│  选择一个常见问题快速开始，或在下方输入您的问题 │
├─────────────────────────────────────────────┤
│  ┌────────────────┐  ┌────────────────┐     │
│  │  📊 分析财报    │  │  📈 对比研报    │     │
│  │ 宁德时代最新   │  │ 比亚迪vs特斯拉 │     │
│  └────────────────┘  └────────────────┘     │
│  ┌────────────────┐  ┌────────────────┐     │
│  │  🔍 提取指标    │  │  📋 总结趋势    │     │
│  │ 关键指标提取   │  │ 行业趋势总结   │     │
│  └────────────────┘  └────────────────┘     │
└─────────────────────────────────────────────┘
```

**快捷问题配置**：

| 卡片标题 | 副标题 | 点击后填充的 query |
|----------|--------|-------------------|
| 📊 分析财报 | 宁德时代最新 | "分析宁德时代最新财报的关键指标" |
| 📈 对比研报 | 比亚迪vs特斯拉 | "对比比亚迪和特斯拉的最新研报" |
| 🔍 提取指标 | 关键指标提取 | "提取研报中的营收、净利润、毛利率等关键指标" |
| 📋 总结趋势 | 行业趋势总结 | "总结新能源行业的最新发展趋势" |

**交互行为**：

| 动作 | 行为 |
|------|------|
| 点击卡片 | 自动将对应 query 填充到输入框，并自动触发发送 |
| hover 效果 | 卡片阴影加深，边框高亮 |

### 4.2 C 状态 — 对话历史卡片元素详情

**触发条件**：`records.length > 0`

**布局结构**：
```
┌─────────────────────────────────────────────┐
│  [滚动容器，自动滚动到底部]                    │
│                                             │
│  ┌─────────────────────────────────────┐   │
│  │ 用户问题气泡（右侧对齐，蓝色背景）    │   │
│  │ 分析宁德时代2024年财报...            │   │
│  └─────────────────────────────────────┘   │
│  ┌─────────────────────────────────────┐   │
│  │ 助手回答气泡（左侧对齐，白色背景）    │   │
│  │ 宁德时代2024年营收同比增长15%...     │   │
│  │ [来源标签] [时间] [模型] [耗时]      │   │
│  └─────────────────────────────────────┘   │
│                                             │
│  ... 更多记录 ...                           │
│                                             │
└─────────────────────────────────────────────┘
```

**单条记录卡片元素**：

| 元素 | 位置 | 样式 | 数据来源 |
|------|------|------|----------|
| 用户问题气泡 | 右侧 | 蓝色背景(#e6f7ff)，圆角8px，最大宽度80% | `record.query` |
| 助手回答气泡 | 左侧 | 白色背景，灰色边框，圆角8px，最大宽度80% | `record.answer` |
| 回答来源标签 | 回答气泡底部左侧 | 根据来源显示不同颜色标签 | `record.answer_source` |
| 时间戳 | 回答气泡底部 | 灰色小字，格式 HH:mm | `record.timestamp` |
| 模型标识 | 回答气泡底部 | 灰色小字，如"gpt-4" | `record.model` |
| 响应耗时 | 回答气泡底部 | 灰色小字，如"1.2s" | `record.response_time_ms` |

**记录卡片交互**：

| 动作 | 行为 |
|------|------|
| 新消息到达 | 自动滚动到底部，显示最新记录 |
| 加载历史 | 向上滚动加载更多，显示 loading 指示器 |
| 点击复制 | 点击回答气泡可复制内容到剪贴板 |

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 错误提示："请输入问题" |
| `INVALID_QUERY` | 400 | 错误提示："问题过长" |
| `EMPTY_SESSION_ID` | 400 | 错误提示："会话ID不能为空" |
| `INVALID_SESSION_ID` | 400 | 错误提示："会话ID格式错误" |
| `SESSION_NOT_FOUND` | 404 | 错误提示："会话不存在或已删除" |
| `EMPTY_FILE` | 400 | 错误提示："请选择要上传的文件" |
| `INVALID_FILE_TYPE` | 400 | 错误提示："仅支持 PDF、DOC、DOCX 格式" |
| `REPORT_NOT_FOUND` | 404 | 错误提示："研报不存在或已删除" |
| `LLM_UNAVAILABLE` | 500 | 错误提示："AI服务暂不可用，已切换至演示模式" |
| `ANALYSIS_FAILED` | 500 | 错误提示："研报分析失败，请稍后重试" |
| `INVALID_TITLE` | 400 | 错误提示："会话标题不能超过100字符" |
| `INVALID_REPORT_COUNT` | 400 | 错误提示："请至少选择2份研报进行对比" |
| `INVALID_FORMAT` | 400 | 错误提示："仅支持 PDF 或 Excel 格式导出" |

## 7. 状态管理
