## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| **问答端点 P95 延迟** | < **5000ms** | `response_time_ms` 字段 | `03` 4, `04` R-03 |
| 会话管理端点延迟 | < 500ms | 服务端计时 | `05` AC-001 |
| 研报分析处理延迟 | < 60000ms | 服务端计时 | `03` 5, `04` R-06, `05` AC-003-03 |
| 研报对比查询延迟 | < 3000ms | 服务端计时 | `04` 6, `05` AC-002-03 |
| 页面初始加载延迟 | < 2000ms | 浏览器 Performance API | `04` 6 |
| 历史记录查询延迟 | < 1000ms | 服务端计时 | `05` AC-005-01 |
| 文件上传延迟 | < 30000ms | 服务端计时 | `04` R-06, `05` AC-003-01 |
| 健康检查端点延迟 | < 200ms | 服务端计时 | `05` AC-004-01 |
| 研报导出处理延迟 | < 10000ms | 服务端计时 | `05` AC-006 |

### 1.2 降级策略

**示例 — 三级降级链**：

```
CoPawAgent.ask(query, session_id)
  ├─[1] CoPaw 桥接 → answer_source='copaw', llm_used=True
  ├─[2] 百炼 DashScope → answer_source='bailian', llm_used=True
  └─[3] 离线演示兜底 → answer_source='demo', llm_used=False
```

| 约束 | 说明 |
|------|------|
| 三级降级**不可跳级** | 必须按 CoPaw → 百炼 → Demo 顺序尝试 |
| 降级**静默执行** | 不抛异常，通过 `answer_source` 标识 |
| Demo 模式**始终可用** | 无外部依赖，纯字符串拼接 |

## 2. 可用性需求

### 2.1 可用性指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | **99%**（教学环境） | 单实例 Flask，不设 HA |
| MTTR | < 5 分钟 | 重启 Flask 进程即可恢复 |

### 2.2 故障模式与应对

| 故障模式 | 触发条件 | 应对策略 | 来源 |
|----------|----------|----------|------|
| 外部LLM不可用 | CoPaw/百炼服务超时或返回5xx | 自动切换至下一级降级 | `03` 5, `04` R-04 |
| 研报分析超时 | 单份研报分析超过60秒 | 返回异步处理中状态，后台继续处理 | `03` 5, `04` R-07 |
| 文件上传失败 | 网络中断或格式校验失败 | 保留临时文件，支持断点续传 | `04` R-06 |
| JSON存储损坏 | 文件系统异常或断电 | 自动备份恢复，丢失最近1分钟数据 | `05` AC-001 |
| 会话数据丢失 | 进程异常退出 | 从JSON文件恢复，已持久化数据不丢失 | `04` R-05 |

### 2.3 恢复方式

| 恢复方式 | 操作步骤 | 说明 | 来源 |
|----------|----------|------|------|
| 进程重启 | 手动重启Flask服务 | 会话数据从JSON自动恢复 | - |
| 降级切换 | 系统自动触发 | 自动降级至Demo模式，无需人工干预 | `04` R-04 |
| 缓存重建 | 系统自动触发 | 研报分析缓存失效后重新分析 | `04` R-07 |

## 3. 可观测性需求

### 3.1 链路追踪

| 项 | 规格 |
|----|------|
| traceId 格式 | `tr_{uuid.hex}`（32 位十六进制） |
| 注入位置 | 所有成功响应顶层 + 错误响应 `error.traceId` |
| 上游透传 | 优先复用请求头 `X-Trace-Id`，缺省时本地生成 |

### 3.2 错误码体系

| HTTP | `error.code` | 触发条件 | 来源 |
|------|--------------|----------|------|
| 400 | `EMPTY_QUERY` | query 为空/空白/null | `04` R-02 |
| 400 | `INVALID_QUERY` | query >500 字符 或 缺少 session_id | `04` R-01, `04` R-02 |
| 400 | `INVALID_FILE_FORMAT` | 上传文件非 pdf/doc/docx 格式 | `04` R-06 |
| 400 | `FILE_TOO_LARGE` | 上传文件超过 50MB | `04` R-06 |
| 400 | `MISSING_SESSION_ID` | 请求未携带 session_id | `04` R-01 |
| 404 | `SESSION_NOT_FOUND` | 指定的会话不存在 | `05` AC-001-02 |
| 404 | `REPORT_NOT_FOUND` | 指定的研报不存在 | `05` AC-002-01 |
| 408 | `ANALYSIS_TIMEOUT` | 研报分析处理超时 | `03` 5, `04` R-07 |
| 429 | `RATE_LIMIT_EXCEEDED` | 请求频率超过限制 | `04` 6 |
| 500 | `UPSTREAM_ERROR` | Agent 编排内部异常 | `04` R-04 |
| 500 | `LLM_UNAVAILABLE` | 所有LLM服务均不可用 | `03` 5, `04` R-04 |
| 503 | `SERVICE_UNAVAILABLE` | 系统维护或过载 | `05` AC-004 |

## 4. 安全需求

| 项 | 当前实现 | 说明 |
|----|----------|------|
| API 认证 | 无（开放访问） | Workshop 教学版 |
| CORS | 全开放 | 生产需白名单 |
| 速率限制 | 无 | 教学场景不限速 |

### 4.1 敏感数据保护

| 数据类型 | 保护方式 |
|----------|----------|
| LLM API Key | 环境变量存储（`.env`），禁止硬编码 |
| 用户查询 | 仅存储在本地 JSON，不传输到第三方（LLM 除外） |
| 研报文件内容 | 本地存储，不上传至外部云服务 | `04` R-06, `05` AC-003-01 |
| 会话历史记录 | 按session_id隔离存储，禁止跨会话访问 | `04` R-05, `05` AC-001-03 |
| 用户身份信息 | 仅存储用户标识，不存储密码等敏感凭证 | `05` AC-001 前置条件 |

## 5. 数据约束

### 5.1 输入约束

| 约束 | 规格 | 来源 |
|------|------|------|
| `query` 最小长度 | 1 字符 | `04` R-02 |
| `query` 最大长度 | 500 字符 | `04` R-02 |
| `session_id` 必填 | 非空字符串 | `04` R-01 |
| 会话标题默认值 | "新会话" + 创建时间（如"新会话 2025-04-14 10:30"） | `05` AC-001-01 |
| 会话标题最大长度 | 100 字符 | `05` AC-001-01 |
| 研报文件格式 | 仅限 pdf/doc/docx | `04` R-06 |
| 研报文件大小上限 | 50MB | `04` R-06 |
| 历史记录分页大小 | 默认20条/页，可选10/50/100 | `05` AC-005-03 |

### 5.2 类型约束

| 字段 | 类型 | 约束 | 来源 |
|------|------|------|------|
| `llm_used` | `boolean` | 必须为 True/False，不得为字符串 | `04` R-03 |
| `answer_source` | `string` | 枚举：copaw \| bailian \| demo | `04` R-03 |
| `session_id` | `string` | UUID格式，32位十六进制字符串 | `04` R-01 |
| `session_title` | `string` | 最大长度100字符 | `05` AC-001-01 |
| `query` | `string` | 长度1-500字符 | `04` R-02 |
| `response_time_ms` | `integer` | 非负整数，单位毫秒 | `04` R-03 |
| `answer` | `string` | 非空字符串，最大10000字符 | `04` R-03 |
| `created_at` | `datetime` | ISO 8601格式，如"2025-04-14T10:30:00Z" | `05` AC-005-01 |
| `report_id` | `string` | UUID格式，唯一标识研报 | `05` AC-003 |
| `report_file` | `file` | 类型限制：pdf / doc / docx | `04` R-06, `05` AC-003-01 |
| `report_file` | `file` | 大小限制：≤ 50MB | `04` R-06 |
| `report_status` | `string` | 枚举：pending \| processing \| completed \| failed | `05` AC-003-03 |
| `export_format` | `string` | 枚举：pdf / excel | `05` AC-006 |
| `report_ids` | `array` | 最小数量≥2，用于对比导出 | `05` AC-006 |
