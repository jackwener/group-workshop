## 1. 安全目标与合规要求

> 明确本模块需遵循的安全目标和外部合规标准。投研场景尤其关注数据隐私与内部信息防泄露。

| 安全目标 | 说明 | 对应合规 |
|----------|------|----------|
| 数据不出域 | 所有用户数据、研报内容、问答记录禁止传输至外部服务 | 内部信息安全规范 |
| 最小权限原则 | 每个组件只拥有完成任务所需的最低权限 | 安全设计最佳实践 |
| 审计可追溯 | 所有关键操作（登录、研报访问、数据导出）均有日志记录 | 等保2.0 三级要求 |

## 2. 认证与授权

> 定义用户身份验证方式和权限控制模型。写出认证流程和角色划分。

### 2.1 认证机制

| 项目 | 当前教学版 | 生产建议 |
|------|------------|----------|
| 认证方式 | 无认证，开放访问（Workshop教学版） | JWT Token + Refresh Token |
| Token 有效期 | N/A | Access Token 30min, Refresh Token 7d |
| 密码策略 | N/A | 最少8位，含大小写+数字+特殊字符，90天强制更换 |
| 多因素认证 | N/A | 管理员角色强制MFA，普通用户可选 |

### 2.2 角色与权限矩阵

| 分析师 | ✓ | ✓ | ✓ | ✓ | ✗ |
| 研究员 | ✓ | ✓ | ✓ | ✓ | ✗ |
| 管理员 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 访客 | ✗ | ✓ | ✓ | ✗ | ✗ |

## 3. 数据安全

> 定义数据分类分级、加密策略、存储安全规范。**投研场景核心关注点**。

### 3.1 数据分类与分级

| 数据类型 | 安全等级 | 示例 | 保护措施 |
|----------|----------|------|----------|
| 研报原文 | **机密** | PDF/HTML 研报文件 | 加密存储，访问审计 |
| 问答记录 | **内部** | 用户提问与AI回答 | 存储加密，定期清理 |
| 用户信息 | **内部** | 用户名、角色、操作日志 | 脱敏展示，最小采集 |
| 系统配置 | 一般 | 模型参数、界面配置 | 版本控制 |

### 3.2 加密策略

| 场景 | 当前方案 | 生产建议 |
|------|----------|----------|
| 传输加密 | HTTP（教学环境） | TLS 1.3，所有 API 通信强制 HTTPS |
| 存储加密 | 无（明文JSON文件） | AES-256-GCM，研报文件与问答记录落盘加密 |
| 密钥管理 | 环境变量 `.env` | HashiCorp Vault / AWS KMS，密钥定期轮转 |

## 4. 接口安全

> 与 `09` API 规格配合，定义 API 层面的安全防护措施。

| 防护措施 | 实现方式 | 说明 |
|----------|----------|------|
| 输入校验 | 服务端白名单校验 | 所有用户输入进行类型、长度、格式校验（09 API规格） |
| SQL 注入防护 | 不适用（JSON文件存储） | 生产环境使用参数化查询 / ORM |
| XSS 防护 | React默认转义 | 研报内容渲染时防止脚本注入，生产环境增加CSP策略 |
| CSRF 防护 | 当前无（教学版） | 生产环境：状态变更接口需 CSRF Token + SameSite Cookie |
| 速率限制 | 当前无（教学版） | 生产环境：100 req/min/user，防止接口滥用 |
| 文件上传校验 | 类型白名单(pdf/doc/docx) + 50MB大小限制 | 魔数校验文件真实类型，防止伪装攻击 |

## 5. LLM / AI 安全

> 针对大模型集成的专项安全措施。投研场景数据敏感，需严格管控数据流向。

| 风险点 | 防护措施 | 验收标准 |
|--------|----------|----------|
| 数据外泄至第三方模型 | 本地部署模型 / 内网百炼服务，禁止调用外网 API | 网络出口审计零外传记录 |
| Prompt 注入攻击 | 系统 Prompt 隔离，用户输入预处理过滤（过滤"忽略前述指令"等关键词） | 渗透测试无法通过Prompt注入获取系统指令 |
| 模型幻觉 / 错误信息 | 回答标注来源引用(answer_source)，标识置信度 | 所有回答携带answer_source字段，Demo模式明确标注 |
| 敏感信息泄露（模型回复） | 输出过滤层，正则匹配敏感信息（手机号、身份证号、邮箱）并脱敏 | 安全扫描无敏感信息明文泄露 |

## 6. 审计与日志

> 定义安全审计日志的记录范围、保留策略。

| 事件类型 | 记录内容 | 保留期限 | 告警 |
|----------|----------|----------|------|
| 登录 / 登出 | 用户ID、时间、IP、结果 | 【如 180天】 | 连续失败 ≥5 次告警 |
| 研报访问 | 用户ID、文档ID、操作类型 | 【如 365天】 | 异常批量下载告警 |
| 数据导出 | 导出内容摘要、目标 | 【如 365天】 | 每次导出需审批 |
| 系统配置变更 | 变更人、变更前后值 | 【如 永久】 | 关键配置变更即时通知 |

## 7. 安全威胁清单（STRIDE 简表）

> 基于 STRIDE 模型，列出主要安全威胁与应对方案。

| 类型 | 威胁 | 风险等级 | 应对措施 | 负责人 |
|------|------|----------|----------|--------|
| S | 伪造用户身份访问研报 | **高** | 强认证 + Token 校验 | 后端开发 |
| T | 研报内容在传输中被篡改 | 中 | TLS + 文件哈希校验 | 运维工程师 |
| I | 内部数据通过AI模型泄露 | **高** | 本地部署 + 输出过滤 | 架构师 |
| D | 大量请求导致服务不可用 | 中 | 速率限制 + 降级策略 | 后端开发 |
| E | 权限提升攻击（普通用户获取管理员权限） | **高** | RBAC权限校验 + 接口鉴权中间件 | 后端开发 |
| R | 拒绝服务攻击（上传超大文件耗尽存储） | 中 | 文件大小限制(50MB) + 存储配额 | 运维工程师 |

## 8. 部署安全

> 定义部署架构中的安全要求。

- [ ] 生产/开发环境**严格隔离**，数据不互通
- [ ] 数据库访问仅限应用服务器 IP 白名单
- [ ] 敏感配置（API Key、密码）通过环境变量注入，不入代码仓库
- [ ] 依赖包定期安全扫描（`pip audit` / `npm audit`）
- [ ] 容器运行非root用户，最小化镜像攻击面
- [ ] 日志集中采集至SIEM系统，保留180天以上
- [ ] 定期漏洞扫描与渗透测试（季度）
- [ ] 备份数据加密存储，异地容灾
- [ ] API网关层统一接入，实现限流、鉴权、日志
