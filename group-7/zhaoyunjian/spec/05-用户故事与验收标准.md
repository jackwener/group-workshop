> **本文只做一件事**：按用户能理解的子场景拆成多条 **User Story**，并为每条写清 **REQ-ID**、**验收标准（AC）**。

## 字段说明 — 每条 UserStory 必须包含以下字段

| 字段 | 填写说明 | 数据来源 ← | 流向下游 → |
|------|----------|------------|-----------|
| **需求编号** | 唯一编号，如 REQ-M1QA-001 | ← `02` 采集编号 | → `14` 追踪矩阵首列 |
| **故事** | 作为【角色】，我希望【行为】，以便【价值】 | ← `04` PRD 场景拆解 | → `06` FSD 功能点 |
| **优先级** | P0（必须）/ P1（应该）/ P2（可选） | ← `03` §4 成功标准 | → `12` 里程碑排期 |
| **来源** | 对应 03/04 哪一条需求 | ← `03` 范围 · `04` 场景 | |
| **前置条件** | 触发该故事的前提状态 | ← `04` 用户流程 | → `13` 测试前置 |
| **功能对齐** | 对应功能规格 + 非功能约束 | | → `06` FSD · `07` NFR |
| **设计对齐** | 对应架构、接口、数据、安全 | | → `08` 架构 · `09` API · `10` Data · `11` 安全 |
| **验证对齐** | 对应测试用例 + 追踪矩阵行 | | → `13` TC · `14` 追踪矩阵行 |
| **验收标准** | AC，每条可独立验证 | ← 故事 + `07` NFR | → `13` 测试用例依据 |

## US-001（P0）会话管理

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-001 |
| **故事** | 作为投研人员，我希望通过独立会话方式与LLM交互，以便快速从研报查询到期望信息 |
| **优先级** | P0 |
| **来源** | ← 03 §3 会话管理 |
| **前置条件** | 用户已登录系统 |
| **功能对齐** | → 06 §会话管理 · 07 §响应时间 |
| **设计对齐** | → 08 §会话模块 · 09 POST /session API · 10 session表 · 11 §数据隔离 |
| **验证对齐** | → 13 TC-001 · 14 第1行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-001-01 | 点击新建会话，新开一个会话窗口，会话列表新增一个会话 |
| AC-001-02 | 用户可以从会话列表选择已创建的会话，点击具体会话切换回去 |
| AC-001-03 | 用户点击会话列表某个会话的删除列表，可删除该会话 |

## US-002（P0）问答提交

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-002 |
| **故事** | 作为投研人员，我希望以问答形式在会话中查询研报关键信息，完成研报对比关键指标，以便高效研报阅读 |
| **优先级** | P0 |
| **来源** | ← 03 §3 研报信息提取、研报对比 |
| **前置条件** | 已创建会话 |
| **功能对齐** | → 06 §问答功能 · 07 §响应时间 |
| **设计对齐** | → 08 §问答模块 · 09 POST /query API · 10 message表 · 11 §输入校验 |
| **验证对齐** | → 13 TC-002 · 14 第2行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-002-01 | 用户查询具体研报时，从已上传研报定位该研报，并展示关键信息 |
| AC-002-02 | 用户在对话框中输入具体的问题，问题转到LLM处理，处理结果展示到前端 |
| AC-002-03 | 用户询问多个研报对比时，系统返回针对同个公司的关键指标对比结果 |

|------|------|
| **需求编号** | REQ-M1QA-003 |
| **故事** | 作为投研人员，我希望可以上传/删除研报，以便对已上传的研报作管理 |
| **优先级** | P0 |
| **来源** | ← 03 §3 研报上传 |
| **前置条件** | 用户已登录系统 |
| **功能对齐** | → 06 §研报管理 · 07 §文件存储 |

| 验收标准 | 描述（每条可独立测试） |
