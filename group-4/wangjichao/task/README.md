## 推荐开发顺序（按里程碑）

### S1 会话管理（可演示：会话 CRUD + 前端侧栏）
1. **T01** → 项目脚手架
2. **T02** + **T04** + **T12**（并行）→ Storage会话 + 路由公共 + 前端框架
3. **T05** + **T09** + **T10**（并行）→ 会话端点 + Provider 空壳
4. **T13**（前端会话侧栏）+ **T15**（Storage 单元测试）

### S2 问答核心（可演示：问答 + 三级降级 + 来源标签）
5. **T08**（Agent 降级编排）
6. **T06**（问答端点）
7. **T13** 续：问答区 + 来源标签

### S3 研报功能（可演示：上传/解析/对比/管理）
8. **T03** + **T11**（并行）→ Storage研报 + 解析引擎
9. **T07**（研报端点）
10. **T14**（前端研报标签页+对比）

### S4 收口（可演示：全链路 E2E）
11. **T16**（API 集成测试）
12. 全链路联调 + E2E
