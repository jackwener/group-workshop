## 1. 任务目标

实现 Sidebar 研报列表区、主区域研报详情标签页、对比分析标签页，包含文件上传、搜索筛选、标记、多研报对比及导出功能。

## 3. Sidebar 研报列表（对齐 `06` §3.2）

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /reports` | 渲染研报列表（标题+评级+时间） |
| 上传研报 | 点击"上传研报" | `POST /reports` | 文件选择器 → 上传进度条 → 解析完成提示 |
| 搜索研报 | 输入搜索词 | `GET /reports?keyword=xxx` | 实时过滤研报列表 |
| 标记研报 | 点击标记图标 | `PUT /reports/<id>/mark` | 切换标记状态 |
| 查看详情 | 点击研报项 | `GET /reports/<id>` | 切换到研报详情标签页 |

## 4. 研报详情标签页（对齐 `06` §4.2）

| 区域 | 内容 |
|------|------|
| 基本信息 | 标题、来源、日期、评级、目标价 |
| 核心观点 | 自动解析的核心观点摘要（≤5条） |
| 原文预览 | 研报原文内容（支持滚动浏览） |
| 操作按钮 | [标记重点] [标记已读] [导出解析结果] |

## 5. 对比分析标签页（对齐 `06` §4.3）

| 元素 | 行为 |
|------|------|
| 研报选择器 | 多选下拉框，最多 10 份研报 |
| 对比表格 | 列：研报标题、评级、目标价、核心观点、日期 |
| 导出按钮 | 点击后导出为 Excel 文件 |
| 加载状态 | 对比生成中显示骨架屏，最长 30 秒 |

调用 `POST /reports/compare` 生成对比数据。

## 6. 错误处理（对齐 `06` §6）

| error.code | 前端展示 |
|-----------|----------|
| INVALID_FILE_TYPE | "不支持的文件格式，仅支持 PDF/HTML" |
| FILE_TOO_LARGE | "文件过大，请限制在 50MB 以内" |
| INVALID_REPORT_SELECTION | "请选择2-10份研报进行对比" |
| PARSE_ERROR | "研报解析失败，请稍后重试" |
