实现左侧会话列表侧栏（增删查改）、主区域问答对话区（三态渲染 + 来源标签）、底部输入区。

## 3. Sidebar 会话列表（对齐 `06` §3.1）

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表 + 默认选中第一个 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 插入列表头部 + 自动选中 |
| 删除会话 | 点击 × | `DELETE /sessions/<id>` | 确认弹窗 → 从列表移除 |
| 选中会话 | 点击会话项 | `GET /sessions/<id>/records` | 高亮 + 加载问答记录 |
| 重命名 | 双击会话项 | `PUT /sessions/<id>` | 编辑模式 → 回车保存 |

## 4. 问答区三态渲染（对齐 `06` §4.1）

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| A 空状态 | `currentSession === null` | "请创建或选择一个会话开始" |
| B 常见问题 | 有会话 && 无记录 | 问题网格卡片，点击自动填充 |
| C 对话历史 | 有记录 | 每条：用户问题 + 系统回答 + 来源标签 + 时间戳 |

## 5. 来源标签（对齐 `06` §4.4）

| `answer_source` | `llm_used` | 显示文本 | 样式 |
|-----------------|------------|----------|------|
| `copaw` | `true` | CoPaw | 绿色标签 |
| `bailian` | `true` | 百炼 | 蓝色标签 |
| `demo` | `false` | 离线演示 | 灰色标签 |

## 6. 输入区（对齐 `06` §5）

- `<textarea>` 3 行，placeholder "请输入您的问题..."
- 发送按钮：loading 时 disabled + 文案"发送中…"
- 清空按钮：清空输入框
- 提交调用 `POST /ask`，参数 `{query, session_id}`

## 7. 错误处理（对齐 `06` §6）

| error.code | 前端展示 |
|-----------|----------|
| EMPTY_QUERY | "请输入问题" |
| INVALID_QUERY | "问题过长，请限制在500字符以内" |
| LLM_UNAVAILABLE | "AI服务暂不可用，已切换离线模式" |
