## 1. 概念模型

```
Session（会话）1 ── * QARecord（问答记录）
   │                      │
   │  session_id (PK)     │  id (PK)
   │  title               │  session_id (FK → Session)
   │  query_count          │  query / answer / llm_used
   │  created_at           │  response_time_ms / answer_source
   └  updated_at           └  timestamp / citations

Report（研报）1 ── 1 ParseResult（解析结果）
   │                      │
   │  report_id (PK)      │  report_id (FK → Report)
   │  title               │  rating / target_price
   │  file_type           │  core_views / data_forecast
   │  file_size           │  parse_time_ms
   │  status              │  parsed_at
   │  uploaded_at         │
   │  is_marked           │
   └  file_url            │
```

> **核心关系**：一个 Session 可包含零到多条 QARecord。一个 Report 对应一个 ParseResult。外键通过 `session_id`/`report_id` 字段逻辑引用。

## 2. 存储引擎

| 项 | 说明 |
|----|------|
| 引擎 | JSON 文件（`json` 标准库） |
| 编码 | UTF-8，缩进 2 空格 |
| 读写模式 | RMW（全量读入 → 修改 → 全量写回） |
| 并发安全 | 无锁，不支持并发写入 |
| 文件布局 | `{DATA_DIR}/sessions.json` + `qa_records.json` + `reports.json` |

## 3. 实体定义 — Session

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `session_id` | `string` (UUID) | 是 | **PK** | 会话唯一标识 |
| `title` | `string` | 是 | ≤100 字符 | 默认“新会话”，首次问答自动重命名 |
| `created_at` | `string` (ISO-8601) | 是 | UTC+Z | 创建时间 |
| `updated_at` | `string` (ISO-8601) | 是 | UTC+Z | 最后更新时间 |
| `query_count` | `integer` | 是 | ≥ 0 | 累计问答次数 |

## 4. 实体定义 — QARecord

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `id` | `string` | 是 | **PK**，`rec_{ts}` | 基于时间戳生成 |
| `session_id` | `string` | 是 | **FK** → Session | 所属会话 |
| `query` | `string` | 是 | 1–500 字符 | 用户提问原文 |
| `answer` | `string` | 是 | — | LLM/Demo 返回的答案 |
| `llm_used` | `boolean` | 是 | RULE-005 | 是否使用真实 LLM |
| `model` | `string\|null` | 是 | — | 模型标识 |
| `response_time_ms` | `integer` | 是 | SLO < 5000 | 响应耗时（ms） |
| `answer_source` | `string\|null` | 否 | 枚举 | `copaw`\|`bailian`\|`demo` |
| `citations` | `array` | 否 | — | 原文引用列表 |
| `timestamp` | `string` (ISO-8601) | 是 | UTC+Z | 回答时间 |

## 5. 实体定义 — Report（研报）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `report_id` | `string` (UUID) | 是 | **PK** | 研报唯一标识 |
| `title` | `string` | 是 | ≤200 字符 | 研报标题 |
| `file_type` | `string` | 是 | 枚举 | pdf / html |
| `file_size` | `integer` | 是 | ≤50MB | 文件大小（字节） |
| `file_path` | `string` | 是 | — | 本地存储路径 |
| `status` | `string` | 是 | 枚举 | pending / parsing / completed / failed |
| `uploaded_at` | `string` (ISO-8601) | 是 | UTC+Z | 上传时间 |
| `is_marked` | `boolean` | 是 | 默认 false | 是否标记为重点 |
| `mark_status` | `string` | 否 | 枚举 | none / important / read |

## 6. 实体定义 — ParseResult（解析结果）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `report_id` | `string` | 是 | **FK** → Report | 所属研报 |
| `title` | `string` | 否 | ≤200 字符 | 提取的标题 |
| `rating` | `string` | 否 | 枚举 | 买入/增持/中性/减持/卖出 |
| `target_price` | `string` | 否 | — | 目标价 |
| `core_views` | `array` | 否 | ≤5条 | 核心观点列表 |
| `data_forecast` | `object` | 否 | — | 数据预测（营收增速、PE等） |
| `parse_time_ms` | `integer` | 否 | SLO < 5000 | 解析耗时（ms） |
| `parsed_at` | `string` (ISO-8601) | 否 | UTC+Z | 解析完成时间 |

## 8. 关键业务逻辑

**示例 — 首次问答自动命名**：

```python
if session["query_count"] == 1:
    session["title"] = query[:20] + ("..." if len(query) > 20 else "")
```

> **规则**：仅首次问答（query_count 从 0 → 1）触发，后续不再自动更名。

| 逻辑 | 触发条件 | 行为 |
|------|----------|------|
| 首次问答自动命名 | `query_count` 从 0 → 1 | 标题 = query 前 20 字 + `...` |
| 级联删除会话 | 删除 Session | 同步删除所有关联 QARecord |
| 级联删除研报 | 删除 Report | 同步删除 ParseResult |
| 研报状态流转 | 上传/解析完成/失败 | status: pending → parsing → completed/failed |
