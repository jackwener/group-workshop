## 1. 安全目标与合规要求

> 明确本模块需遵循的安全目标和外部合规标准。投研场景尤其关注数据隐私与内部信息防泄露。

| 安全目标 | 说明 | 对应合规 |
|----------|------|----------|
| 数据不出域 | 所有用户数据、研报内容、问答记录禁止传输至外部服务 | 内部信息安全规范 |
| 最小权限原则 | 每个组件只拥有完成任务所需的最低权限 | 安全设计最佳实践 |
| 可审计性 | 所有关键操作（研报访问、数据导出）必须记录审计日志 | 金融行业合规要求 |

## 2. 认证与授权

> 定义用户身份验证方式和权限控制模型。写出认证流程和角色划分。

### 2.1 认证机制

| 项目 | 当前实现（教学版） | 生产改进 |
|------|----------------------|----------|
| 认证方式 | **无认证，开放访问** | JWT Token + 内部SSO 对接 |
| Token 有效期 | 不适用 | Access Token 30min, Refresh Token 7d |
| 密码策略 | 不适用 | 最少8位，含大小写+数字，90天强制更换 |
| 多因素认证 | 不适用 | 生产环境必须启用 MFA |

### 2.2 角色与权限矩阵

| 角色 | 研报上传 | 研报阅读 | 问答交互 | 对比分析 | 系统管理 |
|------|----------|----------|----------|----------|----------|
| 分析师 | ✓ | ✓ | ✓ | ✓ | ✗ |
| 管理员 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 投资经理 | ✗ | ✓ | ✓ | ✓ | ✗ |

## 3. 数据安全

> 定义数据分类分级、加密策略、存储安全规范。**投研场景核心关注点**。

### 3.1 数据分类与分级

| 数据类型 | 安全等级 | 示例 | 保护措施 |
|----------|----------|------|----------|
| 研报原文 | **机密** | PDF/HTML 研报文件 | 加密存储，访问审计 |
| 问答记录 | **内部** | 用户提问与AI回答 | 存储加密，定期清理 |
| 用户信息 | **内部** | 用户名、角色、操作日志 | 脱敏展示，最小采集 |
| 系统配置 | 一般 | 模型参数、界面配置 | 版本控制 |

### 3.2 加密策略

| 场景 | 当前实现（教学版） | 生产改进 |
|------|----------------------|----------|
| 传输加密 | HTTP（本地开发） | **TLS 1.2+**，强制 HTTPS |
| 存储加密 | JSON 明文存储 | **AES-256**，研报文件与问答记录落盘加密 |
| 密钥管理 | 环境变量 `.env` 文件 | **Vault / Secrets Manager**，定期轮转 |
| 文件存储 | 本地文件系统 | 加密文件系统 + 访问控制 |

## 4. 接口安全

> 与 `09` API 规格配合，定义 API 层面的安全防护措施。

| 防护措施 | 当前实现（教学版） | 生产改进 |
|----------|----------------------|----------|
| 输入校验 | 服务端白名单校验 | 服务端白名单校验 + WAF |
| SQL 注入防护 | JSON 文件存储，无 SQL | 参数化查询 / ORM（如升级数据库） |
| XSS 防护 | 前端转义 | 输出转义 + CSP |
| CSRF 防护 | **无（开放访问无状态）** | SameSite Cookie + CSRF Token |
| 速率限制 | **无** | 100 req/min/user |
| 文件上传校验 | 类型白名单 + 50MB 大小限制 | 增加病毒扫描、沙箱检测 |

## 5. LLM / AI 安全

> 针对大模型集成的专项安全措施。投研场景数据敏感，需严格管控数据流向。

| 风险点 | 当前实现（教学版） | 生产改进 | 验收标准 |
|--------|----------------------|----------|----------|
| 数据外泄至第三方模型 | 内网百炼/Demo 降级 | 本地私有化部署模型 | 网络出口审计零外传记录 |
| Prompt 注入攻击 | 基础输入过滤 | 系统 Prompt 隔离 + 输入预处理 | 渗透测试无注入成功案例 |
| 模型幻觉 / 错误信息 | 原文引用展示 | 多模型对比验证 + 置信度标识 | 用户投诉率 < 1% |
| 敏感信息泄露 | 无过滤 | 输出过滤层，正则匹配敏感信息脱敏 | DLP 扫描零泄露告警 |

## 6. 审计与日志

> 定义安全审计日志的记录范围、保留策略。

| 事件类型 | 记录内容 | 保留期限 | 告警 |
|----------|----------|----------|------|
| 登录 / 登出 | 用户ID、时间、IP、结果 | 180天 | 连续失败 ≥5 次告警 |
| 研报访问 | 用户ID、文档ID、操作类型 | 365天 | 异常批量下载告警 |
| 数据导出 | 导出内容摘要、目标 | 365天 | 每次导出需审批 |
| 系统配置变更 | 变更人、变更前后值 | 永久 | 关键配置变更即时通知 |

## 7. 安全威胁清单（STRIDE 简表）

> 基于 STRIDE 模型，列出主要安全威胁与应对方案。

| 类型 | 威胁 | 风险等级 | 应对措施 | 负责人 |
|------|------|----------|----------|--------|
| S | 伪造用户身份访问研报 | **高** | 强认证 + Token 校验 | 安全团队 |
| T | 研报内容在传输中被篡改 | 中 | TLS + 文件哈希校验 | 开发团队 |
| I | 内部数据通过AI模型泄露 | **高** | 本地部署 + 输出过滤 | 安全团队 |
| D | 大量请求导致服务不可用 | 中 | 速率限制 + 降级策略 | 运维团队 |
| E | 研报文件被非授权访问 | **高** | RBAC权限控制 + 访问审计 | 安全团队 |
| R | 用户否认操作行为 | 中 | 完整审计日志 + 数字签名 | 合规团队 |

## 8. 部署安全

> 定义部署架构中的安全要求。

- [ ] 生产/开发环境**严格隔离**，数据不互通
- [ ] 数据库访问仅限应用服务器 IP 白名单
- [ ] 敏感配置（API Key、密码）通过环境变量注入，不入代码仓库
- [ ] 依赖包定期安全扫描（`pip audit` / `npm audit`）
- [ ] 定期备份数据文件，备份加密存储
- [ ] 文件上传目录独立权限控制，禁止执行权限
