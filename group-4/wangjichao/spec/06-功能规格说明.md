## 1. 页面总体布局

> 画出你的应用的页面结构（ASCII / 手绘均可）。SPA 通常分：Header + Sidebar + Main + Input Area。

**示例 — 布局结构**：

```
┌──────────────────────────────────────────────────────┐
│  header: 标题 + [能力状态芯片] + [用户信息]            │
├────────────┬─────────────────────────────────────────┤
│  sidebar   │  main-content（多标签页）                 │
│  历史会话   │  [会话] [研报] [对比]                     │
│  [+新建]   │  ┌─────────────────────────────────────┐ │
│  session1  │  │ 会话标签页：                         │ │
│  session2  │  │ A) 空状态                            │ │
│            │  │ B) 常见问题网格                      │ │
│  研报列表   │  │ C) 对话历史列表                      │ │
│  [上传研报] │  │                                     │ │
│  report1   │  │ input-area: textarea + 发送          │ │
│  report2   │  └─────────────────────────────────────┘ │
└────────────┴─────────────────────────────────────────┘
```

**布局说明**：
- Header：顶部导航栏，包含系统标题、LLM能力状态芯片
- Sidebar：左侧边栏，包含会话列表 + 研报列表两个分区
- Main：主内容区，采用多标签页设计（会话/研报/对比）
- Input Area：底部输入区域，根据当前标签页切换不同输入模式

## 3. Sidebar 区域

### 3.1 会话列表管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表 + 默认选中第一个 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 插入列表头部 + 自动选中 |
| 删除会话 | 点击 × | `DELETE /sessions/<id>` | 确认弹窗 → 从列表移除 |
| 选中会话 | 点击会话项 | - | 高亮选中项 + 加载该会话的问答记录 |
| 会话重命名 | 双击会话项 | `PUT /sessions/<id>` | 进入编辑模式 → 回车保存 |

### 3.2 研报列表区

> 对齐 `05` US-003、US-006。描述研报列表的交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /reports` | 渲染研报列表（标题+评级+时间） |
| 上传研报 | 点击"上传研报" | `POST /reports/upload` | 文件选择器 → 上传进度条 → 解析完成提示 |
| 搜索研报 | 输入搜索词 | `GET /reports?keyword=xxx` | 实时过滤研报列表 |
| 标记研报 | 点击标记图标 | `PUT /reports/<id>/mark` | 切换标记状态（重点/已读） |
| 查看详情 | 点击研报项 | - | 跳转到研报详情页或弹出抽屉 |

## 4. Main 内容区（多标签页设计）

> 对齐 `05` US-002（问答提交）、US-003（研报解析）、US-004（对比分析）。采用标签页切换不同功能区域。

### 4.1 会话标签页（三态渲染）

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | "请创建或选择一个会话开始" |
| **B 常见问题** | 有会话 && 无记录 | 显示常见问题网格："这个研报的核心观点是什么？"、"目标价是多少？"，点击后自动填充到输入框 |
| **C 对话历史** | 有记录 | 每条记录卡片包含：用户问题 + 系统回答 + 来源标签 + 时间戳 + 原文引用链接 |

### 4.2 研报详情标签页

> 对齐 `05` US-003、US-006。展示研报解析结果和管理功能。

| 区域 | 内容 |
|------|------|
| 研报基本信息 | 标题、来源、日期、评级、目标价 |
| 核心观点区 | 自动解析的核心观点摘要 |
| 原文预览区 | 研报原文内容（支持滚动浏览） |
| 操作按钮 | [标记重点] [标记已读] [导出解析结果] |

### 4.3 对比分析标签页

> 对齐 `05` US-004。多研报对比功能。

| 元素 | 行为 |
|------|------|
| 研报选择器 | 多选下拉框，最多选择10份研报 |
| 对比表格 | 列：研报标题、评级、目标价、核心观点、日期 |
| 导出按钮 | 点击后导出为Excel文件 |
| 加载状态 | 对比生成中显示骨架屏，最长等待30秒 |

### 4.4 记录卡片中的来源标签逻辑

> 根据 `answer_source` 和 `llm_used` 组合显示不同标签。

| `answer_source` | `llm_used` | 显示文本 | 样式 |
|-----------------|------------|----------|------|
| `copaw` | `true` | CoPaw | 绿色/蓝色标签 |
| `bailian` | `true` | 百炼 | 绿色/蓝色标签 |
| `demo` | `false` | 离线演示 | 灰色标签 |

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 错误提示：“请输入问题” |
| `INVALID_QUERY` | 400 | 错误提示：“问题过长，请限制在500字符以内” |
| `INVALID_FILE_TYPE` | 400 | 错误提示：“不支持的文件格式，仅支持 PDF/HTML” |
| `FILE_TOO_LARGE` | 400 | 错误提示：“文件过大，请限制在 50MB 以内” |
| `INVALID_REPORT_SELECTION` | 400 | 错误提示：“请选择2-10份研报进行对比” |
| `PARSE_ERROR` | 500 | 错误提示：“研报解析失败，请稍后重试” |
| `UPSTREAM_ERROR` | 500 | 错误提示：“系统繁忙，请稍后重试” |
| `LLM_UNAVAILABLE` | 503 | 错误提示：“AI服务暂不可用，已切换离线模式” |
