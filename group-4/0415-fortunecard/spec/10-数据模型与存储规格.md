## 2. 核心实体定义

### 2.1 Card（塔罗牌）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| id | number | ✅ | 1-9 | 卡牌唯一标识 |
| name | string | ✅ | 2-10字符 | 卡牌标题 |
| description | string | ✅ | 5-30字符 | 卡牌描述 |

```typescript
interface Card {
  id: number;
  name: string;
  description: string;
}
```

### 2.2 FatePhase（命运阶段）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| key | string | ✅ | 'past' \| 'present' \| 'future' | 阶段标识 |
| label | string | ✅ | 2-4字符 | 中文标签 |
| labelEn | string | ✅ | 大写英文 | 英文标签 |
| subLabel | string | ✅ | 2-4字符 | 副标签 |
| rarity | string | ✅ | 稀有度名称 | 稀有度 |

```typescript
interface FatePhase {
  key: 'past' | 'present' | 'future';
  label: string;
  labelEn: string;
  subLabel: string;
  rarity: string;
}
```

### 2.3 DiceResult（骰子结果）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| face | number | ✅ | 1-6 | 骰子面值 |
| label | string | ✅ | 结果名称 | 结果标签 |
| rot | string | ✅ | CSS transform值 | 3D旋转值 |

```typescript
interface DiceResult {
  face: number;
  label: string;
  rot: string;
}
```

### 2.4 FateAttribute（命运属性）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| key | string | ✅ | 属性标识 | 如 'luck' |
| label | string | ✅ | 2-4字符 | 属性名称 |
| icon | string | ✅ | Material Icons名 | 图标名称 |
| value | number | ✅ | 0-100 | 属性值 |
| color | string | ✅ | 主题色键名 | 颜色主题 |
| unit | string | ✅ | "%" 或 "MAX" | 单位 |

```typescript
interface FateAttribute {
  key: string;
  label: string;
  icon: string;
  value: number;
  color: 'primary' | 'secondary' | 'tertiary';
  unit: string;
}
```

### 2.5 ReportQuote（报告引言）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| text | string | ✅ | 10-100字符 | 引言文本 |
| highlights | array | ✅ | 高亮配置数组 | 高亮词列表 |

```typescript
interface ReportQuote {
  text: string;
  highlights: {\n    word: string;
    color: string;
  }[];
}
```

### 2.6 GameState（游戏状态）

```typescript
type GameState = 'loading' | 'dice' | 'draw' | 'reveal' | 'report';

type FateChoice = 'change' | 'accept' | null;

interface RitualState {
  currentState: GameState;
  selectedCards: number[];      // 选中的卡牌索引数组（最多3个）
  diceResult: DiceResult | null;

}
```

## 3. 存储方案

### 3.1 存储引擎分配

| 数据类型 | 存储引擎 | 键名 | 理由 |
|----------|----------|------|------|
| 当前游戏状态 | React useState（内存） | N/A | 频繁更新，页面刷新自然重置 |
| 卡牌/属性数据 | JS 模块导出 | N/A | 静态配置，构建时确定 |
| 历史图册 | localStorage | `vibe-oracle-history` | 会话级持久化，简单轻量 |

### 3.2 localStorage 存储

| 方法 | 键 | 读/写 | 数据格式 |
|------|-----|-------|----------|
| getHistory | vibe-oracle-history | 读 | JSON 数组 |
| setHistory | vibe-oracle-history | 写 | JSON 数组 |

### 3.3 存储限额

| 指标 | 限制 | 说明 |
|------|------|------|
| 单条记录大小 | ~1KB | 3张卡索引 + 结果 |
| 最大记录数 | 20条 | 超出后FIFO淘汰 |

## 5. 核心算法

### 5.1 洗牌算法（Fisher-Yates）

```javascript
function shuffleCards(cards) {
  const shuffled = [...cards];
  for (let i = shuffled.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [shuffled[i], shuffled[j]] = [shuffled[j], shuffled[i]];
  }
  return shuffled;
}
```

const STATE_FLOW = {

};

## 6. 数据校验规则

| 规则 | 校验时机 | 失败处理 |
|------|----------|----------|
| Card.id 为1-9的数字 | 构建时 | 修正或移除 |
| selectedCards.length ≤ 3 | 运行时 | 忽略超出的选择 |
| localStorage数据可解析为JSON | 运行时 | 返回空数组 |
| 存储空间足够 | 写入时 | 淘汰旧记录 |
