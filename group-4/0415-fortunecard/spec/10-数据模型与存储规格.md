## 2. 实体定义

### 2.1 Card（卡牌）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| id | string | ✅ | 唯一，格式 `card-{type}-{num}` | 卡牌唯一标识 |
| type | CardType | ✅ | 'state' \| 'desire' \| 'result' | 卡牌类型 |
| title | string | ✅ | 2-20 字符 | 卡牌标题 |
| content | string | ✅ | 10-200 字符 | 卡牌正面内容 |
| image | string | ❌ | URL 或本地路径 | 卡牌插图 |
| weight | number | ❌ | 0-100，默认 50 | 抽取权重（预留） |

```typescript
interface Card {
  id: string;
  type: 'state' | 'desire' | 'result';
  title: string;
  content: string;
  image?: string;
  weight?: number;
}
```

### 2.2 Ending（结局）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| id | string | ✅ | 唯一，格式 `ending-{num}` | 结局唯一标识 |
| combination | string | ✅ | 格式 `{stateId}-{desireId}-{resultId}` | 卡牌组合键 |
| title | string | ✅ | 2-30 字符 | 结局标题 |
| description | string | ✅ | 20-500 字符 | 结局描述 |
| mood | string | ✅ | 枚举值 | 情绪基调（影响主题色） |
| themeColor | string | ✅ | CSS 颜色值 | 结局主题色 |

```typescript
type EndingMood = 'epic' | 'chill' | 'chaos' | 'mystic' | 'absurd';

interface Ending {
  id: string;
  combination: string;
  title: string;
  description: string;
  mood: EndingMood;
  themeColor: string;
}
```

### 2.3 Personality（人格报告）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| id | string | ✅ | 唯一 | 人格标识 |
| label | string | ✅ | 2-20 字符 | 人格标签（如"深夜哲学家"） |
| stats | PersonalityStats | ✅ | 每项 0-100 | 五维状态值 |
| description | string | ❌ | 20-200 字符 | 人格描述文案 |

```typescript
interface PersonalityStats {
  fortune: number;      // 运势 0-100
  actionPower: number;  // 行动力 0-100
  crazyIndex: number;   // 发疯值 0-100
  antiAnxiety: number;  // 反内耗指数 0-100
  mysteryLevel: number; // 神秘值 0-100
}

interface Personality {
  id: string;
  label: string;
  stats: PersonalityStats;
  description?: string;
}
```

### 2.4 HistoryRecord（历史记录）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| id | string | ✅ | UUID 格式 | 记录唯一标识 |
| timestamp | number | ✅ | Unix 时间戳 | 抽卡时间 |
| cards | Card[] | ✅ | 长度恒为 3 | 本次抽取的 3 张卡 |
| ending | Ending | ✅ | 非空 | 最终结局 |
| personality | Personality | ✅ | 非空 | 人格报告 |
| isChangedFate | boolean | ✅ | 默认 false | 是否尝试过改命 |

```typescript
interface HistoryRecord {
  id: string;
  timestamp: number;
  cards: [Card, Card, Card];
  ending: Ending;
  personality: Personality;
  isChangedFate: boolean;
}
```

## 3. 存储方案

### 3.1 存储引擎分配

| 数据类型 | 存储引擎 | 键名 | 理由 |
|----------|----------|------|------|
| 当前游戏状态 | React Context（内存） | N/A | 频繁更新，页面刷新自然重置 |
| 卡牌/结局数据 | 代码内 TS 模块 | N/A | 静态配置，构建时确定 |
| 历史图册 | localStorage | `vibe-oracle-history` | 会话级持久化，简单轻量 |
| 用户偏好 | localStorage | `vibe-oracle-prefs` | 跨刷新保持 |

### 3.2 localStorage 方法清单

| 方法 | 键 | 读/写 | 数据格式 | 大小预估 |
|------|-----|-------|----------|----------|
| getHistory | vibe-oracle-history | 读 | JSON 数组 | ≤50KB |
| setHistory | vibe-oracle-history | 写 | JSON 数组 | ≤50KB |
| getPreferences | vibe-oracle-prefs | 读 | JSON 对象 | <1KB |
| setPreferences | vibe-oracle-prefs | 写 | JSON 对象 | <1KB |

### 3.3 存储限额

| 指标 | 限制 | 说明 |
|------|------|------|
| 单条记录大小 | ~2KB | 3 张卡 + 结局 + 人格 |
| 最大记录数 | 20 条 | 超出后 FIFO 淘汰最早记录 |
| 总存储上限 | ~50KB | 远小于 localStorage 5MB 限制 |

## 4. 核心算法

### 4.1 洗牌算法（Fisher-Yates）

```typescript
function shuffleCards(cards: Card[]): Card[] {
  const shuffled = [...cards];
  for (let i = shuffled.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [shuffled[i], shuffled[j]] = [shuffled[j], shuffled[i]];
  }
  return shuffled;
}
```

### 4.2 结局计算

```typescript
function resolveEnding(
  stateCard: Card,
  desireCard: Card,
  resultCard: Card,
  endings: Ending[]
): Ending {
  const key = `${stateCard.id}-${desireCard.id}-${resultCard.id}`;
  const exact = endings.find(e => e.combination === key);
  if (exact) return exact;

  // 降级：按 mood 匹配
  const fallback = endings.find(e => e.mood === determineMood(stateCard, desireCard, resultCard));
  return fallback ?? endings[0];
}
```

### 4.3 人格计算

```typescript
function resolvePersonality(
  stateCard: Card,
  desireCard: Card,
  resultCard: Card,
  warmUp?: WarmUpResult
): Personality {
  const baseStats = calculateBaseStats(stateCard, desireCard, resultCard);
  const modified = warmUp ? applyStyleModifier(baseStats, warmUp.styleModifier) : baseStats;
  const label = determineLabel(modified);
  return { id: generateId(), label, stats: modified };
}
```

## 5. 数据初始化

### 5.1 卡牌数据配置

| 类型 | 数量 | 示例标题 |
|------|------|----------|
| state（状态） | 3 张 | "量子叠加态"、"薛定谔的社畜"、"平行宇宙流浪者" |
| desire（欲望） | 3 张 | "隐藏的月亮"、"被封印的野心"、"午夜的真心话" |
| result（结果） | 3 张 | "命运急转弯"、"宇宙的回响"、"蝴蝶效应启动" |
| **合计** | **9 张** | - |

### 5.2 结局组合

最少 5 种结局组合（3×3×3 = 27 种可能，配置 5-10 个精确匹配 + 1 个 fallback）。

## 6. 数据校验规则

| 规则 | 校验时机 | 失败处理 |
|------|----------|----------|
| Card.id 不为空且唯一 | 构建时 | TypeScript 编译错误 |
| Card.type 为有效枚举 | 构建时 | TypeScript 编译错误 |
| HistoryRecord.cards 长度 = 3 | 运行时 | 拒绝保存，console.error |
| localStorage 数据可解析为 JSON | 运行时 | 返回默认值 |
| 存储空间足够 | 写入时 | 淘汰旧记录后重试 |
