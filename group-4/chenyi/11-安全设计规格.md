## 1. 安全目标与合规要求

| 安全目标 | 说明 | 对应合规 |
|----------|------|----------|
| 数据不出域 | 所有用户数据、研报内容、问答记录禁止传输至外部服务；LLM 调用仅限内网百炼或本地部署模型 | 内部信息安全规范 |
| 最小权限原则 | 每个组件只拥有完成任务所需的最低权限；Storage 层不调用外部 API，Provider 层不操作本地文件 | 安全设计最佳实践 |
| 敏感配置零硬编码 | API Key、模型地址等敏感配置仅通过环境变量注入，禁止出现在代码仓库或日志中 | 内部研发安全规范 · `.gitignore` 强制要求 |

## 2. 认证与授权

### 2.1 认证机制

| 项目 | 规格 |
|------|------|
| 认证方式 | 教学版：无认证（开放访问，仅限内网部署）；生产版：JWT Bearer Token，由统一身份认证服务签发 |
| Token 有效期 | 生产版：Access Token 30 分钟，Refresh Token 7 天；过期后需重新登录 |
| 密码策略 | 生产版：最少 8 位，含大小写字母 + 数字，90 天强制更换；教学版不适用 |
| 多因素认证 | 生产版：管理员角色强制启用 MFA（TOTP），普通分析师账号建议启用；教学版不适用 |

### 2.2 角色与权限矩阵

| 角色 | 研报上传 | 研报阅读 | 问答交互 | 对比分析 | 系统管理 |
|------|----------|----------|----------|----------|----------|
| 分析师 | ✓ | ✓ | ✓ | ✓ | ✗ |
| 管理员 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 只读访客（生产扩展） | ✗ | ✓ | ✗ | ✗ | ✗ |

> **教学版说明**：当前 v0.1 不实现权限控制，全部接口开放访问。权限矩阵为生产版预留，不影响当前开发排期。

## 3. 数据安全

### 3.1 数据分类与分级

| 数据类型 | 安全等级 | 示例 | 保护措施 |
|----------|----------|------|----------|
| 研报原文 | **机密** | PDF/HTML 研报文件 | 仅存储于本地 `./data/` 目录；禁止上传至任何外部服务；访问需记录审计日志 |
| 问答记录 | **内部** | 用户提问与 AI 回答 | 存储于本地 JSON 文件；日志中 `query` 截断至前 50 字符；生产版落盘加密 |
| LLM API Key | **机密** | `DASHSCOPE_API_KEY`、`IRA_COPAW_*_URL` | 仅通过 `.env` 环境变量注入；加入 `.gitignore`；禁止出现在日志、响应体、前端代码中 |
| 系统配置 | 一般 | 模型参数、端口配置 | 版本控制管理，不含敏感值 |

### 3.2 加密策略

| 场景 | 加密方式 | 说明 |
|------|----------|------|
| 传输加密 | TLS 1.2+（生产） | 教学版 HTTP；生产须全链路 HTTPS，启用 HSTS 头；禁止 TLS 1.0/1.1 |
| 存储加密 | AES-256（生产） | 教学版明文 JSON；生产版研报文件与问答记录落盘加密，密钥由 KMS 管理 |
| 密钥管理 | 环境变量（教学）/ KMS（生产） | 教学版 `.env` + `.gitignore`；生产版接入云厂商 KMS，密钥 90 天自动轮转 |

## 4. 接口安全

| 防护措施 | 实现方式 | 说明 |
|----------|----------|------|
| 输入校验 | 服务端白名单校验（Route 层） | `query` 长度 1–500，`session_id` UUID 格式，`title` ≤ 100 字符；不满足返回 400，对齐 `09` §8 |
| XSS 防护 | 前端输出转义 + Flask `escape()` | 研报内容渲染时前端不使用 `dangerouslySetInnerHTML`；后端响应中的字符串字段统一 HTML 转义 |
| CSRF 防护 | 教学版：无状态 REST API 天然防护；生产版：`SameSite=Strict` Cookie + CSRF Token 双重校验 | 状态变更接口（POST/DELETE）生产须携带 CSRF Token |
| 速率限制 | 教学版：不限速；生产版：60 req/min/IP，超限返回 429 | 防止接口滥用与暴力枚举 `session_id` |
| 文件上传校验 | MIME 类型白名单（`application/pdf`、`text/html`）+ 文件头魔数校验 + 单文件 ≤ 20MB | 禁止上传可执行文件；后端校验不依赖前端限制 |
| 路径穿越防护 | `os.path.basename()` 规范化文件名，禁止 `../` 路径 | 研报文件存储时强制规范化，防止目录遍历攻击 |

## 5. LLM / AI 安全

| 风险点 | 防护措施 | 验收标准 |
|--------|----------|----------|
| 数据外泄至第三方模型 | 仅允许调用内网百炼服务或本地部署模型；禁止调用 OpenAI 等外网 API；网络出口配置白名单 | 网络审计日志中零外网 LLM 请求记录 |
| Prompt 注入攻击 | System Prompt 与用户输入严格隔离；用户 `query` 不直接拼接进 System Prompt；对 `</s>`、`[INST]` 等特殊 token 进行预处理过滤 | 测试用例覆盖常见 Prompt 注入模式（如 "忽略前面的指令"），验证系统 Prompt 不被覆盖 |
| 模型幻觉 / 错误信息 | 回答必须附带 `cited_passages` 原文引用；前端展示"离线演示"标签提示用户降级状态 | 所有非 Demo 模式回答均携带至少 1 条 `cited_passages`；Demo 模式回答前端必须展示灰色标签 |
| 敏感信息泄露（模型回复） | 输出后处理层正则匹配常见敏感信息模式（手机号、身份证、API Key 格式）并以 `[已脱敏]` 替换；生产版接入专用内容安全过滤服务 | 测试用例验证含手机号、身份证格式的回答被正确脱敏后返回 |

## 6. 审计与日志

| 事件类型 | 记录内容 | 保留期限 | 告警 |
|----------|----------|----------|------|
| 登录 / 登出（生产） | 用户 ID、时间戳（UTC）、IP、User-Agent、结果（成功/失败） | 180 天 | 同一 IP 连续失败 ≥ 5 次触发告警 |
| 研报上传与访问 | `traceId`、用户 ID、文件名（脱敏）、操作类型、时间戳 | 365 天 | 单用户 1 小时内批量访问 ≥ 50 份触发告警 |
| 问答交互 | `traceId`、`session_id`、`query` 前 50 字符、`answer_source`、`response_time_ms`、时间戳 | 180 天 | 无（常规操作） |
| 数据导出（对比表） | `traceId`、用户 ID、导出内容摘要（研报文件名列表）、时间戳 | 365 天 | 每次导出记录，生产版批量导出需审批 |
| 系统配置变更 | 变更人、变更字段、变更前后值（敏感字段仅记录变更事件不记录值）、时间戳 | 永久 | 关键配置变更（如模型切换、权限变更）即时通知管理员 |
| LLM 降级事件 | `traceId`、降级原因（超时/异常/未配置）、降级层级（`copaw→bailian`、`bailian→demo`）、时间戳 | 90 天 | 1 小时内降级至 Demo 模式次数 ≥ 10 次触发告警 |

## 7. 安全威胁清单（STRIDE 简表）

| 类型 | 威胁 | 风险等级 | 应对措施 | 负责人 |
|------|------|----------|----------|--------|
| S（伪造） | 伪造用户身份访问研报与问答记录 | **高** | 生产版 JWT 强认证 + Token 校验；教学版内网隔离部署 | IT 运维 |
| T（篡改） | 研报内容在传输中被篡改 | 中 | TLS 1.2+ 全链路加密；研报上传后计算 SHA-256 哈希存档，读取时校验 | IT 运维 |
| I（信息泄露） | 内部研报数据通过 LLM 模型泄露至外部 | **高** | 仅本地部署模型或内网百炼；禁止外网 LLM API；网络出口白名单 | IT 运维 / 安全团队 |
| D（拒绝服务） | 大量问答请求导致本地模型推理积压、服务不可用 | 中 | 生产版速率限制 60 req/min/IP；LLM 调用超时 4500ms 自动降级；Demo 模式始终可用 | 开发团队 |
| E（权限提升） | 普通分析师访问管理员接口或他人会话数据 | 中 | 生产版 Route 层统一鉴权中间件；`session_id` 与用户 ID 绑定校验，禁止越权访问 | 开发团队 |
| R（抵赖） | 用户否认曾上传或访问特定研报 | 低 | 全操作审计日志，包含 `traceId`、用户 ID、时间戳；日志不可篡改（生产版写入只追加存储） | IT 运维 |

## 8. 部署安全

- [x] 教学版仅限内网部署，禁止暴露至公网
- [x] 敏感配置（API Key、模型地址）通过 `.env` 环境变量注入，`.env` 加入 `.gitignore`，不入代码仓库
- [x] `./data/` 目录设置为仅应用进程可读写，禁止 Web 服务器直接访问
- [ ] 生产/开发环境严格隔离，数据目录不互通，研报文件不跨环境复制
- [ ] 生产版数据库访问仅限应用服务器 IP 白名单，禁止公网直连
- [ ] 依赖包定期安全扫描：后端 `pip audit`，前端 `npm audit`，CI/CD 流水线中自动执行
- [ ] 生产版容器镜像使用非 root 用户运行 Flask 进程，禁止 `--privileged` 模式
