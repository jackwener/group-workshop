## 1. 需求编号体系

| 编号格式 | 含义 | 示例 |
|----------|------|------|
| `需求-M1-{NNN}` | 功能需求 | 需求-M1-001 |
| `规则-{NNN}` | 数据/类型约束规则 | 规则-005 |

| 级别 | 含义 | 门禁影响 |
|------|------|----------|
| **P0** | 必须实现，阻塞发布 | 关联测试用例全绿方可合并 |
| **P1** | 应当实现，不阻塞首版 | CI warning |
| **P2** | 可选增强 | 不纳入门禁 |

| **需求-M1-007** | 问答记录读取 | P0 | `05` US-003 · `09` §7 | `GET /sessions/<id>/records` 返回该会话全部记录，按 `created_at` 正序；无记录时返回 `[]`；会话已删除时返回 404 |
| **需求-M1-008** | 三级降级链不可跳级 | P0 | `07` §1.2 · `08` §4 | 必须按 CoPaw → 百炼 → Demo 顺序尝试；每级超时 4500ms；`answer_source` 标识实际使用层级 |
| **需求-M1-009** | 原文引用字段 | P0 | `09` §3.1 · `05` AC-002-01 | 非 Demo 模式回答须携带 `cited_passages` 数组；Demo 模式 `cited_passages=null` |
| **需求-M1-010** | 健康检查接口 | P1 | `05` US-004 · `09` §1（端点 1） | `GET /capabilities` 1 秒内返回各组件状态；单组件异常时标记 `degraded`，整体接口不报错 |
| **需求-M1-011** | 会话软删除与级联 | P0 | `10` §6 · `09` §6 | 删除 Session 置 `status=deleted`，不物理清除；关联 QARecord 级联删除；后续访问 records 返回 404 |
| **需求-M1-012** | `session_id` 存在性校验 | P0 | `09` §8 | `POST /ask` 与 `GET /sessions/<id>/records` 传入不存在或已删除的 `session_id` → 404 `SESSION_NOT_FOUND` |
| **需求-M1-013** | 首次问答自动命名 | P1 | `10` §6 | `query_count` 从 0→1 时，Session `title` 自动更新为 query 前 20 字符；后续问答不再变更 |
| **规则-005** | `llm_used` 字段类型约束 | P0 | `09` DTO | 必须为 bool（`true`/`false`），不得为字符串 |
| **规则-006** | `answer_source` 枚举约束 | P0 | `09` §3.1 · `10` §4 | 枚举值仅限 `copaw` \| `bailian` \| `demo`，不得为其他值 |
| **规则-007** | `response_time_ms` 类型约束 | P0 | `09` §3.1 · `07` §5.2 | 必须为非负整数，单位毫秒，不得为浮点数 |
| **规则-008** | 时间字段格式约束 | P1 | `10` §3 · `07` §5.2 | `created_at`、`updated_at`、`deleted_at` 须为 ISO-8601 UTC 格式，如 `2026-04-14T10:00:00Z` |
