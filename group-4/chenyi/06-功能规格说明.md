## 1. 页面总体布局

> 画出你的应用的页面结构（ASCII / 手绘均可）。SPA 通常分：Header + Sidebar + Main + Input Area。

**示例 — 布局结构**：

```
┌──────────────────────────────────────────────────────┐
│  header: 投研问答助手 · [CoPaw 桥接] [百炼·qwen] 芯片  │
├──────────────┬───────────────────────────────────────┤
│  sidebar     │  main-content（三态渲染）               │
│  [+ 新建会话] │  A) 空状态：无会话时的引导提示           │
│  ──────────  │  B) 欢迎态：有会话但无记录，常见问题网格  │
│  session 1   │  C) 对话态：问答记录卡片列表              │
│  session 2   │                                        │
│  session 3   │                                        │
│  …           │  ─────────────────────────────────    │
│              │  input-area: textarea + 清空 + 发送     │
└──────────────┴───────────────────────────────────────┘
```

区块说明：

| 区块 | 职责 |
|------|------|
| `header` | 展示应用标题与当前能力状态芯片 |
| `sidebar` | 会话列表管理：新建、选中、删除 |
| `main-content` | 根据当前会话状态三态渲染 |
| `input-area` | 问题输入与提交，固定在 main-content 底部 |

## 2. Header 区域

> 描述 Header 包含哪些元素。重点关注能力状态芯片（对齐 `05` US-004 健康检查）。

Header 从左至右依次包含：应用名称"投研问答助手"、能力状态芯片组（见 2.1）。芯片在页面首次加载时通过 `GET /capabilities` 获取，加载中显示骨架占位；加载失败时显示灰色"状态未知"芯片，不阻塞主流程。

### 2.1 能力状态芯片（Capability Chips）

| 条件 | 芯片显示 | 样式 | 说明 |
|------|----------|------|------|
| `caps.copaw_configured = true` | CoPaw 桥接 | 蓝色标签 | CoPaw 已配置 |
| `caps.bailian_configured = true` | 百炼 · {model} | 蓝色标签 | 百炼已配置 + 模型名 |
| `caps.bailian_configured = false` | 离线演示 | 灰色标签 | 降级到离线模式 |
| `GET /capabilities` 请求失败 | 状态未知 | 灰色虚线标签 | 不阻塞主流程，用户可继续使用 |

## 3. Sidebar 会话管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面首次渲染 | `GET /sessions` | 渲染会话列表，按 `created_at` 倒序；默认选中第一条；列表为空时显示"暂无会话，点击新建开始"引导文案 |
| 新建会话 | 点击"+ 新建会话" | `POST /sessions` | 请求成功后将新会话插入列表头部，自动选中，main-content 切换至欢迎态（B） |
| 选中会话 | 点击列表中某条会话 | `GET /sessions/<id>/records` | 高亮选中项，main-content 根据记录数量切换至欢迎态（B）或对话态（C） |
| 删除会话 | 点击会话条目右侧 × 图标 | `DELETE /sessions/<id>` | 弹出确认对话框"确认删除该会话？此操作不可撤销"；确认后从列表移除，若删除的是当前选中会话则自动选中列表第一条，列表为空则切换至空状态（A） |

**会话条目展示内容**：

| 元素 | 说明 |
|------|------|
| 会话标题 | 截断超过 20 字符，鼠标悬停展示完整标题 |
| 问答条数 | `query_count` 以灰色小字展示，如"5 条问答" |
| 删除按钮 | 默认隐藏，鼠标悬停时显示 × 图标 |

## 4. Main 内容区（三态渲染）

> 对齐 `05` US-002（问答提交）、US-003（历史记录）。描述三种条件下显示什么。

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | 居中展示"请创建或选择一个会话开始"，附"+ 新建会话"快捷按钮 |
| **B 欢迎态** | 有会话 && `records.length === 0` | 展示"常见问题"网格（见 4.1），引导用户发出第一条提问 |
| **C 对话态** | `records.length > 0` | 按时间正序渲染问答记录卡片列表（见 4.2），新回答出现后自动滚动到底部 |

### 4.1 欢迎态 — 常见问题网格（B 态）

展示 2×2 或 2×3 的快捷问题卡片网格，每张卡片包含一句示例问题文本。点击后自动填入 `query-input` 并聚焦，不自动提交，允许用户修改后再发送。

示例预置问题：
- "这份研报对目标公司的评级是什么？"
- "目标价是多少？核心逻辑是什么？"
- "与上一份研报相比，观点有何变化？"
- "列出研报中提到的主要风险因素"

### 4.2 对话态 — 记录卡片（C 态）

每条记录卡片包含以下元素：

| 元素 | 说明 |
|------|------|
| 提问气泡 | 右对齐，背景色区分，展示 `query` 原文 |
| 回答区块 | 左对齐，展示 `answer` 文本，支持换行与基础 Markdown 渲染（加粗、列表） |
| 来源标签 | 根据 `answer_source` 显示对应芯片（见 4.3） |
| 引用折叠块 | 若 `cited_passages` 非空，展示"查看引用 ▾"折叠区；展开后每条引用显示原文段落与来源文件名、页码 |
| 时间戳 | 灰色小字，展示 `created_at` 格式化为 `HH:mm` |

### 4.3 记录卡片中的来源标签逻辑

> 根据 `answer_source` 和 `llm_used` 组合显示不同标签。

| `answer_source` | `llm_used` | 显示文本 | 样式 |
|-----------------|------------|----------|------|
| `copaw` | `true` | CoPaw | 蓝色标签 |
| `bailian` | `true` | 百炼 | 蓝色标签 |
| `demo` | `false` | 离线演示 | 灰色标签 |

## 5. 输入区域

> 对齐 `05` US-002 AC（query 非空且长度 1~500）。

| 元素 | 类型 | 行为 |
|------|------|------|
| `query-input` | `<textarea>` | 3 行，placeholder "请输入您的问题..."；实时统计字数，右下角显示"已输入 N / 500 字"；超 500 字时字数变红，禁止提交 |
| `send-btn` | `<button>` | 正常态文案"发送"；`loading=true` 时 disabled + 文案"发送中…" + 加载动画；`query` 为空或超长时 disabled |
| `clear-btn` | `<button>` | 清空 `query-input` 内容，仅在有输入内容时显示 |

**回车快捷键**：按 `Enter` 提交，按 `Shift+Enter` 换行。

**提交流程**：
1. 前端校验 `query` 非空且 ≤ 500 字符，不通过则展示行内错误提示，不发起请求
2. 校验通过后调用 `POST /ask`，按钮进入 loading 态
3. 响应成功后清空输入框，新记录卡片追加至对话列表底部并自动滚动
4. 响应失败则展示 toast 错误提示，输入框内容保留，允许重试

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 输入框下方行内红色提示："请输入问题" |
| `INVALID_QUERY` | 400 | 输入框下方行内红色提示："问题不能超过 500 字符" |
| `SESSION_NOT_FOUND` | 404 | toast 提示："会话不存在或已被删除"，自动刷新会话列表 |
| `MISSING_FIELD` | 422 | toast 提示："请求参数有误，请刷新页面后重试" |
| `LLM_UNAVAILABLE` | 503 | toast 提示："当前所有模型均不可用，请联系管理员"，不清空输入内容 |
| 网络超时 / 其他 5xx | — | toast 提示："网络异常，请稍后重试"，输入框内容保留 |
