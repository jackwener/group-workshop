## 1. MySQL 数据模型

### sessions 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID主键 |
| name | VARCHAR(255) | NULL | 会话名称 |
| user_id | VARCHAR(36) | NOT NULL | 用户ID |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |

**索引**
- PRIMARY KEY (id)
- INDEX idx_user_id (user_id)
- INDEX idx_updated_at (updated_at)

### qa_records 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID主键 |
| session_id | VARCHAR(36) | FK, NOT NULL | 会话ID |
| query | TEXT | NOT NULL | 用户问题 |
| answer | TEXT | NOT NULL | AI回答 |
| answer_source | VARCHAR(50) | NOT NULL | 回答来源 |
| created_at | DATETIME | NOT NULL | 创建时间 |

**索引**
- PRIMARY KEY (id)
- INDEX idx_session_id (session_id)
- INDEX idx_created_at (created_at)

**外键**
- FOREIGN KEY (session_id) REFERENCES sessions(id) ON DELETE CASCADE

## 2. Redis 数据结构

### 会话缓存

```
Key: session:{session_id}
Type: Hash
Fields:
  - name: 会话名称
  - user_id: 用户ID
  - created_at: 创建时间
TTL: 24h
```

### 问答缓存

```
Key: qa:recent:{session_id}
Type: List
Value: 最近10条问答记录JSON
TTL: 1h
```

## 3. Milvus 向量库

### Collection: reports

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT64 | 主键 |
| report_id | VARCHAR(36) | 研报ID |
| chunk_id | INT | 片段序号 |
| content | VARCHAR(2000) | 文本内容 |
| embedding | FLOAT_VECTOR(1536) | 向量 |
| metadata | JSON | 元数据 |

**索引**
- IVF_FLAT, nlist=1024
