## 1. 会话管理功能

### F-001 会话创建

| 字段 | 说明 |
|------|------|
| 功能编号 | F-001 |
| 功能名称 | 会话创建 |
| 关联用户故事 | US-001 |
| 输入 | 会话名称（可选） |
| 输出 | session_id, 创建时间 |
| 业务规则 | 每个用户最多创建100个会话 |

### F-002 会话列表

| 字段 | 说明 |
|------|------|
| 功能编号 | F-002 |
| 功能名称 | 会话列表 |
| 关联用户故事 | US-001 |
| 输入 | 用户ID |
| 输出 | 会话列表（session_id, 名称, 创建时间, 最后更新时间） |
| 业务规则 | 按最后更新时间倒序排列 |

### F-003 会话删除

| 字段 | 说明 |
|------|------|
| 功能编号 | F-003 |
| 功能名称 | 会话删除 |
| 关联用户故事 | US-001 |
| 输入 | session_id |
| 输出 | 删除结果 |
| 业务规则 | 删除会话同时删除关联的问答记录 |

## 2. 问答功能

### F-004 问答提交

| 字段 | 说明 |
|------|------|
| 功能编号 | F-004 |
| 功能名称 | 问答提交 |
| 关联用户故事 | US-002 |
| 输入 | session_id, query（1-500字符） |
| 输出 | answer, answer_source, references |
| 业务规则 | query长度校验，回答必须携带来源标识 |

### F-005 问答历史

| 字段 | 说明 |
|------|------|
| 功能编号 | F-005 |
| 功能名称 | 问答历史 |
| 关联用户故事 | US-002 |
| 输入 | session_id |
| 输出 | 问答记录列表（query, answer, timestamp） |
| 业务规则 | 按时间倒序排列 |
