## 1. 背景与问题

| 痛点 | 来源 |
|------|------|
| 研报阅读困难：篇幅长，关键信息不突出 | 用户访谈 |
| 关键信息不显：标题、评级、目标价需手动提取 | 用户访谈 |
| 研报对比困难：各家格式不同，需手动整理 | 用户访谈 |
| 股票数据查询不便：多系统切换，效率低 | 用户访谈 |

## 2. 提案概要

1. **问答式研报助手入口**：支持关键词快速搜索、研报对比、股票数据查询功能（独立）

2. **关键信息提取**：支持语义定义并使信息点定义，相似表述对齐

3. **研报对比**：结构化分拆研报，生成不同研报间对比分析

4. **股票热招查询**：支持批量选择股票标签，进行相关数据采集汇总

## 3. 范围边界

| 做（范围内） | 不做（范围外） |
|-------------|---------------|
| 问答入口、三个预设入口功能 | 会议记录、聊天上皮召回 |
| 研报传递（关键事件触发、站内） | 任意带内容分拆递送 |
| 研报对比（不同维度数据分析） | 多租户/行级数据权限 |
| 股票数据查询（已改服务，支持更新汇总） | 外部数据源实时同步 |

## 4. 成功标准（可度量）

| 标准 | 度量方式 |
|------|----------|
| 主路径可走通 | 用户提问 → 研报内容总结汇总 |
| 三个功能可走通 | 问答入口、研报对比、股票查询全部可用 |
| 案例通过 | 100字案例，都通过且还单用好 |
| 功能正确 | 每功能30字，都执行且正确 |

## 5. 风险（简表）

| 风险 | 影响 | 应对 |
|------|------|------|
| AI幻觉：使用自身知识出现幻觉 | 回答内容有误 | 引用来源标注，人工审核 |
| 内容有误 | 用户获取错误信息 | 多源验证，置信度评估 |
| 异常引用来源 | 搜寻风险 | 来源追溯，审核机制 |

## 6. 立项前置条件（Go / No-Go）

- ☐ 前端正常运行
- ☐ 演示接口通过，确认10%
- ☐ 初步效果超过验收
