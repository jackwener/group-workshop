# 04 — 产品需求说明（PRD）

---

| 项 | 值 |
|---|---|
| 模块编号 | M4-QA |
| 模块名称 | 研报问答助手 |
| 文档版本 | v0.1 |
| 阶段 | Proposal（Why → What 过渡） |
| 上游 | `03` 立项提案（已通过） |
| 下游 | → `05` UserStory 与验收标准 |

---

## 1. 愿景与目标

| 03 痛点 | 04 目标 |
|---------|---------|
| 研报阅读困难 | 统一问答入口，快速获取关键信息 |
| 关键信息不显 | 自动提取标题、评级、目标价、核心观点 |
| 研报对比困难 | 多份研报关键指标自动对比 |
| 股票数据查询不便 | 研报阅读界面直接查询股票数据 |

## 2. 目标用户

| 角色 | 使用目标 | 频率 |
|------|----------|------|
| 投研分析师 | 快速查询投研观点与市场解释 | 每天多次 |
| 基金经理 | 研报对比，辅助投资决策 | 每天 |
| 研究员 | 股票数据查询与汇总 | 每周 |

## 3. 核心业务场景

| 编号 | 场景名 | 用户路径 |
|------|--------|----------|
| SC-01 | 会话管理 | 用户创建会话 → 切换会话 → 删除会话 |
| SC-02 | 问答提交 | 用户输入问题 → 获取回答（含来源标识）→ 回答自动落库 |
| SC-03 | 历史记录 | 查看问答历史 → 重新发送问题 → 导出记录 |
| SC-04 | 研报对比 | 选择多份研报 → 自动对比分析 → 生成对比报告 |

## 4. 产品规则

| 编号 | 规则 | 来源 |
|------|------|------|
| R-01 | 每条提问必须绑定 `session_id` | 03 §2 "会话式问答" |
| R-02 | `query` 长度 1～500 字符，为空或超长返回明确错误 | 03 §4 "P0 全部可测" |
| R-03 | 回答必须携带来源标识（answer_source） | 03 §5 "引用来源" |
| R-04 | 研报对比至少选择2份研报 | 03 §3 "功能对齐" |
| R-05 | 支持英文查询与回答 | 03 §2 "英文支持" |

## 5. 能力与优先级

| 子能力 | 优先级 | 对应场景 |
|--------|--------|----------|
| 会话管理（创建 / 列表 / 删除） | **P0** | SC-01 |
| 问答提交与回答 | **P0** | SC-02 |
| 历史记录查看与重发 | **P0** | SC-03 |
| 研报对比分析 | **P0** | SC-04 |
| 健康检查 | **P1** | - |

## 6. 验收与成功标准（PRD 层）

| 标准 | 度量 |
|------|------|
| 可演示 | 种子数据 ≥ 10 条下，主路径 + 历史 + 对比 **3 分钟内**演示完毕 |
| 离线可用 | 未配置密钥时系统仍返回离线演示回复 |
| 案例通过 | 100字案例，都通过且还单用好 |
| 功能正确 | 每功能30字，都执行且正确 |

## 7. 与 05 用户故事的关系

| 本文（PRD） | 作用 | 05 中落地 |
|-------------|------|-----------|
| §3 核心场景 | 一条叙事场景 → 一条或多条 US | SC-01 → US-001 |
| §4 产品规则 | 字段/状态/错误口径 | 拆入各 US 的 AC |
| §5 能力优先级 | P0 / P1 | 与各 US 优先级一致 |
