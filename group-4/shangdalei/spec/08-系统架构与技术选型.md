## 2. 技术选型

### 前端技术栈

| 组件 | 技术选型 | 版本 | 说明 |
|------|----------|------|------|
| 框架 | Vue 3 | 3.x | 响应式前端框架 |
| 构建 | Vite | 5.x | 快速构建工具 |
| UI库 | Element Plus | 2.x | 企业级UI组件库 |
| 路由 | Vue Router | 4.x | 路由管理 |
| 状态 | Pinia | 2.x | 状态管理 |
| HTTP | Axios | 1.x | HTTP客户端 |

### 后端技术栈

| 组件 | 技术选型 | 版本 | 说明 |
|------|----------|------|------|
| 框架 | FastAPI | 0.109+ | 高性能异步框架 |
| ORM | SQLAlchemy | 2.x | ORM框架 |
| 验证 | Pydantic | 2.x | 数据验证 |
| 异步 | asyncio | - | 异步支持 |

### 数据存储

| 组件 | 技术选型 | 版本 | 说明 |
|------|----------|------|------|
| 关系库 | MySQL | 8.x | 主数据存储 |
| 缓存 | Redis | 7.x | 会话缓存、热点数据 |
| 向量库 | Milvus | 2.x | 语义搜索向量存储 |

### AI服务

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| LLM | OpenAI API | GPT-4 / GPT-3.5 |
| Embedding | text-embedding-ada-002 | 文本向量化 |

## 4. 模块职责

| 模块 | 职责 |
|------|------|
| Frontend | 用户界面、交互逻辑 |
| Backend | 业务逻辑、API服务 |
| MySQL | 会话、问答记录持久化 |
| Redis | 会话缓存、热点数据 |
| Milvus | 研报向量存储、语义搜索 |
