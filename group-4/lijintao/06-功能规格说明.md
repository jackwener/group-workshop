## 3. Sidebar 会话管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表 + 默认选中第一个或新建 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 弹出输入框 → 输入标题 → 插入列表头部 + 自动选中 |
| 选中会话 | 点击会话项 | - | 高亮选中项 + 加载该会话消息到 Main 区 |
| 删除会话 | 点击 × 图标 | `DELETE /sessions/{id}` | 确认弹窗（"确定删除此会话？"）→ 从列表移除 + 切换到其他会话 |
| 搜索会话 | 输入关键词 | - | 本地过滤会话列表，高亮匹配项 |

**会话项显示**：
- 标题（截断显示前 20 字符）
- 最后活动时间（相对时间：刚刚/5分钟前/今天/昨天/日期）
- 悬停显示删除按钮

### 4.4 流式响应状态

| 状态 | 视觉表现 |
|------|----------|
| 等待中 | 输入框禁用 + 发送按钮显示加载动画 |
| 接收中 | AI 消息气泡显示"正在输入..."光标动画 |
| 完成 | 消息完整显示 + 来源标签 + 时间戳 |
| 错误 | 错误提示条（红色）+ 重试按钮 |

## 5. 输入区域

> 对齐 `05` US-002 AC（query 非空且长度 1~4000）。

| 元素 | 类型 | 行为 |
|------|------|------|
| query-input | `<textarea>` | 3 行自适应，placeholder "请输入您的问题...（最多4000字）" |
| send-btn | `<button>` | 默认禁用（空输入），loading 时显示"发送中..."+禁用 |
| clear-btn | `<button>` | 清空输入框内容 |
| char-count | `<span>` | 实时显示当前字数 / 4000 |

**键盘交互**：
- `Enter`：发送消息（无 Shift 时）
- `Shift + Enter`：换行
- `Ctrl/Cmd + Enter`：发送消息

**验证规则**：
- 空输入：禁用发送按钮
- 超过 4000 字符：显示红色警告，禁用发送
- 仅空白字符：视为空输入

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | Toast 提示："请输入问题内容" |
| `QUERY_TOO_LONG` | 400 | Toast 提示："问题内容超过最大长度（4000字符）" |
| `SESSION_NOT_FOUND` | 404 | Toast 提示："会话不存在或已被删除" |
| `LLM_SERVICE_ERROR` | 503 | 消息气泡内显示："服务暂时不可用，已切换至备用模式" |
| `RATE_LIMIT_EXCEEDED` | 429 | Toast 提示："请求过于频繁，请稍后再试" |
| `INTERNAL_ERROR` | 500 | Toast 提示："系统错误，请稍后重试" |

## 8. 交互流程图

### 8.1 发送消息流程

```
用户输入问题 → 点击发送
    ↓
验证输入（非空、长度）
    ↓
禁用输入框 → 显示加载状态
    ↓
POST /sessions/{id}/messages (SSE)
    ↓
接收流式响应 → 实时渲染消息内容
    ↓
响应完成 → 启用输入框 → 更新消息列表
    ↓
错误处理（降级/重试/提示）
```

### 8.2 切换会话流程

```
用户点击会话项
    ↓
更新 currentSession
    ↓
加载该会话消息（缓存优先）
    ↓
渲染消息列表到 Main 区
    ↓
自动滚动到底部
```
