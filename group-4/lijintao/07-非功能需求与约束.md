## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| **问答响应首字节时间** | ≤ **500ms** | 从请求到首字节返回 | `05` AC-002-01 |
| **问答完整响应 P95** | ≤ **3000ms** | 流式响应完成时间 | `05` AC-002-01 |
| **问答完整响应 P99** | ≤ **5000ms** | 流式响应完成时间 | 系统约束 |
| **会话列表查询** | ≤ **200ms** | 服务端计时 | - |
| **历史消息查询** | ≤ **300ms** | 服务端计时 | `05` AC-003-02 |
| **搜索响应时间** | ≤ **500ms** | 全文搜索结果返回 | `05` AC-003-02 |
| **健康检查响应** | ≤ **100ms** | 基础健康检查 | `05` AC-004-01 |
| **页面首屏加载** | ≤ **2000ms** | FCP (First Contentful Paint) | Web 性能标准 |
| **页面可交互时间** | ≤ **3500ms** | TTI (Time to Interactive) | Web 性能标准 |

### 1.2 吞吐量 SLO

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **并发用户数** | ≥ **100** | 同时在线用户 | 系统容量 |
| **每秒请求数 (QPS)** | ≥ **50** | 峰值处理能力 | - |
| **每分钟消息数** | ≥ **300** | 聊天消息处理能力 | - |

### 1.3 降级策略

**四级降级链**：

```
POST /sessions/{id}/messages
  ├─[1] Azure OpenAI (GPT-4) → provider='azure_openai', is_degraded=false
  ├─[2] OpenAI API (GPT-4)   → provider='openai', is_degraded=false
  ├─[3] Claude API           → provider='claude', is_degraded=false
  └─[4] 本地模型 (Llama 3)   → provider='local', is_degraded=true
```

| 约束 | 说明 |
|------|------|
| **降级可跳级** | 根据故障情况直接跳至可用级别 |
| **降级静默执行** | 不抛异常，通过 `is_degraded` 标识 |
| **降级提示用户** | 降级时消息气泡显示橙色降级标签 |
| **本地模型兜底** | 无外部依赖，保证基本可用性 |
| **降级恢复** | 主服务恢复后自动切回，无需重启 |

### 1.4 缓存策略

| 缓存类型 | TTL | 用途 |
|----------|-----|------|
| 会话列表缓存 | 60s | 减少数据库查询 |
| 会话详情缓存 | 300s | 加速会话切换 |
| LLM 响应缓存 | 3600s | 相同问题复用结果 |
| 限流计数器 | 60s | 滑动窗口限流 |
| 健康状态缓存 | 10s | 避免频繁健康检查 |

## 2. 可用性需求

### 2.1 可用性指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **服务可用性** | **99.5%** | 月度可用性目标 |
| **计划内停机** | ≤ 4小时/月 | 维护窗口 |
| **MTTR (平均恢复时间)** | < 10 分钟 | 故障发生后恢复 |
| **MTBF (平均故障间隔)** | > 720 小时 | 系统稳定性 |

### 2.2 故障模式与恢复

| 故障类型 | 影响 | 检测方式 | 恢复方式 |
|----------|------|----------|----------|
| **LLM 服务不可用** | 问答降级 | 健康检查 | 自动切换 Provider |
| **数据库连接失败** | 服务不可用 | 连接池监控 | 重连 + 告警 |
| **Redis 故障** | 缓存失效 | 连接检测 | 降级直连数据库 |
| **单实例崩溃** | 部分不可用 | 进程监控 | 自动重启 |
| **网络分区** | 外部服务中断 | 心跳检测 | 等待网络恢复 |

### 2.3 灾备要求

| 级别 | RPO (数据丢失) | RTO (恢复时间) | 策略 |
|------|----------------|----------------|------|
| **数据库** | ≤ 1小时 | ≤ 30分钟 | 每小时增量备份 + 每日全量 |
| **配置数据** | 0 | ≤ 10分钟 | Git 版本控制 |
| **会话数据** | ≤ 5分钟 | ≤ 15分钟 | 实时 WAL 归档 |

## 3. 可观测性需求

### 3.1 日志规范

| 项 | 规格 |
|----|------|
| **日志级别** | DEBUG / INFO / WARNING / ERROR / CRITICAL |
| **日志格式** | JSON 结构化 |
| **保留期限** | 7天（热存储）+ 90天（冷存储） |
| **采样率** | 100%（ERROR）/ 10%（INFO） |

**日志字段标准**：

```json
{
  "timestamp": "2026-04-14T10:30:00.000Z",
  "level": "INFO",
  "service": "qa-service",
  "trace_id": "tr_abc123def456",
  "span_id": "span_789xyz",
  "user_id": "user_001",
  "session_id": "session_123",
  "action": "chat_completion",
  "duration_ms": 1250,
  "status": "success",
  "metadata": {
    "provider": "azure_openai",
    "model": "gpt-4",
    "tokens_input": 150,
    "tokens_output": 320
  }
}
```

### 3.2 链路追踪

| 项 | 规格 |
|----|------|
| **traceId 格式** | `tr_{uuid.hex}`（32 位十六进制） |
| **spanId 格式** | `span_{uuid.hex[:16]}`（16 位十六进制） |
| **注入位置** | 所有响应顶层 `traceId` 字段 |
| **请求头透传** | `X-Trace-Id` / `X-Span-Id` |
| **上游透传** | 优先复用请求头，缺省时本地生成 |

### 3.3 监控指标

| 类别 | 指标 | 告警阈值 |
|------|------|----------|
| **应用** | QPS | 异常波动 > 50% |
| | 错误率 | > 1% |
| | P95 延迟 | > 3000ms |
| | P99 延迟 | > 5000ms |
| **业务** | 会话创建数 | 异常波动 |
| | 消息发送数 | 异常波动 |
| | LLM 调用成功率 | < 95% |
| **资源** | CPU 使用率 | > 80% |
| | 内存使用率 | > 85% |
| | 磁盘使用率 | > 80% |
| | 数据库连接数 | > 80% |

### 3.4 告警规则

| 告警级别 | 触发条件 | 通知方式 | 响应时间 |
|----------|----------|----------|----------|
| **P0 - 紧急** | 服务完全不可用 | 电话 + 短信 + 邮件 | 5分钟内 |
| **P1 - 高** | 错误率 > 5% 或 P95 > 5s | 短信 + 邮件 + Slack | 15分钟内 |
| **P2 - 中** | 降级模式持续 > 10分钟 | 邮件 + Slack | 1小时内 |
| **P3 - 低** | 资源使用率预警 | 邮件 | 4小时内 |

## 4. 安全需求

### 4.1 认证授权

| 项 | 规格 | 说明 |
|----|------|------|
| **认证方式** | JWT (JSON Web Token) | Access Token + Refresh Token |
| **Token 有效期** | Access: 15分钟 / Refresh: 7天 | - |
| **密码策略** | bcrypt, cost=12 | 强制加密存储 |
| **会话管理** | Redis 存储 Token 黑名单 | 支持主动登出 |
| **权限控制** | RBAC (基于角色的访问控制) | 用户只能访问自己的数据 |

### 4.2 传输安全

| 项 | 规格 |
|----|------|
| **传输协议** | HTTPS / TLS 1.3 |
| **HSTS** | max-age=31536000; includeSubDomains |
| **证书** | 有效证书，自动续期 |

### 4.3 输入安全

| 项 | 规格 |
|----|------|
| **SQL 注入防护** | ORM 参数化查询 |
| **XSS 防护** | 输入过滤 + 输出转义 |
| **CSRF 防护** | Token 验证 |
| **文件上传** | 禁止（本系统无上传功能） |
| **请求大小限制** | 10MB |

### 4.4 敏感数据保护

| 数据类型 | 保护方式 | 存储位置 |
|----------|----------|----------|
| **用户密码** | bcrypt 哈希 | PostgreSQL |
| **JWT Secret** | 环境变量 | 服务器内存 |
| **LLM API Key** | 环境变量 / 密钥管理服务 | 服务器内存 |
| **用户查询内容** | 明文存储（业务需要） | PostgreSQL |
| **消息历史** | 明文存储 | PostgreSQL |

### 4.5 审计日志

| 操作 | 记录内容 | 保留期 |
|------|----------|--------|
| 用户登录 | 时间、IP、设备、结果 | 1年 |
| 会话创建/删除 | 时间、用户、会话ID | 1年 |
| 消息发送 | 时间、用户、会话ID、Token数 | 90天 |
| 配置变更 | 时间、操作人、变更内容 | 2年 |
