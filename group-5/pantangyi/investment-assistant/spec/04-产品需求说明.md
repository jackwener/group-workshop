## 1. 产品概述

### 1.1 产品定位

投研问答助手是一款面向分析师的智能问答工具，旨在解决研报处理效率低、信息分散的问题。通过整合多数据源系统，提供研报阅读、股票信息查询等能力，帮助分析师快速提取关键信息、形成分析报告。

### 1.2 目标用户

- **主要用户**：证券分析师、投资研究员
- **用户特征**：需要频繁阅读研报、查询股票信息、撰写分析报告
- **核心痛点**：信息分散在多个系统、研报数据量大难以快速提取关键信息

### 1.3 核心价值主张

- **效率提升**：3分钟内完成从新建会问到获取分析结果的全流程
- **信息整合**：统一问答入口，整合研报、股票数据等多源信息
- **智能分析**：调用大模型提取研报要点、生成股票分析报告

## 2. 需求场景

### 2.1 场景一：研报阅读分析

**场景描述**：分析师需要阅读多份研报，提取关键信息并比对分析

**用户旅程**：
1. 分析师创建新会话
2. 上传一份或多份研报文件
3. 系统调用大模型提取每份研报的关键信息
4. 系统分析研报间的关联性指标
5. 分析师查看分析结果，形成报告

**价值**：将原本需要数小时的研报阅读时间缩短至3分钟内

### 2.2 场景二：股票信息查询

**场景描述**：分析师需要快速获取某只股票的综合分析报告

**用户旅程**：
1. 分析师在会话中输入股票代码
2. 系统检索并整合多数据源的股票数据
3. 系统生成包含财务指标、研报摘要的分析报告
4. 分析师查看报告，支持下载分享

**价值**：一站式获取股票全面信息，准确率90%以上

### 2.3 场景三：历史问答追溯

**场景描述**：分析师需要回顾之前的问答记录，快速检索历史信息

**用户旅程**：
1. 分析师查看历史会话列表
2. 选择特定历史会话
3. 查看完整的问答上下文
4. 基于历史记录继续提问或导出报告

**价值**：可追溯的信息获取方式，便于知识沉淀和复用

### 4.2 异常流程

| 异常场景 | 处理方式 |
|----------|----------|
| 外部LLM不可用 | 启动降级策略：CoPaw → 百炼 → Demo模式 |

| 股票代码不存在 | 提示错误，建议检查输入 |
| 数据源超时 | 重试机制，超时后提示用户 |

## 5. 非功能需求

### 5.1 性能需求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | < 2秒 |
| 会话创建响应 | < 1秒 |
| 研报分析完成 | < 3分钟 |
| 股票报告生成 | < 3分钟 |
| 并发用户数 | 支持10人同时在线 |

### 5.2 可用性需求

- 支持主流浏览器（Chrome、Firefox、Edge）
- 界面响应式，适配主流分辨率
- 操作反馈明确，错误提示友好

### 5.3 安全需求

- 研报数据不外传，本地处理
- 未公开数据不获取
- 用户会话数据隔离存储

### 5.4 兼容性需求

- 支持PDF、Word格式研报上传
- 后端Flask + 前端React + Vite技术栈

## 8. 依赖与约束

### 8.1 外部依赖

| 依赖项 | 用途 | 降级方案 |
|--------|------|----------|
| CoPaw LLM | 研报分析、问答 | 百炼 → Demo模式 |

### 8.2 技术约束

- 后端：Flask + JSON文件存储
- 前端：React + Vite
- 测试：pytest
- 不实现多租户/行级数据权限
- 不实现AI总结报告核心功能
