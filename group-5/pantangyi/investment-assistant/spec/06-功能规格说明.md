## 2. 会话管理功能 (FUNC-001~004)

### 2.1 创建会话 (FUNC-001)

**功能描述**: 创建一个新的问答会话

**输入**: 
- title (可选): 会话标题，默认"新会话"
- type (可选): 会话类型，默认"general"

**处理逻辑**:
1. 生成唯一session_id (格式: sess_YYYYMMDD{序号})
2. 创建Session实体，状态设为"active"
3. 创建空消息列表文件
4. 返回会话信息

**输出**: Session对象

**异常处理**:
| 异常 | 处理 |
|------|------|
| 参数格式错误 | 返回400错误 |
| 文件写入失败 | 返回500错误 |

---

### 2.2 获取会话列表 (FUNC-002)

**功能描述**: 获取历史会话列表，默认返回最近5个

**输入**:
- limit (可选): 返回数量，默认5，最大20
- offset (可选): 偏移量，默认0

**处理逻辑**:
1. 读取data/sessions目录下所有JSON文件
2. 按updated_at降序排序
3. 根据offset和limit截取结果
4. 返回会话列表和总数

**输出**: Session列表 + total

**异常处理**:
| 异常 | 处理 |
|------|------|
| 目录读取失败 | 返回空列表 |

---

### 2.3 删除会话 (FUNC-003)

**功能描述**: 删除指定会话及其关联数据

**输入**:
- session_id: 会话ID

**处理逻辑**:
1. 验证session_id是否存在
2. 标记Session状态为"deleted"
3. 异步清理关联数据（消息、分析记录）
4. 返回成功

**输出**: 成功/失败状态

**异常处理**:
| 异常 | 处理 |
|------|------|
| 会话不存在 | 返回404错误 |
| 会话已删除 | 返回400错误 |

---

### 2.4 获取会话详情 (FUNC-004)

**功能描述**: 获取会话完整信息，包括消息历史

**输入**:
- session_id: 会话ID

**处理逻辑**:
1. 读取Session实体
2. 读取关联的Message列表
3. 合并返回

**输出**: Session + Messages

**异常处理**:
| 异常 | 处理 |
|------|------|
| 会话不存在 | 返回404错误 |

---

## 3. 问答分析功能 (FUNC-005~007)

### 3.1 研报分析 (FUNC-005)

**功能描述**: 上传研报文件并调用LLM提取关键信息

**输入**:
- session_id: 会话ID
- files: 研报文件列表（PDF/Word）
- extract_keywords: 是否提取关键词
- compare_reports: 是否比对多份研报

**处理逻辑**:
1. 验证session_id存在且状态为active
2. 保存上传文件到uploads目录
3. 提取文件文本内容
4. 调用LLM服务分析每份研报
5. 如有多份研报且compare_reports=true，计算关联性指标
6. 保存分析结果到Analysis实体
7. 创建Message记录分析结果
8. 更新Session的updated_at和message_count

**输出**: Analysis结果

**异常处理**:
| 异常 | 处理 |
|------|------|
| 会话不存在 | 返回404错误 |
| 文件格式不支持 | 返回400错误 |
| LLM服务不可用 | 触发降级策略 |
| 分析超时 | 返回processing状态，支持轮询 |

---

### 3.2 股票查询 (FUNC-006)

**功能描述**: 输入股票代码，获取综合分析报告

**输入**:
- session_id: 会话ID
- stock_code: 股票代码
- stock_name (可选): 股票名称
- analysis_type: 分析类型（full/financial/news）

**处理逻辑**:
1. 验证session_id存在且状态为active
2. 从数据源查询股票基础信息
3. 查询股票相关研报摘要
4. 调用LLM生成综合分析报告
5. 计算综合评分和风险等级
6. 保存分析结果到Analysis实体
7. 创建Message记录分析结果
8. 更新Session的updated_at和message_count

**输出**: 股票分析报告

**异常处理**:
| 异常 | 处理 |
|------|------|
| 股票代码不存在 | 返回404错误 |
| 数据源超时 | 重试2次后返回错误 |
| LLM服务不可用 | 触发降级策略 |

---

### 3.3 发送消息 (FUNC-007)

**功能描述**: 在会话中发送消息并获取回复

**输入**:
- session_id: 会话ID
- content: 消息内容
- type: 消息类型

**处理逻辑**:
1. 验证session_id存在且状态为active
2. 创建用户Message
3. 根据消息内容类型调用相应服务
4. 创建助手Message（回复）
5. 更新Session的updated_at和message_count

**输出**: 助手回复Message

**异常处理**:
| 异常 | 处理 |
|------|------|
| 会话不存在 | 返回404错误 |
| 消息内容为空 | 返回400错误 |

---

## 4. 报告功能 (FUNC-008~009)

### 4.1 下载报告 (FUNC-008)

**功能描述**: 将分析结果生成PDF报告并下载

**输入**:
- analysis_id: 分析任务ID
- format: 格式（pdf/json）

**处理逻辑**:
1. 读取Analysis实体
2. 如format=pdf且PDF不存在，生成PDF文件
3. 返回文件流或JSON数据

**输出**: PDF文件或JSON数据

**异常处理**:
| 异常 | 处理 |
|------|------|
| 分析记录不存在 | 返回404错误 |
| PDF生成失败 | 返回500错误 |

---

### 4.2 健康检查 (FUNC-009)

**功能描述**: 检查服务健康状态

**输入**: 无

**处理逻辑**:
1. 检查数据目录可读写
2. 检查LLM服务可用性
3. 汇总服务状态

**输出**: 健康状态报告

## 6. 界面交互规格

### 6.1 会话列表交互

| 操作 | 响应 |
|------|------|
| 点击会话 | 切换到该会话，加载消息历史 |
| 点击删除 | 确认弹窗，确认后删除 |
| 点击新建 | 创建新会话，切换到新会话 |
| 列表滚动 | 加载更多历史会话 |

### 6.2 问答区域交互

| 操作 | 响应 |
|------|------|
| 点击上传 | 打开文件选择器，支持多选 |
| 输入股票代码 | 实时校验格式，回车发送 |
| 发送消息 | 显示loading，接收流式响应 |
| 查看结果 | 展开/收起详细信息 |
