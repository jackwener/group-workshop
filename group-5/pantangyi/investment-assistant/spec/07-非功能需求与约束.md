## 2. 可用性需求

### 2.1 系统可用性

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用率 | 99% | 除计划维护外 |
| 故障恢复时间 | < 5分钟 | 手动重启恢复 |
| 计划维护窗口 | 非工作时间 | 提前通知用户 |

### 2.2 容错能力

| 场景 | 容错策略 |
|------|----------|
| LLM服务不可用 | 三级降级：CoPaw → 百炼 → Demo模式 |
| 数据源超时 | 重试2次，超时后返回缓存数据或错误提示 |
| 文件上传失败 | 支持断点续传，失败可重新上传 |
| 分析任务失败 | 记录错误日志，支持重新分析 |

### 2.3 降级策略

```
┌─────────────────────────────────────────┐
│           服务降级策略                   │
├─────────────────────────────────────────┤
│ Level 0: 正常服务                        │
│   - CoPaw LLM可用                        │
│   - 数据源正常                           │
│   - 全功能可用                           │
├─────────────────────────────────────────┤
│ Level 1: 部分降级                        │
│   - CoPaw不可用，切换到百炼              │
│   - 分析质量可能略有下降                 │
│   - 核心功能可用                         │
├─────────────────────────────────────────┤
│ Level 2: 最大降级                        │
│   - 外部LLM均不可用，使用Demo模式        │
│   - 返回示例数据或静态响应               │
│   - 仅演示功能，不保证准确性             │
└─────────────────────────────────────────┘
```

## 3. 安全需求

### 3.1 数据安全

| 需求项 | 要求 | 实现方式 |
|--------|------|----------|
| 研报数据不外传 | 必须 | 本地存储，不上传云端 |
| 未公开数据不获取 | 必须 | 仅使用公开数据源 |
| 会话数据隔离 | 必须 | 按session_id隔离存储 |
| 敏感信息保护 | 必须 | 不存储用户凭证 |

### 3.2 访问控制

| 需求项 | 要求 |
|--------|------|
| 用户认证 | 基础登录验证（如需要） |
| 会话权限 | 用户只能访问自己的会话 |
| 文件访问 | 只能访问本会话上传的文件 |

### 3.3 输入安全

| 需求项 | 要求 | 实现方式 |
|--------|------|----------|
| 文件类型校验 | 仅允许PDF/Word | 白名单校验 |
| 文件大小限制 | 单文件<50MB | 服务端校验 |
| SQL注入防护 | 不适用 | JSON文件存储 |
| XSS防护 | 必须 | 输入转义输出 |

## 5. 可维护性需求

### 5.1 日志要求

| 日志类型 | 级别 | 内容 |
|----------|------|------|
| 访问日志 | INFO | 请求路径、响应时间、状态码 |
| 错误日志 | ERROR | 异常堆栈、上下文信息 |

| 监控项 | 告警阈值 |
|--------|----------|
| API错误率 | > 5% |
| 平均响应时间 | > 5秒 |
