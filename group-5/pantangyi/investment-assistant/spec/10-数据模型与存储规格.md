## 2. 实体详细定义

### 2.1 Session (会话)

**存储文件**: `data/sessions/{session_id}.json`

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| id | string | 是 | 会话唯一标识 | "sess_202504140001" |
| title | string | 是 | 会话标题 | "某公司股票分析" |
| type | string | 是 | 会话类型：report/stock/general | "stock" |
| status | string | 是 | 状态：active/archived/deleted | "active" |
| created_at | string | 是 | 创建时间 | "2025-04-14T10:30:00Z" |
| updated_at | string | 是 | 更新时间 | "2025-04-14T10:35:00Z" |
| message_count | integer | 是 | 消息数量 | 5 |

**JSON示例**:
```json
{
  "id": "sess_202504140001",
  "title": "某公司股票分析",
  "type": "stock",
  "status": "active",
  "created_at": "2025-04-14T10:30:00Z",
  "updated_at": "2025-04-14T10:35:00Z",
  "message_count": 5
}
```

---

### 2.2 Message (消息)

**存储文件**: `data/sessions/{session_id}_messages.json`

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| id | string | 是 | 消息唯一标识 | "msg_202504140001" |
| session_id | string | 是 | 所属会话ID | "sess_202504140001" |
| role | string | 是 | 角色：user/assistant/system | "user" |
| content | string | 是 | 消息内容 | "分析股票000001" |
| type | string | 是 | 类型：text/file/analysis | "text" |
| attachments | array | 否 | 附件列表 | [{"filename": "report.pdf"}] |
| timestamp | string | 是 | 时间戳 | "2025-04-14T10:30:00Z" |

**JSON示例**:
```json
{
  "messages": [
    {
      "id": "msg_202504140001",
      "session_id": "sess_202504140001",
      "role": "user",
      "content": "分析股票000001",
      "type": "text",
      "timestamp": "2025-04-14T10:30:00Z"
    },
    {
      "id": "msg_202504140002",
      "session_id": "sess_202504140001",
      "role": "assistant",
      "content": "分析报告内容...",
      "type": "analysis",
      "timestamp": "2025-04-14T10:31:00Z"
    }
  ]
}
```

### 2.3 Analysis (分析任务)

**存储文件**: `data/analysis/{analysis_id}.json`

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| id | string | 是 | 分析任务ID | "ana_202504140001" |
| session_id | string | 是 | 所属会话ID | "sess_202504140001" |
| type | string | 是 | 类型：report/stock | "stock" |
| status | string | 是 | 状态：processing/completed/failed | "completed" |
| input_data | object | 是 | 输入数据 | 见下文 |
| output_data | object | 否 | 输出数据 | 见下文 |
| accuracy | number | 否 | 准确率 | 0.92 |
| error_msg | string | 否 | 错误信息 | "" |
| created_at | string | 是 | 创建时间 | "2025-04-14T10:30:00Z" |
| completed_at | string | 否 | 完成时间 | "2025-04-14T10:35:00Z" |

**input_data (研报分析)**:
```json
{
  "files": ["report1.pdf", "report2.pdf"],
  "extract_keywords": true,
  "compare_reports": true
}
```

**input_data (股票查询)**:
```json
{
  "stock_code": "000001",
  "stock_name": "平安银行",
  "analysis_type": "full"
}
```

**JSON示例**:
```json
{
  "id": "ana_202504140001",
  "session_id": "sess_202504140001",
  "type": "stock",
  "status": "completed",
  "input_data": {
    "stock_code": "000001",
    "stock_name": "平安银行",
    "analysis_type": "full"
  },
  "output_data": {
    "stock_code": "000001",
    "stock_name": "平安银行",
    "financial_indicators": {
      "revenue": 1500000000,
      "profit": 450000000,
      "roe": 12.5
    },
    "report_summary": "多家机构给予买入评级...",
    "comprehensive_score": 85,
    "risk_level": "medium"
  },
  "accuracy": 0.92,
  "created_at": "2025-04-14T10:30:00Z",
  "completed_at": "2025-04-14T10:35:00Z"
}
```

### 2.4 Report (分析报告)

**存储文件**: `data/reports/{report_id}.json` 和 `data/reports/{report_id}.pdf`

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| id | string | 是 | 报告ID | "rpt_202504140001" |
| analysis_id | string | 是 | 关联分析ID | "ana_202504140001" |
| session_id | string | 是 | 关联会话ID | "sess_202504140001" |
| title | string | 是 | 报告标题 | "平安银行分析报告" |
| type | string | 是 | 类型：report/stock | "stock" |
| content | object | 是 | 报告内容 | 见下文 |
| file_path | string | 是 | PDF文件路径 | "reports/rpt_202504140001.pdf" |
| created_at | string | 是 | 创建时间 | "2025-04-14T10:35:00Z" |

**content (研报分析报告)**:
```json
{
  "reports": [
    {
      "filename": "report1.pdf",
      "title": "某公司2025年Q1研报",
      "summary": "公司业绩稳步增长...",
      "key_points": ["营收增长15%", "净利润提升"],
      "risk_warnings": ["市场竞争加剧"]

  "comparison": {
    "similarity": 0.75,
    "consistency": "观点基本一致"
  }
}
```

**content (股票分析报告)**:
```json
{
  "stock_code": "000001",
  "stock_name": "平安银行",
  "financial_indicators": {
    "revenue": 1500000000,
    "profit": 450000000,
    "roe": 12.5,
    "pe": 8.5,
    "pb": 1.2

}
```

## 4. 数据访问模式

### 4.1 CRUD操作

| 实体 | 创建 | 读取 | 更新 | 删除 |
|------|------|------|------|------|
| Session | 创建会话 | 查询列表/详情 | 更新标题/状态 | 删除会话 |
| Message | 发送消息 | 查询消息列表 | - | - |
| Analysis | 创建分析任务 | 查询分析结果 | 更新状态 | - |
| Report | 生成报告 | 查询/下载报告 | - | - |

### 4.2 查询模式

| 查询场景 | 实现方式 |
|----------|----------|
| 会话列表 | 读取sessions目录，按updated_at排序 |
| 会话详情 | 读取对应session_id的JSON文件 |
| 消息历史 | 读取{session_id}_messages.json |
| 分析结果 | 读取analysis/{analysis_id}.json |

## 5. 数据一致性

### 5.1 约束规则

| 规则 | 说明 |
|------|------|
| 会话删除 | 级联删除关联的消息和分析记录 |
| 分析完成 | 必须更新completed_at和status字段 |
| 报告生成 | 必须同时生成JSON元数据和PDF文件 |

### 5.2 索引设计

| 索引 | 用途 |
|------|------|
| sessions按updated_at排序 | 快速获取最近会话列表 |
| analysis按session_id索引 | 快速查询会话关联的分析 |

---

## 6. 数据安全

### 6.1 数据隔离

- 会话数据按session_id隔离存储
- 上传文件存储在独立uploads目录
- 报告文件按report_id命名，避免冲突

### 6.2 数据保护

- 研报数据本地存储，不外传
- 敏感信息（如内部数据源凭证）不存储在数据文件中
- 定期清理deleted状态的会话数据
