└─────────────────────────────────────────────────────────────────┘

│                      业务逻辑层                                  │

### 1.2 安全原则

| 原则 | 说明 |
|------|------|
| 最小权限 | 只授予必要的访问权限 |
| 纵深防御 | 多层安全控制，单点失效不影响整体 |
| 数据隔离 | 用户数据相互隔离，防止越权访问 |
| 安全审计 | 关键操作记录日志，可追溯 |

## 3. 数据安全

### 3.1 数据分类

| 数据类型 | 敏感级别 | 保护措施 |
|----------|----------|----------|
| 用户会话 | 中 | 隔离存储，访问控制 |
| 研报文件 | 高 | 本地存储，禁止外传 |
| 分析结果 | 中 | 访问控制，定期清理 |
| 股票数据 | 低 | 公开数据源 |

### 3.2 数据隔离

```
┌─────────────────────────────────────────┐
│           数据隔离模型                   │
├─────────────────────────────────────────┤
│  用户A                                  │
│   ├── sessions/sess_A001/               │
│   ├── uploads/user_A/                   │
│   └── reports/user_A/                   │
├─────────────────────────────────────────┤
│  用户B                                  │
│   ├── sessions/sess_B001/               │
│   ├── uploads/user_B/                   │
│   └── reports/user_B/                   │
└─────────────────────────────────────────┘
```

### 3.3 数据保护

| 保护措施 | 实现方式 | 适用范围 |
|----------|----------|----------|
| 本地存储 | 数据不上传云端 | 所有用户数据 |
| 文件隔离 | 按session_id分目录 | 上传文件 |
| 安全删除 | 删除时覆盖写 | 敏感文件 |
| 定期清理 | 定时任务清理deleted数据 | 废弃会话 |

## 4. 传输安全

### 4.1 传输协议

| 场景 | 协议 | 说明 |
|------|------|------|
| 开发环境 | HTTP | 本地信任网络 |
| 生产环境 | HTTPS | TLS 1.2+ |

### 4.2 安全头部

| 头部 | 值 | 说明 |
|------|-----|------|
| X-Content-Type-Options | nosniff | 防止MIME嗅探 |
| X-Frame-Options | DENY | 防止点击劫持 |
| X-XSS-Protection | 1; mode=block | XSS防护 |
| Strict-Transport-Security | max-age=31536000 | HSTS |

## 5. 输入安全

### 5.1 文件上传安全

| 检查项 | 策略 | 失败处理 |
|--------|------|----------|
| 文件类型 | 白名单：PDF/DOC/DOCX | 拒绝上传 |
| 文件大小 | 最大50MB | 拒绝上传 |
| 文件名 | 过滤特殊字符，重命名 | 自动处理 |
| 文件内容 | 病毒扫描（如需要） | 隔离处理 |

### 5.2 输入校验

| 输入项 | 校验规则 | 处理方式 |
|--------|----------|----------|
| 会话标题 | 长度<100，过滤XSS | 转义存储 |
| 股票代码 | 格式：6位数字 | 正则校验 |
| 消息内容 | 长度<5000，过滤XSS | 转义存储 |
| 分页参数 | limit<=20, offset>=0 | 边界校验 |

### 5.3 输出编码

| 场景 | 编码方式 |
|------|----------|
| HTML输出 | HTML实体编码 |
| JSON输出 | JSON转义 |
| 文件下载 | Content-Disposition |

## 6. 安全审计

### 6.1 审计日志

| 操作类型 | 记录内容 | 保留周期 |
|----------|----------|----------|
| 会话创建 | 时间、用户、IP | 90天 |
| 会话删除 | 时间、用户、会话ID | 90天 |
| 文件上传 | 时间、用户、文件名、大小 | 90天 |
| 分析执行 | 时间、用户、类型、耗时 | 90天 |
| 错误异常 | 时间、错误信息、堆栈 | 180天 |

### 6.2 日志格式

```json
{
  "timestamp": "2025-04-14T10:30:00Z",
  "level": "INFO",
  "user_id": "user_001",
  "ip": "192.168.1.1",
  "action": "session.create",
  "resource": "sess_202504140001",
  "result": "success",
  "duration_ms": 150
}
```

## 7. 异常处理

### 7.1 安全异常

| 异常类型 | 响应方式 | 日志记录 |
|----------|----------|----------|
| 未授权访问 | 401 Unauthorized | 记录警告 |
| 越权访问 | 403 Forbidden | 记录警告 |
| 资源不存在 | 404 Not Found | 不记录 |
| 请求过于频繁 | 429 Too Many Requests | 记录警告 |
| 服务器错误 | 500 Internal Error | 记录错误 |

### 7.2 错误信息脱敏

| 场景 | 生产环境响应 | 日志记录 |
|------|--------------|----------|
| 数据库错误 | "服务暂时不可用" | 完整错误 |
| 文件读取失败 | "文件处理失败" | 完整错误 |
| LLM调用失败 | "分析服务繁忙" | 完整错误 |

## 8. 安全测试

### 8.1 测试项

| 测试类型 | 测试内容 | 工具/方法 |
|----------|----------|-----------|
| 渗透测试 | SQL注入、XSS、CSRF | 手动+工具 |
| 文件上传 | 恶意文件、路径遍历 | 手动测试 |
| 权限测试 | 越权访问、水平越权 | 手动测试 |
| 依赖扫描 | 第三方库漏洞 | SCA工具 |

### 8.2 安全基线

| 检查项 | 要求 |
|--------|------|
| 无高危漏洞 | CVSS >= 7.0 必须修复 |
| 无中危漏洞 | CVSS >= 4.0 计划修复 |
| 依赖更新 | 每月检查更新 |
