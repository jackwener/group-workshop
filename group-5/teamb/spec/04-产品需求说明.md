## 1. 产品概述

### 1.1 产品定位

面向命理测算爱好者与普通用户的**多功能命理工具集合Web应用**，聚焦三类核心使用场景，为用户提供从日常参考到长期规划的个性化命理测算服务。

### 1.2 目标用户

| 用户类型 | 特征描述 | 核心需求 |
|---------|---------|---------|
| 日常参考用户 | 25-45岁，上班族，对命理有兴趣但非专业 | 每日快速查看运势，指导日常决策 |
| 事件决策用户 | 30-55岁，商务人士，面临重要决策 | 针对特定事件获取成功率参考 |
| 深度研究用户 | 28-60岁，命理爱好者，希望深入了解 | 解析自己和他人命格，了解人生基调 |

### 1.3 核心价值

- **个性化**: 区别于通用黄历，基于用户专属八字生成内容
- **场景化**: 覆盖日常参考、事件决策、长期规划三大场景
- **专业化**: 自研命理算法，支持奇门遁甲、大小六壬等传统起卦方式
- **便捷化**: Web端响应式设计，PC/移动端随时访问

### 2.3 功能详细说明

#### 2.3.1 用户注册与登录

**功能描述**: 用户通过手机号或邮箱注册账号，设置密码后登录系统。

**业务流程**:
1. 用户访问首页，点击"注册"按钮
2. 输入手机号/邮箱、验证码、密码
3. 提交注册，系统发送验证码（手机号短信/邮箱邮件）
4. 验证通过后创建账号，引导填写基础信息
5. 登录时输入账号密码，系统验证后发放JWT Token

**验收标准**:
- [ ] 支持手机号和邮箱两种注册方式
- [ ] 密码强度校验（至少8位，包含字母和数字）
- [ ] 登录失败显示明确错误提示
- [ ] Token有效期24小时，过期需重新登录

#### 2.3.2 个人档案管理

**功能描述**: 用户录入个人出生信息，系统自动计算八字并保存。

**业务流程**:
1. 用户进入"我的档案"页面
2. 输入姓名、性别、出生日期（公历）
3. 选择出生时辰（支持"不清楚时辰"选项）
4. 系统自动计算八字（年柱、月柱、日柱、时柱）
5. 用户确认并保存档案

**验收标准**:
- [ ] 支持公历日期输入，自动转农历
- [ ] 时辰选择提供12时辰选项 + "不清楚"选项
- [ ] 八字计算准确率100%
- [ ] 档案可随时修改更新

#### 2.3.3 个性化黄历日历

**功能描述**: 基于用户八字生成当日专属黄历内容。

**输出内容**:
- **适宜事项**: 3-5条当日适合开展的活动（如：签约、出行、面试）
- **不适宜事项**: 2-3条当日应避免的活动（如：动土、借贷）
- **幸运颜色**: 1-2种当日有利衣物颜色（如：红色、黄色）
- **有利方向**: 1-2个当日有利方位（如：正东、东南）

**业务流程**:
1. 用户登录后的首页默认展示今日黄历
2. 系统根据用户八字 + 当日日期计算个性化内容
3. 以卡片形式展示适宜/不适宜事项、幸运提示
4. 支持左右滑动或点击按钮查看前后日期

**验收标准**:
- [ ] 首页加载即显示今日黄历，无需额外操作
- [ ] 内容基于用户八字个性化生成，非通用黄历
- [ ] 响应式设计，移动端单列显示，PC端可多列布局
- [ ] 支持查看前后7天的黄历

#### 2.3.4 奇门遁甲起卦

**功能描述**: 依托用户当前时间+空间信息自动起卦，针对特定事项给出建议。

**业务流程**:
1. 用户进入"运势问询"功能页
2. 选择"奇门遁甲"起卦方式
3. 输入要测算的具体事项（如：今天下午的会议是否顺利？）
4. 系统自动获取当前时间和用户位置（需授权）
5. 起卦计算，显示卦象和解析结果
6. 输出"是否适合开展"和"成功率预估"

**输出内容**:
- **卦象信息**: 局数、值符、值使、九宫排盘
- **事项建议**: 明确给出"适合"或"不适合"的建议
- **成功率**: 百分比形式（如：75%）
- **详细解析**: 200-500字的解析说明

**验收标准**:
- [ ] 需要用户授权地理位置信息
- [ ] 同一用户同日仅限起卦1次（限制防滥用）
- [ ] 起卦计算时间<3秒
- [ ] 结果包含卦象可视化展示

#### 2.3.5 大小六壬起卦

**功能描述**: 用户手动输入3个数字起卦，支持单日多次测算。

**业务流程**:
1. 用户进入"运势问询"功能页
2. 选择"大小六壬"起卦方式
3. 输入要测算的具体事项
4. 手动输入3个数字（范围：1-12）
5. 系统根据数字起卦计算
6. 显示卦象和解析结果

**输出内容**: 与奇门遁甲相同

**验收标准**:
- [ ] 3个数字输入范围限制1-12
- [ ] 支持单日多次起卦（最多5次/日）
- [ ] 不同数字组合产生不同卦象结果
- [ ] 起卦计算时间<2秒

#### 2.3.6 静态命格解析

**功能描述**: 长期静态命理分析，解析个人整体人生基调。

**业务流程**:
1. 用户进入"命格解析"功能页
2. 选择"解析本人"或"解析他人"
3. 输入姓名、出生日期、出生时辰（可选）
4. 系统计算命格，生成关键词和深度解析
5. 展示解析结果

**输出内容**:
- **命格关键词**: 1-3个概括性关键词（如："高楼望月"、"龙腾四海"）
- **五行分析**: 金木水火土五行强弱分布
- **性格特征**: 200-300字性格描述
- **事业财运**: 200-300字事业和财运分析
- **感情婚姻**: 200-300字感情婚姻分析
- **健康提示**: 100-200字健康注意事项
- **运势建议**: 100-200字人生规划建议

**验收标准**:
- [ ] 支持本人和他人命格解析
- [ ] 无时辰情况下仍可解析，但标注"精度降低"
- [ ] 解析内容总字数800-1500字
- [ ] 解析结果支持保存和查看历史

## 3. UI/UX设计规范

### 3.1 设计风格

- **设计语言**: 自定义传统中式玄学设计系统
- **风格定位**: 神秘玄学感、传统文化底蕴、现代简洁交互
- **设计原则**: 
  - **文化传承** - 融入阴阳五行、八卦纹样等传统元素
  - **神秘优雅** - 深色调配合金色点缀，营造玄学氛围
  - **简洁高效** - 减少用户操作步骤，信息层次清晰
  - **响应适配** - PC/平板/移动端无缝体验

### 3.2 色彩系统

**主色调**:
- Primary: #d4a574 - 古铜金色（主要按钮、链接、强调元素）
- Secondary: #8b6f47 - 深古铜色（次要按钮、边框）
- Accent: #c23a2b - 朱砂红（重要提示、危险操作）

**状态色**:
- Success: #2ecc71 - 成功状态、确认操作
- Warning: #f39c12 - 警告提示、需要注意
- Error: #e74c3c - 错误状态、危险操作
- Info: #3498db - 信息提示、帮助说明

**中性色**:
- 页面背景: #1a0a2e - 深玄色（主背景）
- 卡片背景: #2c1e4a - 紫玄色（内容卡片）
- 文字主色: #f0e6d3 - 米白色（主要文本）
- 文字次色: #b8a99a - 浅褐色（次要文本、说明）
- 边框色: #3d2b5a - 深紫色（分割线、边框）
- 输入框背景: #251540 - 深紫黑色

**暗色主题**: 产品默认使用暗色主题，不提供亮色主题切换。

### 3.3 字体规范

**字体家族**:
- 标题字体: 'Noto Serif SC', 'Source Han Serif SC', 'STSong', serif
- 正文字体: 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif
- 等宽字体: 'SFMono-Regular', Consolas, 'Liberation Mono', monospace（代码显示）

**字号层级**:
- Display: 48px/56px - 页面大标题（如命格关键词）

**字重**:
- Regular: 400 - 正文
- Medium: 500 - 强调文本
- SemiBold: 600 - 小标题
- Bold: 700 - 大标题

- **轻度阴影** (sm): 0 2px 4px rgba(0,0,0,0.3) - 卡片hover状态
- **中度阴影** (md): 0 4px 8px rgba(0,0,0,0.4) - 浮动卡片

**页面布局**:
- 顶部导航高度: 64px
- 内容区最大宽度: 1200px
- 侧边栏宽度: 280px（仅PC端显示）

### 3.8 组件规范

**按钮**:
- 主按钮: 古铜金色背景(#d4a574)，白色文字，高度44px，圆角8px
- 次按钮: 透明背景，古铜金色边框(#d4a574)，金色文字
- 危险按钮: 朱砂红背景(#c23a2b)，白色文字
- 禁用状态: 透明度50%，光标not-allowed

**输入框**:
- 默认状态: 深紫黑背景(#251540)，紫色边框(#3d2b5a)，内边距12px 16px

- Error状态: 朱砂红边框(#c23a2b)，下方显示错误提示
- 禁用状态: 背景色#1a0a2e，光标not-allowed

**卡片**:
- 内边距: 24px
- 背景: 紫玄色(#2c1e4a)
- 边框: 1px solid #3d2b5a
- 圆角: 12px
- 阴影: 中度阴影(md)

### 3.9 动画规范

**过渡时长**:
- Fast: 150ms - hover、focus状态变化
- Normal: 250ms - 颜色、背景过渡
- Slow: 350ms - 展开、收起、弹窗动画

**缓动函数**:
- ease-in-out - 标准过渡
- ease-out - 进入动画
- ease-in - 离开动画

**动画原则**:
- 有意义的动画（增强用户体验，非装饰性）
- 快速响应用户操作
- 避免过度动画导致性能问题

### 3.10 响应式设计

**移动端优先策略**

**适配规则**:
- 小屏(<768px): 单列布局，隐藏侧边栏，底部Tab导航
- 中屏(768px-1024px): 双列布局，侧边栏可折叠
- 大屏(>1024px): 多列布局，完整功能展示

**触摸优化**:
- 最小点击区域: 44x44px
- 手势支持: 左右滑动切换日期、下拉刷新

### 3.11 可访问性(Accessibility)

- 对比度: WCAG AA标准（普通文本≥4.5:1，大文本≥3:1）
- 键盘导航: 所有交互元素可通过Tab键访问
- 屏幕阅读器: 提供ARIA标签和语义化HTML
- 焦点指示: 清晰的focus-visible样式（金色边框）
- 色盲友好: 不单独依赖颜色传达信息（配合图标和文字）

### 3.12 设计资源

- 图标库: FontAwesome 6 + 自定义SVG（八卦、阴阳等传统元素）
- 组件库: Headless UI + Tailwind CSS（无样式组件库）
- 字体资源: Google Fonts (Noto Serif SC, Noto Sans SC)

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 目标值 | 测量方式 |
|------|--------|---------|
| 首屏加载时间(FCP) | <2秒 | Lighthouse |
| 可交互时间(TTI) | <3秒 | Lighthouse |

| 复杂计算时间 | <3秒 | 前端计时 |
| 页面切换时间 | <300ms | 前端监控 |

### 4.2 可用性要求

| 指标 | 目标值 |
|------|--------|
| 服务可用性 | ≥99.9% |
| 故障恢复时间(RTO) | <5分钟 |
| 数据恢复点(RPO) | <1分钟 |

### 4.3 安全性要求

- 认证方式: JWT Token（有效期24小时）
- 密码加密: bcrypt（salt rounds 10）
- 传输加密: HTTPS (TLS 1.3)
- SQL注入防护: Prisma ORM参数化查询
- XSS防护: React自动转义 + CSP策略
- CSRF防护: SameSite Cookie + Token验证
