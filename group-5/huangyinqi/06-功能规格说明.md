## 1. 页面总体布局

> 画出你的应用的页面结构（ASCII / 手绘均可）。SPA 通常分：Header + Sidebar + Main + Input Area。

**布局结构**：

```
┌──────────────────────────────────────────┐
│  header: 标题 + [能力状态芯片] + [研报上传] │
├────────────┬─────────────────────────────┤
│  sidebar   │  main-content（三态渲染）     │
│  历史会话   │  A) 空状态                    │
│  [+新建]   │  B) 常见问题网格              │
│  session1  │  C) 对话历史列表              │
│  session2  │                              │
│            │  input-area: textarea + 发送  │
└────────────┴─────────────────────────────┘
```

**区块说明**：
- **Header**: 应用标题、能力状态芯片、研报上传按钮
- **Sidebar**: 会话列表、新建会话按钮、会话删除操作
- **Main**: 根据状态显示空状态/常见问题/对话历史
- **Input Area**: 问题输入框、发送按钮、清空按钮

## 2. Header 区域

## 3. Sidebar 会话管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表 + 默认选中第一个 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 插入列表头部 + 自动选中 |
| 删除会话 | 点击 × | `DELETE /sessions/<id>` | 确认弹窗 → 从列表移除 |
| 选中会话 | 点击会话项 | 无 | 高亮选中项 + 加载该会话记录 + Main区切换至C状态 |

**选中会话详细行为**：
1. 点击会话项时，该项高亮显示（背景色变化）
2. 调用 `GET /sessions/<id>/records` 加载该会话的问答历史
3. Main内容区切换为C状态（对话历史列表）
4. 如果该会话有关联研报，显示研报信息卡片

## 4. Main 内容区（三态渲染）

> 对齐 `05` US-002（问答提交）、US-003（历史记录）。描述三种条件下显示什么。

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | "请创建或选择一个会话开始" |
| **B 常见问题** | 有会话 && 无记录 | 显示6个常见问题卡片网格，点击后自动填入输入框并发送 |
| **C 对话历史** | 有记录 | 按时间倒序显示问答记录卡片，每条含query/answer/来源标签/时间戳 |

### 4.1 B状态 - 常见问题网格

| 卡片 | 问题内容 | 点击行为 |
|------|----------|----------|
| 问题1 | "如何分析研报中的核心观点？" | 填入输入框并触发发送 |
| 问题2 | "这只股票的评级和目标价是多少？" | 填入输入框并触发发送 |
| 问题3 | "研报中的风险提示有哪些？" | 填入输入框并触发发送 |
| 问题4 | "对比最近3份研报的观点变化" | 填入输入框并触发发送 |
| 问题5 | "这只股票的投资逻辑是什么？" | 填入输入框并触发发送 |
| 问题6 | "研报中的财务数据摘要" | 填入输入框并触发发送 |

### 4.2 C状态 - 对话历史卡片元素

每条问答记录卡片包含：

| 元素 | 类型 | 说明 |
|------|------|------|
| 用户头像 | icon | 左侧，标识用户提问 |
| query文本 | text | 用户问题原文 |
| AI头像 | icon | 左侧，标识AI回答 |
| answer文本 | text | AI回答内容，支持Markdown渲染 |
| 来源标签 | badge | 根据`answer_source`显示CoPaw/百炼/离线演示 |
| 响应时间 | text | 显示`response_time_ms`毫秒 |
| 时间戳 | text | `timestamp`格式化显示 |
| 复制按钮 | button | 复制answer内容到剪贴板 |

### 4.3 记录卡片中的来源标签逻辑

> 根据 `answer_source` 和 `llm_used` 组合显示不同标签。

| `answer_source` | `llm_used` | 显示文本 | 样式 |
|-----------------|------------|----------|------|
| `copaw` | `true` | CoPaw | 绿色/蓝色标签 |
| `bailian` | `true` | 百炼 | 绿色/蓝色标签 |
| `demo` | `false` | 离线演示 | 灰色标签 |

## 5. 输入区域

> 对齐 `05` US-002 AC（query 非空且长度 1~500）。

| 元素 | 类型 | 行为 |
|------|------|------|
| query-input | `<textarea>` | 3 行，placeholder "请输入您的问题..." |
| send-btn | `<button>` | loading 时 disabled + 文案"发送中…" |
| clear-btn | `<button>` | 清空输入框 |
| upload-report-btn | `<button>` | 打开文件选择器，支持PDF/HTML |

**输入校验逻辑**：
- 空输入时发送按钮置灰
- 输入超过500字符时显示红色提示"问题过长，请精简"
- 未选择会话时发送按钮置灰，提示"请先创建或选择会话"

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 错误提示："请输入问题" |
| `INVALID_QUERY` | 400 | 错误提示："问题过长，最多500字符" |
| `INVALID_SESSION` | 400 | 错误提示："会话不存在或已失效，请重新选择" |
| `INVALID_FILE_FORMAT` | 400 | 错误提示："仅支持PDF或HTML格式研报" |
| `FILE_TOO_LARGE` | 400 | 错误提示："文件过大，请上传小于10MB的文件" |
| `NOT_FOUND` | 404 | 错误提示："请求的资源不存在" |
| `LLM_UNAVAILABLE` | 500 | 错误提示："AI服务暂时不可用，已切换至离线演示模式" |
| `UNAUTHORIZED` | 401 | 错误提示："请先登录系统" |
