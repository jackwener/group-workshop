## 1. 页面总体布局

> 画出你的应用的页面结构（ASCII / 手绘均可）。SPA 通常分：Header + Sidebar + Main + Input Area。

**示例 — 布局结构**：

```
┌──────────────────────────────────────────┐
│  header: 标题 + [能力状态芯片]             │
├────────────┬─────────────────────────────┤
│  sidebar   │  main-content（三态渲染）     │
│  历史会话   │  A) 空状态                    │
│  [+新建]   │  B) 常见问题网格              │
│  session1  │  C) 对话历史列表              │
│  session2  │                              │
│            │  input-area: textarea + 发送  │
└────────────┴─────────────────────────────┘
```

```
┌──────────────────────────────────────────┐
│  header: 投研问答助手 IRA + [能力状态芯片]  │
├────────────┬─────────────────────────────┤
│  sidebar   │  main-content（三态渲染）     │
│  历史会话   │  A) 空状态                    │
│  [+新建]   │  B) 常见问题网格              │
│  session1  │  C) 对话历史列表              │
│  session2  │                              │
│            │  input-area: textarea + 发送  │
└────────────┴─────────────────────────────┘
```

- **header**: 显示应用标题和能力状态芯片（CoPaw/百炼/离线演示）
- **sidebar**: 会话列表，支持新建、删除、切换会话
- **main-content**: 根据状态显示空状态/常见问题/对话历史
- **input-area**: 问题输入框和发送按钮 |

## 2. Header 区域

## 3. Sidebar 会话管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表 + 默认选中第一个 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 插入列表头部 + 自动选中 |
| 删除会话 | 点击 × | `DELETE /sessions/<id>` | 确认弹窗 → 从列表移除 |
| 选中会话 | 点击会话项 | `GET /sessions/<id>/records` | 加载该会话历史记录，高亮选中项 |

## 4. Main 内容区（三态渲染）

> 对齐 `05` US-002（问答提交）、US-003（历史记录）。描述三种条件下显示什么。

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | "请创建或选择一个会话开始" |
| **B 常见问题** | 有会话 && 无记录 | 显示6个常见问题卡片（如"如何分析财报"），点击后自动填入输入框 |
| **C 对话历史** | 有记录 | 显示问答记录列表，每条包含：用户问题、AI回答、来源标签、时间戳 |

## 5. 输入区域

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 错误提示："请输入问题" |
| `INVALID_QUERY` | 400 | 错误提示："问题过长，最多500字符" |
| `SESSION_NOT_FOUND` | 404 | 错误提示："会话不存在，请刷新页面重试" |
| `UPSTREAM_ERROR` | 500 | 错误提示："服务暂时不可用，已切换至离线模式" |

## 7. 状态管理

> React `useState` Hooks，列出你的组件需要管理哪些状态。

| State 变量 | 类型 | 初始值 | 用途 |
|------------|------|--------|------|
| `sessions` | `Session[]` | `[]` | 会话列表 |
| `currentSession` | `Session\|null` | `null` | 当前选中会话 |
| `records` | `QARecord[]` | `[]` | 当前会话的问答记录 |
| `query` | `string` | `""` | 输入框内容 |
| `loading` | `boolean` | `false` | 发送中状态 |
| `error` | `string\|null` | `null` | 错误提示信息 |
| `capabilities` | `Capabilities` | `{}` | 服务能力状态 |
