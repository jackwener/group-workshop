## IRA 实例对照

### 模块信息

| 项 | IRA 实例值 |
|----|----------|
| 模块编号 | M1-IRA |
| 模块名称 | 投研问答助手（Investment Research Assistant） |
| 技术栈 | Flask + JSON + React + Vite + pytest |
| 痛点 | 信息分散、研报阅读耗时、对比困难、提取不完整 |

### US 编号实例

| US | REQ编号 | 故事 | 优先级 |
|----|---------|------|--------|
| US-001 | REQ-M1IRA-001 | 会话管理（创建/查看/删除） | P0 |
| US-002 | REQ-M1IRA-002 | 问答提交（自然语言提问） | P0 |
| US-003 | REQ-M1IRA-003 | 历史记录（回顾追溯） | P0 |
| US-004 | REQ-M1IRA-004 | 健康检查（LLM可用性） | P1 |
| US-005 | REQ-M1IRA-005 | 研报对比（指标对比） | P1 |

### AC 实例

```
US-001 会话管理:
  AC-001-01: 点击"新会话"创建新会话并返回唯一 session_id
  AC-001-02: 会话列表按时间倒序排列，显示标题和更新时间
  AC-001-03: 删除会话后系统软删除，保留审计痕迹

US-002 问答提交:
  AC-002-01: 1~500字符问题正常接收，返回 answer+answer_source+references
  AC-002-02: CoPaw→百炼自动降级，answer_source 准确标识
  AC-002-03: 所有LLM不可用时 Demo 模式兜底
  AC-002-04: 响应时间 ≤ 5s
```

### 范围边界实例

| 做 | 不做 |
|----|------|
| 会话管理 CRUD | 多租户/行级权限 |
| 研报问答 | 研报上传解析 |
| 三级降级 | 多模态问答 |
| 历史记录 | 对比可视化图表 |
| 健康检查 | 用户权限/SSO |
