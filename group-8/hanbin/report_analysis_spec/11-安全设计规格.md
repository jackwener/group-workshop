## 3. 数据安全

> 定义数据分类分级、加密策略、存储安全规范。**投研场景核心关注点**。

### 3.1 数据分类与分级

| 数据类型 | 安全等级 | 示例 | 保护措施 |
|----------|----------|------|----------|
| 研报原文 | **内部** | PDF/HTML/Word/PPT 研报文件、URL链接 | 本地存储 |
| 提取信息 | **内部** | 评级、目标价、核心观点 | 本地存储，可发送至LLM |
| 问答记录 | **内部** | 用户提问与AI回答 | 存储加密，定期清理 |
| 系统配置 | 一般 | 模型参数、界面配置 | 版本控制 |

### 3.2 加密策略

| 场景 | 加密方式 | 说明 |
|------|----------|------|
| 传输加密 | TLS 1.2+ | 外部API通信加密 |
| 存储加密 | 无（教学版） | 本地JSON存储 |
| 密钥管理 | 环境变量 `.env` | 密钥不硬编码 |

## 4. 接口安全

> 与 `09` API 规格配合，定义 API 层面的安全防护措施。

| 防护措施 | 实现方式 | 说明 |
|----------|----------|------|
| 输入校验 | 服务端白名单校验 | 所有用户输入进行类型、长度、格式校验 |
| SQL 注入防护 | N/A | 使用JSON文件存储，无SQL |
| XSS 防护 | 输出转义 | 研报内容渲染时防止脚本注入 |
| CSRF 防护 | 无 | 本地部署，暂不启用 |
| 速率限制 | 无 | 教学场景不限速 |
| 文件上传校验 | 类型白名单 + 大小限制 | 仅允许 PDF/HTML/Word/PPT或URL，限制单文件 50MB |

## 5. LLM / AI 安全

> 针对大模型集成的专项安全措施。投研场景数据敏感，需严格管控数据流向。

| 风险点 | 防护措施 | 验收标准 |
|--------|----------|----------|
| API密钥泄露 | 环境变量存储，禁止硬编码 | 代码审计无硬编码 |
| Prompt 注入攻击 | 系统 Prompt 隔离，用户输入预处理过滤 | 过滤危险关键词 |
| 模型幻觉 / 错误信息 | 回答标注来源引用，标识置信度 | 答案携带 source 标识 |
| 敏感信息泄露（模型回复） | 输出过滤层，正则匹配敏感信息并脱敏 | 敏感信息脱敏处理 |

## 6. 审计与日志

| 类型 | 威胁 | 风险等级 | 应对措施 | 负责人 |

## 8. 部署安全

> 定义部署架构中的安全要求。

- [ ] 生产/开发环境**严格隔离**，数据不互通
- [ ] 敏感配置（API Key、密码）通过环境变量注入，不入代码仓库
- [ ] 依赖包定期安全扫描（`pip audit` / `npm audit`）
- [ ] 研报文件存储目录设置适当权限（仅应用可读写）
