## 0. 视觉设计规范（南方基金风格）

> 本模块前端视觉风格与南方基金官网保持一致，传递专业、可信的金融科技形象。

| 颜色名称 | 色值 | 用途 |

## 1. 页面总体布局

> 画出你的应用的页面结构（ASCII / 手绘均可）。SPA 通常分：Header + Sidebar + Main + Input Area。

**布局结构**：

```
┌──────────────────────────────────────────┐
│  header: 标题 + [能力状态芯片]             │
├────────────┬─────────────────────────────┤
│  sidebar   │  main-content（三态渲染）     │
│  会话列表   │  A) 空状态                    │
│  [+新建]   │  B) 研报上传区                │
│  session1  │  C) 研报详情+问答区           │
│  session2  │                              │

└────────────┴─────────────────────────────┘
```

## 4. Main 内容区（南方基金风格）

> 对齐 `05` US-001（研报上传）、US-002（问答交互）。主内容区采用白色背景，卡片式布局。

### 4.0 视觉规格

| 元素 | 样式 |
|------|------|
| 背景色 | `#FFFFFF` |
| 内边距 | 24px |
| 卡片 | 白色背景，阴影 `0 2px 8px rgba(0,0,0,0.08)`，无圆角 |

### 4.1 三态渲染

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | 居中显示图标 + "请创建或选择一个会话开始"（`#888888`，14px） |
| **B 研报上传** | 有会话 && 无研报 | 上传区域：虚线边框（`#BABABA`），拖拽或点击上传，支持PDF/HTML/Word/PPT或URL |
| **C 研报详情** | 有研报 | 研报信息卡片（白色卡片）+ 问答历史列表 + 输入框 |

### 4.2 研报信息卡片（南方基金风格）

| 元素 | 显示内容 | 样式 |
|------|----------|------|
| 标题 | 提取的研报标题 | 18px，`#333333`，字重500 |
| 评级 | 买入/增持/中性/减持等 | 标签样式，背景 `#E5F8FD`，文字 `#004098` |
| 目标价 | 提取的目标价格 | 14px，`#333333` |
| 核心观点 | 提取的核心观点摘要 | 14px，`#333333`，最多3行 |
| 来源标签 | PDF/HTML/Word/PPT/URL | 12px，`#888888` |

### 4.3 问答记录卡片

| 元素 | 说明 | 样式 |
|------|------|------|
| 用户问题 | 用户输入的原文 | 背景 `#EFF4F9`，文字 `#333333`，圆角 8px |
| 系统回答 | LLM生成的回答 | 白色背景，文字 `#333333` |
| 来源标签 | 根据 `answer_source` 显示 | 标签样式：`bailian`为蓝色，`demo`为灰色 |
| 时间戳 | 问答时间 | 12px，`#888888` |

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 错误提示："请输入问题" |
| `INVALID_FILE_TYPE` | 400 | 错误提示：“仅支持PDF、HTML、Word、PPT格式或URL链接” |
| `FILE_TOO_LARGE` | 400 | 错误提示："文件大小超过50MB限制" |
| `PARSE_ERROR` | 500 | 错误提示："研报解析失败，请检查文件格式" |
