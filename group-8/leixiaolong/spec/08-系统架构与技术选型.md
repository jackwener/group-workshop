## 1. 架构总览

### 1.1 系统上下文

```

│       http://localhost:5173     │
└──────────────┬──────────────────┘
               │ HTTP  /api/v1/agent/*
               ▼
┌─────────────────────────────────┐
│     Flask Backend (WSGI)        │
│     http://localhost:5000       │
│  ┌────────────────────────────┐ │

│  │    ↓          ↓         ↓  │ │

│  └────┬──────────┬────────────┘ │
│       ▼          ▼              │
│  ┌────────┐ ┌──────────┐       │
│  │ LLM 层 │ │ 文件系统  │       │

└─────────────────────────────────┘
```

### 1.2 架构风格

> 选择架构风格时思考：教学场景需要什么样的复杂度？分层带来什么好处？

| 决策 | 选型 | 理由 |
|------|------|------|
| **前后端分离** | React SPA + Flask REST API | 教学清晰度：前端独立开发服务器 |
| **单体部署** | 前后端各一个进程 | 不引入微服务复杂度 |
| **分层架构** | Route → Agent → Storage | 替换存储引擎时上层零改动 |
| **三级降级** | CoPaw → 百炼 → Demo | 保证服务高可用，外部依赖失败时自动降级 |

## 2. 后端分层结构

> 每层写清"允许做什么、禁止做什么"。

| 层 | 文件 | 允许做 | 禁止做 |
|----|------|--------|--------|
| **Route** | `agent_bp.py` | 参数校验、HTTP 状态码、traceId | 直接读写文件、调用 LLM |
| **Agent** | `agent.py` | 降级编排、结果组装、权限验证 | 感知 HTTP 请求/响应 |
| **Provider** | `copaw_bridge.py` / `bailian_qa.py` | HTTP 调用外部 API、文件解析 | 操作本地存储 |
| **Storage** | `storage.py` | 文件 CRUD、数据校验、备份 | 调用外部 API |
| **Upload Handler** | `upload_handler.py` | 文件接收、格式校验、key_points 提取 | 直接返回给前端 |

## 3. 前端架构

| 项 | 选型 | 理由 |
|----|------|------|
| UI 框架 | React（Hooks）≥ 18 | 教学通用性最高 |
| 构建工具 | Vite ≥ 5 | 极快 HMR，零配置启动 |
| 状态管理 | `useState` + `useEffect` | 10 个 state 变量足够，不引入 Redux |
| HTTP 客户端 | `fetch` API | 浏览器原生，不引入 axios |
| **样式方案** | **CSS Modules** | **组件级隔离，避免全局污染** |
| **路由** | **React Router v6** | **支持多页面（会话/对比/设置）** |

## 4. 三级降级编排

> 对齐 `07` 1.2 降级策略。画出降级链路，标明每级的 `answer_source` 和 `llm_used`。

```
ask(query, session_id)
  ├─[1] CoPaw  → {source:"copaw",  llm:true}
  ├─[2] 百炼   → {source:"bailian",llm:true}
  └─[3] Demo   → {source:"demo",   llm:false}
```

| 提供商 | 文件 | 配置检测 | 超时 | 错误处理 |
|--------|------|----------|------|----------|
| **CoPaw** | `copaw_bridge.py` | `IRA_COPAW_*_URL` 非空 | **3s** | 返回 None 静默降级 |
| **百炼** | `bailian_qa.py` | `DASHSCOPE_API_KEY` 非空 | **5s** | 区分多类错误码 |
| **Demo** | `agent.py` | 始终可用 | 0s | 纯字符串拼接 |
| **文件解析** | `upload_handler.py` | **pdfplumber/python-docx/openpyxl** | **10s** | **返回 FILE_TOO_LARGE/UNSUPPORTED_FORMAT** |

## 5. 数据存储架构

### 5.1 存储演进路线

| 阶段 | 存储 | 变更范围 | 说明 |
|------|------|----------|------|
| **P0（当前）** | JSON 文件 | — | 适合教学，零配置 |

## 7. ADR（架构决策记录）

> 每条 ADR 记录一个"为什么选 A 而不选 B"的决策。至少写 2 条。

**示例 — ADR-001**：为什么选 Flask 而非 FastAPI？Flask 学习曲线低，无需 async/await，学员 Python 基础即可上手。

| ADR | 决策 | 核心理由 |
|-----|------|----------|
| ADR-001 | Flask 而非 FastAPI | 学习曲线低，教学更适合，无需 async/await |
| ADR-002 | JSON 文件而非 SQLite（P0） | 零配置、易调试、适合教学演示 |
| ADR-003 | React Hooks 而非 Class Components | 代码更简洁、状态管理更直观 |
| ADR-004 | 三级降级而非单一 LLM | 保证高可用，外部服务失败时自动兜底 |

## 8. 安全架构

> 对齐 `07` 4 安全需求。当前教学版与生产需求的差距。

| 层 | 当前措施 | 生产改进 |
|----|----------|----------|
| 认证 | **基于角色的权限控制** | JWT + OAuth2 |
| CORS | **限定域名白名单** | 严格白名单 + CSRF Token |
| 密钥 | 环境变量 `.env` | Vault / Secrets Manager |
| **会话隔离** | **session_id 绑定用户** | **多租户 + 行级权限** |
| **速率限制** | **100 请求/分钟** | **Redis + 滑动窗口算法** |
| **文件上传** | **临时存储 + 格式校验** | **病毒扫描 + 沙箱执行** |
