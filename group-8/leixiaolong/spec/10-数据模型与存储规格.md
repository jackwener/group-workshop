## 1. 概念模型

```
Session（会话）1 ── * QARecord（问答记录）
   │                      │
   │  session_id (PK)     │  record_id (PK)
   │  title               │  session_id (FK → Session)
   │  query_count         │  query / answer / llm_used
   │  created_at          │  response_time_ms / answer_source
   └  updated_at          └  timestamp / sources

UploadFile（上传文件）1 ── * Report（研报）
   │                           │
   │  file_id (PK)            │  report_id (PK)
   │  session_id (FK)         │  title / company / industry
   │  filename                │  publisher / publish_date
   │  file_size / file_type   │  rating / target_price / score
   └  processing_status       └  tags[]
```

> **核心关系**：
> 1. 一个 Session 可包含零到多条 QARecord（外键通过 `session_id` 逻辑引用）
> 2. 一个 UploadFile 关联到一个 Session
> 3. Report 独立存储，支持多维度检索和对比

## 2. 存储引擎

| 项 | 说明 |
|----|------|
| 引擎 | JSON 文件（`json` 标准库） |
| 编码 | UTF-8，缩进 2 空格 |
| 读写模式 | RMW（全量读入 → 修改 → 全量写回） |
| 并发安全 | 无锁，不支持并发写入 |
| 文件布局 | `{DATA_DIR}/sessions.json` + `qa_records.json` |

## 3. 实体定义 — Session

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `session_id` | `string` (UUID) | 是 | **PK** | 会话唯一标识 |
| `title` | `string` | 是 | ≤100 字符 | 默认"新会话"，首次问答自动重命名 |
| `created_at` | `string` (ISO-8601) | 是 | UTC+Z | 创建时间 |
| `updated_at` | `string` (ISO-8601) | 是 | UTC+Z | 最后更新时间 |
| `query_count` | `integer` | 是 | ≥ 0 | 累计问答次数 |

## 4. 实体定义 — QARecord

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `record_id` | `string` | 是 | **PK**，`rec_{uuid}` | 基于 UUID 生成 |
| `session_id` | `string` | 是 | **FK** → Session | 所属会话 |
| `query` | `string` | 是 | 1–500 字符 | 用户提问原文 |
| `answer` | `string` | 是 | — | LLM/Demo 返回的答案 |
| `llm_used` | `boolean` | 是 | 必须 True/False | 是否使用真实 LLM |
| `model` | `string\|null` | 是 | — | 模型标识（如未使用 LLM 则为 null） |
| `response_time_ms` | `integer` | 是 | SLO < 5000 | 响应耗时（ms） |
| `answer_source` | `string` | 是 | 枚举 | `copaw`\|`bailian`\|`demo` |
| `timestamp` | `string` (ISO-8601) | 是 | UTC+Z | 记录时间 |
| `sources` | `array[string]` | 否 | — | 引用来源列表 |

## 5. 实体定义 — UploadFile

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `file_id` | `string` | 是 | **PK** | 文件唯一标识 |
| `session_id` | `string` | 是 | **FK** → Session | 所属会话 |
| `filename` | `string` | 是 | — | 原始文件名 |
| `file_size` | `integer` | 是 | ≤10MB | 文件大小（bytes） |
| `file_type` | `string` | 是 | 枚举 | `pdf`\|`docx`\|`xlsx` |
| `upload_status` | `string` | 是 | 枚举 | `success`\|`failed` |
| `processing_status` | `string` | 是 | 枚举 | `pending`\|`processing`\|`completed` |
| `key_points` | `object\|null` | 否 | — | 提取的重点信息（rating/target_price/core_viewpoints） |
| `uploaded_at` | `string` (ISO-8601) | 是 | UTC+Z | 上传时间 |

## 6. 实体定义 — Report

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `report_id` | `string` | 是 | **PK** | 研报唯一标识 |
| `title` | `string` | 是 | — | 研报标题 |
| `company` | `string` | 是 | — | 公司名 |
| `industry` | `string` | 是 | — | 行业 |
| `publisher` | `string` | 是 | — | 发布机构 |
| `publish_date` | `string` (ISO-8601) | 是 | — | 发布日期 |
| `rating` | `string` | 是 | — | 评级（如：强于大市、买入） |
| `target_price` | `number\|null` | 否 | — | 目标价 |

## 6. 关键业务逻辑

**示例 — 首次问答自动命名**：

```python
if session["query_count"] == 1:
    session["title"] = query[:20] + ("..." if len(query) > 20 else "")
```

> **规则**：仅首次问答（query_count 从 0 → 1）触发，后续不再自动更名。

| 逻辑 | 触发条件 | 行为 |
|------|----------|------|
| 首次问答自动命名 | `query_count` 从 0 → 1 | 标题 = query 前 20 字 + `...` |
| 级联删除 | 删除 Session | 同步删除所有关联 QARecord 和 UploadFile |
| **文件处理完成** | **key_points 提取成功** | **processing_status 从 processing → completed** |
| **研报评分计算** | **新研报添加** | **根据 rating/target_price/tags 自动计算 score（0-100）** |
