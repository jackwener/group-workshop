## 2. Header 区域

> 描述 Header 包含哪些元素。重点关注能力状态芯片（对齐 `05` US-005）。

### 2.1 能力状态芯片（Capability Chips）

| 条件 | 芯片显示 | 说明 |
|------|----------|------|
| `answer_source = copaw` | CoPaw 已连接 | CoPaw LLM 服务可用 |
| `answer_source = bailian` | 百炼 · {model} | 百炼 LLM 服务可用 + 模型名 |
| `answer_source = demo` | 离线演示模式 | 未配置外部模型，降级到演示 |

### 2.2 用户权限显示

| 字段 | 显示内容 |
|------|----------|
| `user.role` | 用户角色（投研分析师/高级分析师/投资经理） |
| `user.has_permission` | 无权限时显示"暂无访问权限"并禁用操作 |

## 3. Sidebar 会话管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表，按 `updated_at` 降序，默认选中第一个 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 插入列表头部 + 自动选中 + 清空主内容区 |
| 删除会话 | 右键菜单 → 删除 | `DELETE /sessions/<id>` | 确认弹窗 → 从列表移除 + 清空主内容区 |
| 选中会话 | 点击会话项 | - | 加载该会话的问答记录（`GET /sessions/<id>/records`） |
| 切换会话 | 点击另一会话 | - | 保存当前状态 + 加载新会话记录 |

## 4. Main 内容区（三态渲染）

> 对齐 `05` US-002（问答提交）、US-003（历史记录）。描述三种条件下显示什么。

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | 居中显示"+ 新建会话"按钮，点击后自动创建会话并切换到 B 状态 |
| **B 常见问题** | 有会话 && 无记录 | 显示常见问题网格（如：行业趋势、股票推荐、研报解读），点击自动填入输入框 + 底部输入区 |
| **C 对话历史** | 有记录 | 对话卡片列表：用户提问（右）+ AI回答（左）+ 来源标签 + 时间戳 |
| **D 研报对比** | 切换到对比页面 | 研报列表（分页）+ 多维度筛选（公司/行业/发布人/时间）+ 评分标签 |

### 4.1 记录卡片中的来源标签逻辑

> 根据 `answer_source` 和 `llm_used` 组合显示不同标签。

| `answer_source` | `llm_used` | 显示文本 | 样式 |
|-----------------|------------|----------|------|
| `copaw` | `true` | CoPaw | 蓝色标签 |
| `bailian` | `true` | 百炼 | 绿色标签 |
| `demo` | `false` | 离线演示 | 灰色标签 |

### 4.2 对话卡片元素

每条记录卡片包含：
- **用户提问**：右侧气泡，显示 `query` 文本
- **AI 回答**：左侧气泡，显示 `answer` 文本
- **来源标签**：显示 `answer_source` 对应的标签
- **响应时间**：显示 `response_time_ms`（如：1.2s）
- **时间戳**：显示 `timestamp`（格式化为相对时间，如：2分钟前）
- **引用来源**：如有 `sources` 数组，显示可展开的引用列表
- **加载状态**：AI 回答生成中显示打字动画

## 5. 输入区域

> 对齐 `05` US-002 AC（query 非空且长度 1~500）。

| 元素 | 类型 | 行为 |
|------|------|------|
| query-input | `<textarea>` | 3 行，placeholder "请输入您的问题..."，支持 Ctrl+Enter 发送 |
| upload-btn | `<button>` | 上传研报文件（PDF/Word/Excel），≤10MB，调用 `POST /upload` |
| send-btn | `<button>` | loading 时 disabled + 文案"发送中…"，无会话时 disabled |
| clear-btn | `<button>` | 清空输入框内容 |
| stop-btn | `<button>` | 生成中途可暂停（US-002 AC-002-03） |

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 错误提示："请输入问题" |
| `INVALID_QUERY` | 400 | 错误提示："问题过长（最多500字符）" |
| `INVALID_SESSION_ID` | 400 | 错误提示："会话ID无效" |
| `PERMISSION_DENIED` | 403 | 全屏提示："您没有访问权限，请联系管理员" + 禁用所有操作 |
| `SESSION_NOT_FOUND` | 404 | Toast 提示："会话不存在，已自动刷新列表" + 重新加载会话列表 |
| `FILE_TOO_LARGE` | 400 | Toast 提示："文件大小超过10MB限制" |
| `UNSUPPORTED_FORMAT` | 400 | Toast 提示："仅支持PDF/Word/Excel格式" |
| `LLM_UNAVAILABLE` | 503 | 提示："AI服务暂时不可用，已切换到离线演示模式" + 自动降级 |
