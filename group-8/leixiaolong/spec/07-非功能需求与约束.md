## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| **问答端点 P95 延迟** | < **5000ms** | `response_time_ms` 字段 | 03 风险应对 |
| **文件上传处理延迟** | < **10000ms** | 从上传到返回 key_points | 04 SC-02 |
| **研报对比查询延迟** | < **2000ms** | 从请求到返回列表 | 04 SC-04 |
| **会话管理端点延迟** | < **500ms** | 服务端计时 | JSON I/O < 10ms |
| **会话列表加载延迟** | < **1000ms** | 前端渲染完成时间 | 05 US-001 |

### 1.2 降级策略

**示例 — 三级降级链**：

```
CoPawAgent.ask(query, session_id)
  ├─[1] CoPaw 桥接 → answer_source='copaw', llm_used=True
  ├─[2] 百炼 DashScope → answer_source='bailian', llm_used=True
  └─[3] 离线演示兜底 → answer_source='demo', llm_used=False
```

| 约束 | 说明 |
|------|------|
| 三级降级**不可跳级** | 必须按 CoPaw → 百炼 → Demo 顺序尝试 |
| 降级**静默执行** | 不抛异常，通过 `answer_source` 标识 |
| Demo 模式**始终可用** | 无外部依赖，纯字符串拼接 |
| **降级超时限制** | CoPaw 超时 3s、百炼超时 5s，超时自动切换下一级 |
| **降级日志记录** | 每次降级必须记录日志，包含降级原因和切换时间 |

## 2. 可用性需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | **99%**（教学环境） | 单实例 Flask，不设 HA |
| MTTR | < 5 分钟 | 重启 Flask 进程即可恢复 |
| **数据持久性** | **99.9%** | JSON 文件自动备份到 `.bak` 目录 |
| **并发用户数** | **10 用户** | 教学场景，不设负载均衡 |

## 3. 可观测性需求

### 3.1 链路追踪

| 项 | 规格 |
|----|------|
| traceId 格式 | `tr_{uuid.hex}`（32 位十六进制） |
| 注入位置 | 所有成功响应顶层 + 错误响应 `error.traceId` |
| 上游透传 | 优先复用请求头 `X-Trace-Id`，缺省时本地生成 |

### 3.2 错误码体系

| HTTP | `error.code` | 触发条件 |
|------|--------------|----------|
| 400 | `EMPTY_QUERY` | query 为空/空白/null |
| 400 | `INVALID_QUERY` | query >500 字符 |
| 400 | `INVALID_TITLE` | session title >100 字符 |
| 400 | `INVALID_SESSION_ID` | session_id 格式无效（非 UUID） |
| 400 | `INVALID_PAGE` | page < 1 |
| 400 | `INVALID_PAGE_SIZE` | page_size 不在 1-100 范围 |
| 400 | `FILE_TOO_LARGE` | 上传文件超过 10MB |
| 400 | `UNSUPPORTED_FORMAT` | 不支持的文件格式（非 pdf/docx/xlsx） |
| 403 | `PERMISSION_DENIED` | 用户无权限访问 |
| 404 | `SESSION_NOT_FOUND` | 会话不存在 |
| 503 | `LLM_UNAVAILABLE` | LLM 服务不可用（CoPaw/百炼均失败） |

## 4. 安全需求

| 项 | 当前实现 | 说明 |
|----|----------|------|
| API 认证 | **基于角色的权限控制** | 通过 user.role 字段验证访问权限 |
| CORS | **限定域名白名单** | 仅允许前端应用域名访问 |
| 速率限制 | **100 请求/分钟** | 防止滥用，超出返回 429 |
| **会话隔离** | **session_id 绑定** | 用户只能访问自己的会话 |

### 4.1 敏感数据保护

| 数据类型 | 保护方式 |
|----------|----------|
| LLM API Key | 环境变量存储（`.env`），禁止硬编码，不写入日志 |
| 用户查询 | 仅存储在本地 JSON，不传输到第三方（LLM 除外） |
| **上传文件** | **临时存储，处理完成后删除原始文件，仅保留 key_points** |
| **会话数据** | **JSON 文件权限 600，仅 owner 可读写** |
| **traceId** | **不关联用户身份，仅用于链路追踪** |

## 5. 数据约束

### 5.1 输入约束

| 约束 | 规格 | 来源 |
|------|------|------|
| `query` 最小长度 | 1 字符 | 04 R-02 |
| `query` 最大长度 | 500 字符 | 04 R-02 |
| `session_id` 必填 | 非空 UUID 格式字符串 | 04 R-01 |
| **会话标题最大长度** | **100 字符** | 04 R-05 |
| **上传文件大小限制** | **≤10MB** | 04 R-06 |
| **上传文件格式限制** | **仅 pdf/docx/xlsx** | 04 R-06 |
| **分页 page 最小值** | **≥1** | 04 R-08 |
| **分页 page_size 范围** | **1-100** | 04 R-08 |

### 5.2 类型约束

| 字段 | 类型 | 约束 |
|------|------|------|
| `llm_used` | `boolean` | 必须为 True/False，不得为字符串 |
| `answer_source` | `string` | 枚举：copaw \| bailian \| demo |
| **`session_id`** | **string** | **UUID v4 格式** |
| **`created_at`/`updated_at`** | **string** | **ISO 8601 格式（如：2024-01-15T10:30:00Z）** |
| **`response_time_ms`** | **integer** | **≥0，单位毫秒** |
| **`score`** | **number** | **0-100，研报综合评分** |
