## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| **问答端点 P95 延迟** | < **5000ms** | `response_time_ms` 字段 | `03` §5 风险-LLM降级 |
| 会话管理端点延迟 | < 500ms | 服务端计时 | `04` R-01 |
| JSON 文件读取延迟 | < 100ms | 文件 I/O 计时 | `08` §5 JSON存储 |
| JSON 文件写入延迟 | < 200ms | 文件 I/O 计时 | `08` §5 JSON存储 |
| 首屏加载时间 (FCP) | < 3s | 浏览器 FCP | `08` §3 Vite |
| 研报对比响应时间 | < 10s | AI实时解析计时 | `03` §5 风险-研报解析 |

### 1.2 降级策略

**示例 — 三级降级链**：

```
CoPawAgent.ask(query, session_id)
  ├─[1] CoPaw 桥接 → answer_source='copaw', llm_used=True
  ├─[2] 百炼 DashScope → answer_source='bailian', llm_used=True
  └─[3] 离线演示兜底 → answer_source='demo', llm_used=False
```

| 约束 | 说明 |
|------|------|
| 三级降级**不可跳级** | 必须按 CoPaw → 百炼 → Demo 顺序尝试 |
| 降级**静默执行** | 不抛异常，通过 `answer_source` 标识 |
| Demo 模式**始终可用** | 无外部依赖，纯字符串拼接 |

## 2. 可用性需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | **99%**（教学环境） | 单实例 Flask，不设 HA |
| MTTR | < 5 分钟 | 重启 Flask 进程即可恢复 |
| LLM 不可用降级 | Demo 模式自动接管 | 无需人工干预 |
| JSON 文件损坏 | 恢复备份或重建空文件 | 需手动检查 |

### 2.1 失败模式与恢复方法

| 失败模式 | 触发条件 | 恢复方法 | 来源 |
|----------|----------|----------|------|
| **CoPaw 服务不可用** | 网络超时或服务异常 | 自动降级至百炼 DashScope | `03` §5 风险-LLM降级 |
| **百炼 DashScope 不可用** | API Key 无效或配额耗尽 | 自动降级至 Demo 离线模式 | `03` §5 风险-LLM降级 |
| **当天研报未解析** | 研报数据未及时入库 | AI 实时解析响应 | `03` §5 风险-研报解析 |
| **JSON 文件损坏** | 文件格式错误或数据丢失 | 重建空文件或恢复备份 | `08` §5 存储架构 |
| **Flask 进程崩溃** | 未捕获异常或内存溢出 | 进程重启（MTTR < 5分钟） | `07` §2 MTTR |

## 3. 可观测性需求

### 3.1 链路追踪

| 项 | 规格 |
|----|------|
| traceId 格式 | `tr_{uuid.hex}`（32 位十六进制） |
| 注入位置 | 所有成功响应顶层 + 错误响应 `error.traceId` |
| 上游透传 | 优先复用请求头 `X-Trace-Id`，缺省时本地生成 |

### 3.2 错误码体系

| HTTP | `error.code` | 触发条件 | 来源 |
|------|--------------|----------|------|
| 400 | `EMPTY_QUERY` | query 为空/空白/null | `04` R-02 |
| 400 | `INVALID_QUERY` | query >500 字符 或 缺少 session_id | `04` R-02 |
| 404 | `SESSION_NOT_FOUND` | session_id 对应的会话不存在 | `05` AC-001-01 |
| 408 | `TIMEOUT_ERROR` | 请求超时（超过 SLO 阈值） | `07` §1.1 SLO |
| 429 | `RATE_LIMIT_ERROR` | 请求过于频繁（生产环境） | `08` §8 安全架构 |
| 500 | `UPSTREAM_ERROR` | Agent 编排内部异常 | `03` §5 风险 |
| 0 | `NETWORK_ERROR` | 网络连接失败 | `06` §6 错误处理 |

## 4. 安全需求

| 项 | 当前实现 | 说明 |
|----|----------|------|
| API 认证 | 无（开放访问） | Workshop 教学版 |
| CORS | 全开放 | 生产需白名单 |
| 速率限制 | 无 | 教学场景不限速 |

### 4.1 敏感数据保护

| 数据类型 | 保护方式 | 来源 |
|----------|----------|------|
| LLM API Key | 环境变量存储（`.env`），禁止硬编码 | `08` §8 安全架构 |
| 用户查询内容 | 仅存储在本地 JSON，不传输到第三方（LLM 除外） | `04` §4 R-01 |
| 会话历史记录 | 本地 JSON 文件存储，教学场景明文存储 | `05` AC-001 |
| 研报解析结果 | 本地缓存，不包含用户身份信息 | `03` §3 范围 |
| traceId 追踪日志 | 仅用于调试，不记录敏感业务数据 | `07` §3.1 链路追踪 |

## 5. 数据约束

### 5.1 输入约束

| 约束 | 规格 | 来源 |
|------|------|------|
| `query` 最小长度 | 1 字符 | `04` R-02 |
| `query` 最大长度 | 500 字符 | `04` R-02 |
| `session_id` 必填 | 非空字符串，UUID 格式 | `04` R-01 |
| 会话标题默认值 | "新会话" | `04` R-01 |
| 会话标题最大长度 | 23 字符，超出自动截断 | `05` AC-001-02 |
| 问答记录最大保存数 | 无限制（教学场景） | `08` §5 JSON存储 |
| 研报对比查询关键词 | 非空，支持股票代码/公司名 | `03` §2 提案概要 |
| 回答字段必填 | `answer`, `answer_source`, `llm_used`, `response_time_ms` | `04` R-03 |

### 5.2 类型约束

| 字段 | 类型 | 约束 | 来源 |
|------|------|------|------|
| `llm_used` | `boolean` | 必须为 True/False，不得为字符串 | `08` §4 降级编排 |
| `answer_source` | `string` | 枚举：copaw \| bailian \| demo | `08` §4 降级编排 |
| `session_id` | `string` (UUID) | 必须符合 UUID 格式，36字符 | `04` R-01 |
| `title` | `string` | 最大 23 字符，超出截断 | `04` R-01 |
| `response_time_ms` | `integer` | 非负整数，单位毫秒 | `07` §1.1 SLO |
| `query` | `string` | 1~500 字符，禁止 null/空字符串 | `04` R-02 |
| `answer` | `string` | 非空字符串，无长度限制 | `04` R-03 |
| `created_at` | `string` (ISO 8601) | 格式：YYYY-MM-DDTHH:mm:ss | `08` §5 存储架构 |
| `error.code` | `string` | 枚举：EMPTY_QUERY \| INVALID_QUERY \| UPSTREAM_ERROR | `07` §3.2 错误码 |
| `traceId` | `string` | 格式：tr_{uuid.hex}（32位十六进制） | `07` §3.1 链路追踪 |
