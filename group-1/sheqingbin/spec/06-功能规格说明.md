## 3. Sidebar 会话管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表 + 默认选中第一个 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 插入列表头部 + 自动选中 |
| 删除会话 | 点击 × | `DELETE /sessions/<id>` | 确认弹窗 → 从列表移除 |
| 选中会话 | 点击会话项 | `GET /sessions/<id>/records` | 加载对话记录并渲染到主内容区 |
| 选中会话 | 点击侧边栏会话列表中的某一项 | `GET /sessions/<id>/records` | 1. 高亮显示被选中的会话项<br>2. 调用 API 获取该会话的所有问答记录<br>3. 在主内容区渲染对话历史列表（状态C）<br>4. 如果没有记录，显示研报对比入口（状态B）<br>5. 更新 `currentSession` 状态 |

## 4. Main 内容区（三态渲染）

> 对齐 `05` US-002（问答提交）、US-003（历史记录）。描述三种条件下显示什么。

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | "请创建或选择一个会话开始" |
| **B 常见问题网格** | 有会话 && 无记录 | 显示常见问题网格：<br>- 网格布局 2x3 展示6个常见问题卡片<br>- 每个卡片包含：问题图标 + 问题标题<br>- 点击卡片自动填充到输入框并发送<br>- 底部显示"请输入问题开始问答"提示 |
| **C 对话历史** | 有记录 | 对话历史卡片列表，每条记录包含：<br>- **用户问题区**：左侧显示用户头像，右侧显示问题文本<br>- **AI回答区**：左侧显示AI头像，右侧显示答案文本<br>- **来源标签**：根据 `answer_source` 显示对应标签（见4.1节）<br>- **时间戳**：显示格式化的时间（如"10:30"）<br>- **操作按钮**：复制答案、重新生成（可选） |

### 4.2 常见问题网格

> 对齐 `05` US-005。当用户选中会话但尚无问答记录时，展示常见问题引导网格。

| 元素 | 说明 |
|------|------|
| **布局** | 2行3列网格布局，共6个问题卡片 |
| **卡片内容** | 每个卡片包含：图标 + 问题标题（最多2行） |
| **交互行为** | 点击卡片 → 自动填充问题到输入框 → 触发发送 |
| **示例问题** | "对比宁德时代Q3研报"、"分析新能源行业趋势"等 |

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 错误提示："请输入问题" |
| `INVALID_QUERY` | 400 | 错误提示："问题过长" |
| `SESSION_NOT_FOUND` | 404 | 错误提示："会话不存在或已被删除" |
| `UPSTREAM_ERROR` | 500 | 错误提示："服务暂时不可用，请稍后重试" |
| `NETWORK_ERROR` | 0 | 错误提示："网络连接失败，请检查网络设置" |
| `TIMEOUT_ERROR` | 408 | 错误提示："请求超时，请稍后重试" |
| `RATE_LIMIT_ERROR` | 429 | 错误提示："请求过于频繁，请稍后再试" |
