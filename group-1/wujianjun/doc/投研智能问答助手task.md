## 质量门禁（5 Gate）

| Gate | 阶段 | 关键阈值 | 检查方式 |
|------|------|----------|----------|
| Gate 1 | 代码准入 | PEP 8 违规 ≤ 5，单元测试 100% | `flake8`, `pytest` |
| Gate 2 | 集成准入 | 覆盖率 ≥ 80%，6 个 API 端点全通过 | `pytest --cov`, API 测试 |
| Gate 3 | 功能准出 | 15 条 AC 全部通过，Demo 模式 100% 可用 | E2E 测试 |
| Gate 4 | 性能准出 | P95 < 5000ms，内存无泄漏 | locust, 内存监控 |
| Gate 5 | 安全准出 | 0 密钥硬编码，0 高危 CVE | `bandit`, `pip audit` |
