## 1. 里程碑总览（Sprint 划分）

基于 `05` 用户故事优先级（P0/P1）和 `08` 架构设计，划分为 4 个 Sprint：

| Sprint | 周期 | 目标 | 交付物 | 成功标准 |
|--------|------|------|--------|----------|
| **S1** 基础架构 | Week 1 | 项目骨架 + Storage 层 + 三级降级框架 | 可运行的 Flask 骨架 | `GET /capabilities` 返回正确状态 |
| **S2** 核心 API | Week 2 | 6 个 API 端点全部实现 | 完整后端 API | 单元测试覆盖率 ≥ 80% |
| **S3** 前端集成 | Week 3 | React 界面 + 前后端联调 | 可交互的 Web 应用 | 3 分钟完成主路径演示 |
| **S4** 验收交付 | Week 4 | 测试补全 + 文档完善 + 演示准备 | 交付物包 | `13` 测试全部通过 |
