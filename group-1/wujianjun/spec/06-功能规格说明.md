## 1. 页面总体布局

投研智能问答助手采用 SPA 单页应用架构，布局分为四个核心区域：

```
┌──────────────────────────────────────────────────┐
│  Header: "投研智能问答助手" + [能力状态芯片]         │
├────────────┬─────────────────────────────────────┤
│  Sidebar   │  Main Content（三态渲染）            │
│  ┌────────┐│  ┌─────────────────────────────┐   │
│  │ + 新建 ││  │ A) 空状态                    │   │
│  ├────────┤│  │    "请创建或选择一个会话"     │   │
│  │ 会话1  ││  ├─────────────────────────────┤   │
│  │ 会话2  ││  │ B) 常见问题网格              │   │
│  │ 会话3  ││  │    [问题1] [问题2] [问题3]    │   │
│  │  ...   ││  ├─────────────────────────────┤   │
│  └────────┘│  │ C) 对话历史列表              │   │
│            │  │    Q: ...                    │   │
│            │  │    A: ... [来源标签]          │   │
│            │  └─────────────────────────────┘   │
│            │  ┌─────────────────────────────┐   │
│            │  │ Input: [textarea] [发送]     │   │
│            │  └─────────────────────────────┘   │
└────────────┴─────────────────────────────────────┘
```

**布局说明**：
- **Header**：固定顶部，高度 60px，包含应用标题和能力状态芯片
- **Sidebar**：固定左侧，宽度 260px，可折叠，显示会话列表
- **Main Content**：自适应宽度，根据条件三态渲染
- **Input Area**：固定底部，高度自适应，包含输入框和发送按钮

## 2. Header 区域

对齐 `05` US-004（数据安全与降级），展示当前系统能力状态。

### 2.1 能力状态芯片（Capability Chips）

| 条件 | 芯片显示 | 样式 | 说明 |
|------|----------|------|------|
| `caps.copaw_configured = true` | CoPaw 桥接 | 蓝色背景，白色文字 | CoPaw 已配置，使用企业内部 LLM |
| `caps.bailian_configured = true` | 百炼 · {model} | 绿色背景，白色文字 | 百炼已配置，显示模型名 |
| `caps.bailian_configured = false` 且 `caps.copaw_configured = false` | 离线演示 | 灰色背景，白色文字 | 未配置外部 LLM，使用 Demo 模式 |

**API 调用**：页面加载时调用 `GET /capabilities` 获取能力状态。

## 3. Sidebar 会话管理

对齐 `05` US-001（会话管理），实现会话的增删查交互。

### 3.1 会话列表

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表，按 `created_at` 倒序排列，默认选中第一个 |
| 新建会话 | 点击"+ 新建"按钮 | `POST /sessions` | 创建会话 → 插入列表头部 → 自动选中 → 清空 Main 区 |
| 删除会话 | 点击会话右侧 "×" | `DELETE /sessions/<id>` | 弹出确认弹窗 → 确认后删除 → 级联删除问答记录 |
| 选中会话 | 点击会话项 | `GET /sessions/<id>/records` | 高亮选中项 → 加载该会话的问答记录 → 切换 Main 区状态 |

### 3.2 会话项展示

每个会话项包含：
- **标题**：会话 `title` 字段，最多显示 20 字符，超出显示 "..."
- **问题数**：显示 `query_count` 条数
- **删除按钮**：鼠标悬停时显示 "×" 按钮

## 4. Main 内容区（三态渲染）

对齐 `05` US-002（研报问答）、US-003（问答历史），根据条件三态渲染。

### 4.1 状态转换逻辑

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | 居中显示 "请创建或选择一个会话开始" + 新建按钮 |
| **B 常见问题** | `currentSession !== null` && `records.length === 0` | 显示 3~6 个常见问题卡片，点击自动填充到输入框 |
| **C 对话历史** | `records.length > 0` | 滚动列表显示问答记录，最新记录在底部 |

### 4.2 常见问题网格（B 状态）

| 问题示例 | 点击行为 |
|----------|----------|
| "这份研报的核心观点是什么？" | 填充到输入框，用户可编辑后发送 |
| "目标价和评级是多少？" | 填充到输入框，用户可编辑后发送 |
| "有哪些风险提示？" | 填充到输入框，用户可编辑后发送 |

### 4.3 记录卡片展示（C 状态）

每条问答记录卡片包含：

| 元素 | 内容 | 样式 |
|------|------|------|
| 用户问题 | `query` 字段 | 右对齐，蓝色气泡背景 |
| AI 回答 | `answer` 字段 | 左对齐，灰色气泡背景 |
| 来源标签 | `answer_source` | 见下表 |
| 响应时间 | `response_time_ms` ms | 小字灰色，显示在回答下方 |
| 时间戳 | `timestamp` 格式化 | 小字灰色，显示在回答下方 |

#### 4.3.1 来源标签逻辑

对齐 `05` AC-003-03：

| `answer_source` | `llm_used` | 显示文本 | 样式 |
|-----------------|------------|----------|------|
| `copaw` | `true` | CoPaw | 蓝色背景，白色文字 |
| `bailian` | `true` | 百炼 | 绿色背景，白色文字 |
| `demo` | `false` | 离线演示 | 灰色背景，白色文字 |

## 5. 输入区域

对齐 `05` US-002 AC（query 非空且长度 1~500）。

### 5.1 输入元素

| 元素 | 类型 | 行为 |
|------|------|------|
| query-input | `<textarea>` | 3 行高度，placeholder "请输入您的问题..."，最大输入 500 字符 |
| send-btn | `<button>` | 主按钮样式，loading 时 disabled + 文案 "发送中…" |
| char-count | `<span>` | 显示当前字数/500，超过 450 字符时变红色提醒 |

### 5.2 输入校验

| 条件 | 行为 |
|------|------|
| 输入为空或空白 | 发送按钮 disabled |
| 输入 1~500 字符 | 发送按钮 enabled |
| 输入超过 500 字符 | 发送按钮 disabled，显示 "问题过长，请精简" |

### 5.3 发送流程

1. 用户点击发送按钮
2. 按钮变为 loading 状态
3. 调用 `POST /ask` API
4. 成功：清空输入框，将新记录追加到对话历史底部
5. 失败：显示错误提示，保持输入内容

## 6. 错误处理

对齐 `05` US-002 AC-002-02、AC-002-03，错误码定义见 `07` §3.2。

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | Toast 提示："请输入问题"，输入框聚焦 |
| `INVALID_QUERY` | 400 | Toast 提示："问题过长，请精简至500字以内" |
| `SESSION_NOT_FOUND` | 404 | Toast 提示："会话不存在"，刷新会话列表 |
| `UPSTREAM_ERROR` | 500 | Toast 提示："服务暂时不可用，请稍后重试" |
| 网络错误 | - | Toast 提示："网络连接失败，请检查网络" |

**Toast 样式**：红色背景，白色文字，3 秒后自动消失，显示在页面顶部。

## 7. 状态管理

使用 React `useState` Hooks 管理组件状态。

| State 变量 | 类型 | 初始值 | 用途 |
|------------|------|--------|------|
| `sessions` | `Session[]` | `[]` | 会话列表，对齐 `09` GET /sessions 响应 |
| `currentSession` | `Session\|null` | `null` | 当前选中会话 |
| `records` | `QARecord[]` | `[]` | 当前会话的问答记录，对齐 `09` GET /sessions/<id>/records 响应 |
| `capabilities` | `Capabilities\|null` | `null` | 系统能力状态，对齐 `09` GET /capabilities 响应 |
| `query` | `string` | `""` | 输入框内容，长度约束 1~500 字符 |
| `isLoading` | `boolean` | `false` | 发送请求中，控制发送按钮状态 |
| `error` | `Error\|null` | `null` | 错误信息，用于 Toast 展示 |
| `showDeleteConfirm` | `boolean` | `false` | 删除确认弹窗显示状态 |
| `deleteTargetId` | `string\|null` | `null` | 待删除的会话 ID |
| `recordsTotal` | `integer` | `0` | 当前会话的问答记录总数 |

### 7.1 TypeScript 类型定义

```typescript
interface Session {
  session_id: string;
  title: string;
  created_at: string;
  updated_at: string;
  query_count: number;
}

interface QARecord {
  id: string;
  session_id: string;
  query: string;
  answer: string;
  llm_used: boolean;
  model: string | null;
  response_time_ms: number;
  answer_source: 'copaw' | 'bailian' | 'demo';
  timestamp: string;
}

interface Capabilities {
  copaw_configured: boolean;
  bailian_configured: boolean;
  model: string | null;
}
```
