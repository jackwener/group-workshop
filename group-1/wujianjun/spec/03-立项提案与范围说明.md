## 1. 背景与问题

基于 `02` 需求采集记录（会议纪要 S-01、邮件沟通 S-02、用户访谈 S-03），梳理出以下核心痛点：

| 痛点 | 来源 | 影响程度 |
|------|------|----------|
| 研报阅读耗时：每天需阅读10+份研报，平均每份30-50页，耗时2-3小时 | S-02 邮件、S-03 访谈 | P0 |
| 关键信息提取不完整：电子版研报不知如何快速定位重点（评级、目标价、核心观点） | S-01 会议纪要、S-03 访谈 | P0 |
| 多份研报对比困难：需手动复制粘贴到Excel，效率极低 | S-01 会议纪要、S-02 邮件、S-03 访谈 | P1 |
| 股票数据查询分散：需在多个系统间切换 | S-02 邮件 | P1 |

## 2. 提案概要

在投研工作场景内交付**智能问答助手**能力，帮助分析师通过自然语言交互快速获取研报关键信息。系统采用**会话式问答**模式，支持基于研报内容的智能问答并引用原文；具备**三级降级能力**（CoPaw → 百炼 → Demo），确保在外部服务不可用时仍能提供服务；所有问答历史**自动沉淀**，支持随时回溯复盘。数据严格**内部部署**，确保投研数据不出域。

## 3. 范围边界

| 做（范围内） | 不做（范围外） |
|-------------|---------------|
| 会话管理：创建、列表、删除会话 | 多租户/行级数据权限 |
| 研报问答：基于研报内容的自然语言问答，支持引用原文 | 研报自动上传与解析（需人工导入） |
| 问答历史：自动记录问答内容，支持查看历史记录 | 舆情监控实时告警（仅支持历史查询） |
| 能力降级：CoPaw → 百炼 → Demo 三级降级 | 股票实时行情数据对接 |
| 数据安全：本地部署，数据不出域 | 移动端适配（仅Web端） |

## 4. 成功标准（可度量）

| 标准 | 度量方式 |
|------|----------|
| 主路径可走通 | 用户在 3 分钟内完成"新建会话 → 提问 → 查看历史"全链路 |
| 问答响应达标 | P95 响应时间 < 5 秒（`response_time_ms` 字段）|
| 离线可用 | 未配置外部LLM密钥时，系统自动降级为 Demo 模式并正常返回 |
| 信息提取准确率 | 评级/目标价/核心观点提取准确率 ≥ 80%（抽样评估）|

## 5. 风险（简表）

| 风险 | 影响 | 应对 |
|------|------|------|
| 外部 LLM 不可用 | 问答功能降级 | 三级降级：CoPaw → 百炼 → Demo 模式兜底 |
| 数据安全风险 | 投研敏感信息泄露 | 本地部署，数据不出域；API Key 环境变量管理 |
| 研报格式不统一 | 解析准确率下降 | 优先支持主流券商PDF格式，逐步扩展 |

## 6. 立项前置条件（Go / No-Go）

- ☐ 后端与前端可独立启动
- ☐ 演示数据目录可读写
- ☐ CoPaw 或百炼 API 密钥已申请（至少一个）
- ☐ 测试环境服务器资源已确认
