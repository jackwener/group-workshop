## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| **问答端点 P95 延迟** | < **5000ms** | `response_time_ms` 字段 | `03` §4 |
| 会话管理端点延迟 | < 500ms | 服务端计时 | JSON I/O < 10ms |
| 前端首屏加载 | < 3000ms | Lighthouse 性能指标 | SPA 资源加载 |
| JSON 文件读写延迟 | < 100ms | `os.path.getsize` 度量 | 本地文件系统 |
| API 响应序列化 | < 50ms | 后端日志计时 | JSON dumps 性能 |

### 1.2 降级策略

**示例 — 三级降级链**：

```
CoPawAgent.ask(query, session_id)
  ├─[1] CoPaw 桥接 → answer_source='copaw', llm_used=True
  ├─[2] 百炼 DashScope → answer_source='bailian', llm_used=True
  └─[3] 离线演示兜底 → answer_source='demo', llm_used=False
```

| 约束 | 说明 |
|------|------|
| 三级降级**不可跳级** | 必须按 CoPaw → 百炼 → Demo 顺序尝试 |
| 降级**静默执行** | 不抛异常，通过 `answer_source` 标识 |
| Demo 模式**始终可用** | 无外部依赖，纯字符串拼接 |

## 2. 可用性需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | **99%**（教学环境） | 单实例 Flask，不设 HA |
| MTTR | < 5 分钟 | 重启 Flask 进程即可恢复 |

### 2.1 故障模式与恢复

| 故障模式 | 影响范围 | 恢复方式 | 来源 |
|----------|----------|----------|------|
| 外部 LLM 不可用 | 问答功能降级 | 三级降级自动切换至 Demo 模式 | `03` §5 风险1 |
| API Key 配置错误 | 无法调用外部 LLM | 静默降级，返回 Demo 答案 | `04` R-04 |
| JSON 文件损坏 | 数据读取失败 | 备份文件恢复 + 重建空文件 | 运维手册 |
| Flask 进程崩溃 | 服务不可用 | 进程监控自动重启 | 部署配置 |
| 端口冲突 | 服务启动失败 | 检查端口占用，更换端口 | 部署手册 |

## 3. 可观测性需求

### 3.1 链路追踪

| 项 | 规格 |
|----|------|
| traceId 格式 | `tr_{uuid.hex}`（32 位十六进制） |
| 注入位置 | 所有成功响应顶层 + 错误响应 `error.traceId` |
| 上游透传 | 优先复用请求头 `X-Trace-Id`，缺省时本地生成 |

### 3.2 错误码体系

| HTTP | `error.code` | 触发条件 |
|------|--------------|----------|
| 400 | `EMPTY_QUERY` | query 为空/空白/null |
| 400 | `INVALID_QUERY` | query >500 字符 或 缺少 session_id |
| 404 | `SESSION_NOT_FOUND` | session_id 不存在 |
| 500 | `UPSTREAM_ERROR` | Agent 编排内部异常 |

## 4. 安全需求

| 项 | 当前实现 | 说明 |
|----|----------|------|
| API 认证 | 无（开放访问） | Workshop 教学版 |
| CORS | 全开放 | 生产需白名单 |
| 速率限制 | 无 | 教学场景不限速 |
| 数据加密 | 无（明文 JSON） | 教学版无加密，生产需 AES-256 |
| 审计日志 | 无 | 教学版不记录，生产需记录操作日志 |

### 4.1 敏感数据保护

| 数据类型 | 保护方式 |
|----------|----------|
| LLM API Key | 环境变量存储（`.env`），禁止硬编码 | `03` §5 风险2 |
| 用户查询内容 | 仅存储在本地 JSON，不传输到第三方（LLM 除外） | `04` R-07 |
| 会话历史记录 | 本地 JSON 文件存储，数据不出域 | `03` §3 数据安全 |
| QA 问答对 | 不记录用户身份信息，仅保留 query/answer | 隐私最小化 |
| 日志文件 | 禁止记录 API Key 明文，使用 `***` 脱敏 | 安全审计 |

## 5. 数据约束

### 5.1 输入约束

| 约束 | 规格 | 来源 |
|------|------|------|
| `query` 最小长度 | 1 字符 | `04` R-02 |
| `query` 最大长度 | 500 字符 | `04` R-02 |
| `session_id` 必填 | 非空字符串，UUID 格式 | `04` R-01 |
| `title` 默认值 | "新会话"（首次提问后自动更新） | `04` R-05 |
| `title` 最大长度 | 100 字符 | 存储设计 |

### 5.2 类型约束

| 字段 | 类型 | 约束 |
|------|------|------|
| `llm_used` | `boolean` | 必须为 True/False，不得为字符串 | `04` R-03 |
| `answer_source` | `string` | 枚举：copaw \| bailian \| demo | `04` R-04 |
| `response_time_ms` | `integer` | ≥ 0，P95 < 5000 | `03` §4 |
| `model` | `string\|null` | 允许为空（Demo 模式） | `04` R-03 |
| `created_at`/`updated_at` | `string` | ISO-8601 格式（UTC+Z） | 数据模型 |
| `query_count` | `integer` | ≥ 0，删除会话时级联重置 | `04` R-06 |
