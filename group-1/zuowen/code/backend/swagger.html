投研问答助手 — Swagger API 文档

版本 v1.0  |  OpenAPI 3.0  |  Base URL：/api/v1/agent

一、概述

本文档描述投研问答助手后端全部 6 个 REST API 端点，覆盖能力探测、问答提交、会话管理三大功能域。服务采用 Flask 框架，三级降级编排（CoPaw → 百炼 → Demo）。

服务地址：http://localhost:5000（开发环境）
接口前缀：/api/v1/agent
数据格式：请求体 & 响应体均为 application/json，UTF-8 编码
CORS：已启用，允许所有来源跨域访问

二、接口目录

  1. GET /capabilities — 能力探测
  2. POST /ask — 问答提交
  3. GET /sessions — 会话列表
  4. POST /sessions — 新建会话
  5. DELETE /sessions/{session_id} — 删除会话
  6. GET /sessions/{session_id}/records — 问答记录

三、通用错误格式

{
  "error": {
    "code":    "ERROR_CODE",
    "message": "可读描述",
    "details": {},
    "traceId": "tr_xxxxxxxxxxxx"
  }
}
HTTP 状态码错误 code含义
400EMPTY_QUERYquery 为空或全为空白字符
400INVALID_QUERYquery 超过 500 字符 / 缺少 session_id
400INVALID_TITLE会话标题超过 23 字符
400 / 404SESSION_NOT_FOUNDsession_id 不存在
500UPSTREAM_ERROR上游 LLM 服务异常

四、接口详情

GET/api/v1/agent/capabilities能力探测

返回当前服务已配置的 LLM 能力状态，前端据此判断是否展示「演示模式」提示。

请求参数

无

成功响应 — 200

{
  "copaw_configured":  false,
  "bailian_configured": true,
  "model":  "qwen-plus",
  "traceId": "tr_xxxxxxxxxxxx"
}
字段类型说明
copaw_configuredbooleanIRA_COPAW_CHAT_URL 是否已配置
bailian_configuredbooleanDASHSCOPE_API_KEY 是否已配置
modelstring | null当前生效模型名，未配置时为 null
traceIdstring请求追踪 ID
POST/api/v1/agent/ask问答提交

提交投研问题，系统按 CoPaw → 百炼 → Demo 三级降级编排返回答案。

请求体

{
  "query":      "茅台近期研报摘要",
  "session_id": "uuid-string"
}
字段类型必填约束说明
querystring是1–500 字符，非空用户问题
session_idstring是需为已存在会话会话 ID

成功响应 — 200

{
  "answer":          "茅台近期研报显示...",
  "llm_used":        true,
  "model":           "qwen-plus",
  "response_time_ms": 1234,
  "answer_source":   "bailian",
  "traceId":         "tr_xxxxxxxxxxxx"
}
字段类型说明
answerstring回答内容
llm_usedboolean是否使用了 LLM
modelstring | null模型名（Demo 模式为 null）
response_time_msinteger响应耗时（毫秒）
answer_sourcestring回答来源：copaw / bailian / demo
traceIdstring请求追踪 ID

错误响应

状态码code触发条件
400EMPTY_QUERYquery 为空
400INVALID_QUERYquery > 500 字符 / 缺少 session_id
400SESSION_NOT_FOUNDsession_id 不存在
500UPSTREAM_ERRORLLM 调用异常
GET/api/v1/agent/sessions会话列表

获取全部会话列表，按 updated_at 倒序排列。

请求参数

无

成功响应 — 200

{
  "traceId": "tr_xxxxxxxxxxxx",
  "sessions": [
    {
      "session_id": "uuid-string",
      "title":      "茅台近期研报摘...",
      "created_at": "2026-04-14T06:00:00Z",
      "updated_at": "2026-04-14T06:05:00Z",
      "query_count": 3
    }
  ]
}
字段类型说明
session_idstring会话唯一标识
titlestring会话标题（≤23 字符，首次问答自动命名）
created_atstring创建时间（ISO 8601 UTC）
updated_atstring最后更新时间
query_countinteger问答次数
POST/api/v1/agent/sessions新建会话

创建新的问答会话。

请求体

{
  "title": "我的投研会话"
}
字段类型必填约束说明
titlestring否≤ 23 字符会话标题，默认"新会话"

成功响应 — 201

{
  "traceId":     "tr_xxxxxxxxxxxx",
  "session_id":  "uuid-string",
  "title":       "我的投研会话",
  "created_at":  "2026-04-14T06:00:00Z",
  "query_count": 0
}

错误响应

状态码code触发条件
400INVALID_TITLE标题超过 23 字符
