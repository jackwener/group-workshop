### 1.2 架构风格

| 决策 | 选型 | 理由 |
|------|------|------|
| **前后端分离** | React SPA + Flask REST API | 前后端独立开发/部署，职责清晰 |
| **单体部署** | 前后端各一个进程 | 教学项目不引入微服务复杂度 |
| **蓝图分层** | stock_bp / finance_bp / ai_bp | 按业务域隔离，各蓝图独立维护 |
| **服务层抽象** | Service 类封装外部 API | 替换数据源时路由层零改动 |
| **Vite 代理** | /api → localhost:5000 | 开发环境避免 CORS 问题 |

## 2. 后端分层结构

| 层 | 文件 | 允许做 | 禁止做 |
|----|------|--------|--------|
| **Blueprint** | `stock_bp.py` / `finance_bp.py` / `ai_bp.py` | 参数校验、HTTP 状态码、调用 Service | 直接请求外部 API、管理会话状态 |
| **Service** | `eastmoney_service.py` / `dashscope_service.py` | 封装外部 API 调用、数据转换 | 感知 HTTP 请求/响应对象 |
| **SessionManager** | `session_manager.py` | 会话 CRUD、上下文窗口管理、自动清理 | 调用外部 API |
| **Cache** | `cache_service.py` | TTL 缓存读写 | 业务逻辑 |
| **Utils** | `finance_calc.py` | 同比/环比计算 | 任何 I/O 操作 |

## 3. 前端架构

| 项 | 选型 | 理由 |
|----|------|------|
| UI 框架 | React 18（Hooks） | 生态丰富，教学通用性高 |
| 构建工具 | Vite 5 | 极快 HMR，开发体验好 |
| 语言 | TypeScript | 类型安全，减少运行时错误 |
| 样式方案 | Tailwind CSS | 原子化 CSS，快速开发 |
| 图表库 | Recharts | 基于 React，声明式 API |
| 路由 | React Router v6 | SPA 路由标准方案 |
| HTTP 客户端 | fetch API + 封装层 | 浏览器原生，不引入额外依赖 |
| 状态管理 | useState + useEffect + Context | 状态量适中，不需要 Redux |

## 4. DashScope 集成

### 4.1 涨跌分析

```
change-analysis 端点:
  1. 获取实时行情（eastmoney_service.get_quote）
  2. 获取相关新闻（eastmoney_service.get_news）
  3. 拼接 Prompt：行情数据 + 新闻摘要
  4. 调用 DashScope qwen-plus 生成分析
  5. 返回 { analysis: string, news: array }
```

### 4.2 AI 多轮对话

```
chat 端点:
  1. 获取/创建会话（session_manager）
  2. 注入系统提示（含股票基本面摘要）
  3. 滑动窗口：取最近 20 条消息
  4. 调用 DashScope qwen-plus 多轮对话
  5. 保存消息到会话历史
  6. 返回 AI 回复
```

| 配置 | 值 | 说明 |
|------|----|------|
| 模型 | qwen-plus | 中文能力强，成本适中 |
| 滑动窗口 | 20 条消息 | 约 7K tokens，在上下文窗口内 |
| 会话超时 | 2 小时 | 不活动自动清理 |
| 系统提示 | 动态注入 | 包含当前股票的行情和基本信息 |

## 5. 数据存储架构

### 5.1 存储方案

| 数据类型 | 存储方式 | 说明 |
|----------|----------|------|
| API 缓存 | 内存 dict + TTL | cache_service.py 实现 |
| 会话数据 | 内存 dict | session_manager.py 管理 |
| 对话历史 | 内存 list (per session) | 随会话生命周期 |

### 5.2 存储演进路线

| 阶段 | 存储 | 变更范围 | 说明 |
|------|------|----------|------|
| **P0（当前）** | 内存 | — | 适合教学，重启丢失 |
| P1 | SQLite | session_manager 替换 | 持久化会话和对话 |
| P2 | PostgreSQL | 全量迁移 | 生产级存储 |

## 7. ADR（架构决策记录）

| ADR | 决策 | 核心理由 |
|-----|------|----------|
| ADR-001 | Flask 而非 FastAPI | Flask 学习曲线低，同步模型简单，教学更适合 |
| ADR-002 | 东方财富 API 而非 Tushare | 无需注册 API Key，覆盖搜索/行情/财报/概况/新闻全链路 |
| ADR-003 | DashScope 而非 OpenAI | 国内访问稳定，中文能力强，API 成本低 |
| ADR-004 | 内存存储而非 SQLite | 教学项目简化架构，避免数据库运维复杂度 |
| ADR-005 | Recharts 而非 ECharts | 基于 React，声明式 API，与技术栈一致 |
| ADR-006 | Tailwind CSS 而非 CSS Modules | 原子化样式开发效率高，深色主题配置方便 |

## 8. 安全架构

| 层 | 当前措施 | 生产改进 |
|----|----------|----------|
| 认证 | 无（开放访问） | JWT + 用户系统 |
| CORS | Flask-CORS 全开放 | 白名单限制 |
| 密钥 | 环境变量 `.env` | Vault / Secrets Manager |
| 输入校验 | Blueprint 层参数校验 | WAF + 更严格的校验 |
| LLM 安全 | 系统提示隔离 | Prompt 注入检测 + 输出过滤 |
