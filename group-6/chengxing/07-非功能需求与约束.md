## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| **股票搜索 P95 延迟** | < **1000ms** | 前端从输入到建议列表渲染 | `03` §4 |
| **行情/概况端点延迟** | < **3000ms** | 后端 API 响应时间 | `04` R-06 |
| **财务数据端点延迟** | < **5000ms** | 后端 API 响应时间（含东方财富调用） | `04` R-06 |
| **涨跌分析端点延迟** | < **15000ms** | 后端 API 响应时间（含 DashScope 调用） | `03` §4 |
| **AI 问答端点延迟** | < **30000ms** | 后端 API 响应时间（含 DashScope 多轮对话） | `04` SC-05 |

### 1.2 缓存策略

| 数据类型 | TTL | 缓存方式 | 说明 |
|----------|-----|----------|------|
| 股票搜索结果 | 5 分钟 | 内存 dict | 相同关键词短期不重复请求 |
| 实时行情 | 30 秒 | 内存 dict | 行情数据变化频繁，短 TTL |
| 季度财报 | 24 小时 | 内存 dict | 财报数据更新频率低 |
| 公司概况 | 24 小时 | 内存 dict | 公司信息变化极少 |
| 新闻数据 | 10 分钟 | 内存 dict | 新闻有时效性 |

## 2. 可用性需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | **99%**（教学环境） | 单实例 Flask + 单实例 Vite |
| MTTR | < 5 分钟 | 重启 Flask/Vite 进程即可恢复 |
| 故障恢复 | 自动降级 | 东方财富 API 不可用时返回缓存数据或错误提示 |

## 3. 可观测性需求

### 3.1 日志规范

| 项 | 规格 |
|----|------|
| 日志格式 | Python logging，`[%(asctime)s] %(levelname)s %(name)s: %(message)s` |
| 日志级别 | INFO（正常请求）、WARNING（外部 API 超时）、ERROR（异常） |
| 关键日志 | 每次东方财富 API 调用记录 URL + 耗时 + 状态码 |
| DashScope 日志 | 每次 LLM 调用记录 model + token 用量 + 耗时 |

### 3.2 错误码体系

| HTTP | 错误描述 | 触发条件 |
|------|----------|----------|
| 400 | 参数错误 | 缺少必填参数或参数格式不正确 |
| 404 | 资源不存在 | 股票代码不存在或会话 ID 无效 |
| 500 | 服务器内部错误 | 东方财富 API 异常或 DashScope 异常 |
| 504 | 网关超时 | 外部 API 调用超时 |

## 4. 安全需求

| 项 | 当前实现 | 说明 |
|----|----------|------|
| API 认证 | 无（开放访问） | 教学版不设认证 |
| CORS | Flask-CORS 全开放 | 允许 localhost:5173 跨域请求 |
| 速率限制 | 无 | 教学场景不限速 |

### 4.1 敏感数据保护

| 数据类型 | 保护方式 |
|----------|----------|
| DashScope API Key | 环境变量存储（`DASHSCOPE_API_KEY`），禁止硬编码 |
| 用户对话内容 | 仅存于内存会话，不持久化到磁盘 |
| 东方财富请求头 | 统一设置 User-Agent + Referer，不在前端暴露 |

## 5. 数据约束

### 5.1 输入约束

| 约束 | 规格 | 来源 |
|------|------|------|
| `keyword` 搜索 | 最少 1 字符，最多 50 字符 | `04` SC-01 |
| `secid` 股票代码 | 格式 `{market}.{code}`，如 `1.600519` | 东方财富 API 规范 |
| `years` 财务年限 | 1~10 正整数，默认 3 | `04` SC-02 |
| AI 消息内容 | 1~2000 字符 | `04` R-04 |
| `session_id` | 非空字符串 | `04` R-02 |

### 5.2 类型约束

| 字段 | 类型 | 约束 |
|------|------|------|
| `price` | `float` | 东方财富原始值需除以 100 |
| `changePercent` | `float` | 百分比值 |
| `revenue` / `profit` | `float` | 单位：元 |
| `yoyGrowth` | `float\|null` | 同比增长率，首期无对比时为 null |
