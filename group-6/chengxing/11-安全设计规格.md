## 1. 安全目标与合规要求

| 安全目标 | 说明 | 对应合规 |
|----------|------|----------|
| API Key 不泄露 | DashScope API Key 仅存于后端环境变量，不暴露给前端 | OWASP API Security Top 10 |
| 输入校验 | 所有用户输入在服务端严格校验，防止注入攻击 | OWASP Top 10 |
| 最小权限 | 后端仅请求必要的外部 API 数据，不请求用户无需的敏感信息 | 安全设计最佳实践 |

## 2. 认证与授权

### 2.1 认证机制

| 项目 | 规格 |
|------|------|
| 认证方式 | 无认证（教学版，开放访问） |
| 说明 | 本项目为课程作业，不涉及用户登录和权限管理 |
| 生产改进 | 应增加 JWT Token 认证 + 用户注册/登录 |

### 2.2 角色与权限矩阵

| 角色 | 股票搜索 | 查看行情 | 财务数据 | AI 问答 | 系统管理 |
|------|----------|----------|----------|---------|----------|
| 匿名用户 | ✓ | ✓ | ✓ | ✓ | ✗ |

> 教学版仅有匿名用户角色，所有功能开放。生产环境需增加分析师、管理员等角色。

## 3. 数据安全

### 3.1 数据分类与分级

| 数据类型 | 安全等级 | 示例 | 保护措施 |
|----------|----------|------|----------|
| DashScope API Key | **机密** | `sk-xxx...` | 环境变量存储，禁止硬编码，不入代码仓库 |
| 用户对话内容 | **内部** | AI 问答消息 | 仅内存存储，不持久化，进程重启即清除 |
| 股票行情数据 | **公开** | 价格、涨跌幅 | 来自东方财富公开 API，无保护要求 |
| 系统配置 | **一般** | 缓存 TTL、端口号 | 版本控制 |

### 3.2 加密策略

| 场景 | 当前实现 | 生产改进 |
|------|----------|----------|
| 传输加密 | HTTP（localhost 开发） | TLS 1.2+ 强制 HTTPS |
| 存储加密 | 无（内存存储） | 数据库层加密 |
| 密钥管理 | 环境变量 `.env` | KMS / Vault |

## 4. 接口安全

| 防护措施 | 实现方式 | 说明 |
|----------|----------|------|
| 输入校验 | Blueprint 层参数校验 | keyword/secid/message 长度和格式校验 |
| XSS 防护 | React 自动转义 + API 返回纯文本 | React JSX 默认转义 HTML |
| CORS | Flask-CORS 配置 | 开发环境全开放，生产需白名单 |
| 请求伪造防护 | 无状态 API | 无 session cookie，不需要 CSRF Token |
| 速率限制 | 无 | 教学环境不限速，生产需增加 |
| 代理层隔离 | 后端代理东方财富 API | 前端不直接请求外部 API，隐藏请求细节 |

## 5. LLM / AI 安全

| 风险点 | 防护措施 | 验收标准 |
|--------|----------|----------|
| API Key 泄露 | Key 仅存后端环境变量，前端无 Key | 前端代码和网络请求中无 Key 泄露 |
| Prompt 注入攻击 | 系统提示与用户输入分离，system role 独立 | 用户输入不能覆盖或修改系统提示 |
| 模型幻觉 | 涨跌分析注入真实行情数据和新闻 | 分析结果基于真实数据，不是纯编造 |
| 过度消费 | 滑动窗口限制 20 条消息，约 7K tokens | 单次请求 token 消耗可控 |
| 敏感信息泄露 | AI 系统提示声明投研免责 | 回复包含免责声明提示 |

## 6. 审计与日志

| 事件类型 | 记录内容 | 保留期限 | 说明 |
|----------|----------|----------|------|
| API 请求 | 端点、参数、耗时、状态码 | 运行时内存 | Flask 标准日志 |
| 东方财富调用 | URL、耗时、响应状态 | 运行时内存 | 排查外部 API 问题 |
| DashScope 调用 | 模型、token 用量、耗时 | 运行时内存 | 监控 LLM 成本 |
| 异常错误 | 堆栈跟踪、错误消息 | 运行时内存 | ERROR 级别日志 |

## 7. 安全威胁清单（STRIDE 简表）

| 类型 | 威胁 | 风险等级 | 应对措施 |
|------|------|----------|----------|
| **S**（仿冒） | 无认证，任何人可调用 API | 低（教学版） | 生产增加 JWT 认证 |
| **T**（篡改） | HTTP 明文传输可被中间人篡改 | 低（localhost） | 生产使用 HTTPS |
| **I**（信息泄露） | DashScope API Key 泄露 | **高** | 环境变量存储 + .gitignore |
| **D**（拒绝服务） | 大量并发请求耗尽内存 | 中 | 生产增加速率限制 + 会话数上限 |
| **E**（权限提升） | 无权限体系 | 低（教学版） | 生产增加 RBAC |
| **R**（抵赖） | 无操作审计日志持久化 | 低（教学版） | 生产增加持久化审计日志 |

## 8. 部署安全

- [x] DashScope API Key 通过环境变量注入（`.env` 文件），不入代码仓库
- [x] `.env` 文件已加入 `.gitignore`
- [x] 后端代理所有外部 API 请求，前端不直接访问外部服务
- [ ] 生产环境：依赖包定期安全扫描（`pip audit` / `npm audit`）
- [ ] 生产环境：生产/开发环境严格隔离
- [ ] 生产环境：启用 HTTPS + HSTS
