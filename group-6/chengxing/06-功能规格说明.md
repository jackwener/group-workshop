## 1. 路由结构

| 路径 | 组件 | 说明 |
|------|------|------|

### 2.1 SearchBar 交互

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 防抖搜索 | 输入字符后 300ms | `GET /api/v1/stock/search?keyword=` | 展示下拉建议列表 |
| 选择建议 | 点击建议项 | — | `navigate(/stock/${secid})` |
| 快速入口 | 点击标签 | — | `navigate(/stock/${secid})` 直接跳转热门股票 |
| 清空搜索 | 点击清除按钮 | — | 清空输入框 + 隐藏建议列表 |

### 3.1 PriceHeader 组件

| 字段 | 数据来源 | 展示规则 |
|------|----------|----------|
| 股票名称 | `quote.name` | 正常文本 |
| 股票代码 | `quote.code` | 灰色辅助文本 |
| 实时价格 | `quote.price` | 大字号，涨红跌绿 |
| 涨跌幅 | `quote.changePercent` | Badge 样式，正值红 + ▲，负值绿 + ▼ |
| 成交量 | `quote.volume` | 格式化（万/亿） |
| 总市值 | `quote.marketCap` | 格式化（万/亿） |

## 4. 财务数据 Tab

| 组件 | 数据来源 | 展示内容 |
|------|----------|----------|
| FinanceChart | `GET /api/v1/finance/quarterly` | Recharts 双柱图（营收 #E63946 + 净利润 #7B2FFF）+ 同比折线 |
| FinanceTable | 同上 | 表格：季度 / 营收 / 净利润 / 营收同比 / 利润同比 / 营收环比 / 利润环比 |
| GrowthBadge | 计算字段 | 正增长绿色 Badge，负增长红色 Badge |

## 5. 涨跌分析 Tab

| 组件 | 数据来源 | 展示内容 |
|------|----------|----------|
| ChangeAnalysis | `GET /api/v1/stock/change-analysis` | AI 分析卡片：结构化涨跌原因文本 |
| NewsList | 同上 response.news | 相关新闻列表：标题 + 来源 + 时间 |
| LoadingSkeleton | 请求中 | 骨架屏占位（分析通常需 5~15 秒） |

## 6. 公司概况 Tab

| 组件 | 数据来源 | 展示内容 |
|------|----------|----------|
| CompanyProfile | `GET /api/v1/stock/profile` | 基本信息卡片（行业/上市日期/注册资本/员工数）|
| 主营业务 | 同上 | 文本段落展示 |
| 公司简介 | 同上 | 文本段落展示 |

## 7. AI 问答 Tab

```
┌──────────────────────────────────────────┐
│                AI 问答 Tab                │
├────────────┬─────────────────────────────┤
│ SessionList │  ChatPanel                  │
│ [+ 新建]   │  ┌─────────────────────────┐│
│            │  │ ChatMessage (AI)         ││
│ session-1  │  │ ChatMessage (User)       ││
│ session-2  │  │ ChatMessage (AI)         ││
│ session-3  │  │ ...                      ││
│            │  └─────────────────────────┘│
│            │  ┌─────────────────────────┐│
│            │  │ ChatInput               ││
│            │  │ [输入问题...] [发送]     ││
│            │  └─────────────────────────┘│
└────────────┴─────────────────────────────┘
```

### 7.1 SessionList 交互

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | Tab 渲染 | `GET /api/v1/ai/sessions?stock_code=` | 渲染会话列表 |
| 新建会话 | 点击"+ 新建" | — | 前端创建占位会话，首次提问时后端创建 |
| 选中会话 | 点击列表项 | `GET /api/v1/ai/sessions/:id` | 加载会话历史消息 |
| 删除会话 | 点击 × | `DELETE /api/v1/ai/sessions/:id` | 从列表移除 |

### 7.2 ChatPanel 交互

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 发送消息 | 点击发送/回车 | `POST /api/v1/ai/chat` | 追加用户消息 → loading → 追加 AI 回复 |
| 消息渲染 | 收到回复 | — | 用户消息右对齐，AI 消息左对齐 + Markdown 渲染 |
| 自动滚动 | 新消息 | — | 滚动到最新消息 |

## 8. 错误处理

| 错误场景 | HTTP | 前端展示 |
|----------|------|----------|
| 搜索无结果 | 200 (空数组) | 下拉展示"无匹配结果" |
| 股票不存在 | 404 | 详情页展示"未找到该股票信息" |
| 东方财富 API 超时 | 504 | 展示"数据获取超时，请稍后重试" |
| DashScope 不可用 | 500 | 展示"AI 服务暂时不可用" |
| 网络异常 | — | 展示"网络连接异常，请检查网络" |

## 9. 状态管理

| State 变量 | 类型 | 初始值 | 用途 |
|------------|------|--------|------|
| `searchKeyword` | `string` | `""` | 搜索关键词 |
| `searchResults` | `StockItem[]` | `[]` | 搜索建议列表 |
| `stockQuote` | `StockQuote\|null` | `null` | 实时行情数据 |
| `financeData` | `FinanceQuarter[]` | `[]` | 季度财务数据 |
| `changeAnalysis` | `AnalysisResult\|null` | `null` | 涨跌分析结果 |
| `companyProfile` | `CompanyInfo\|null` | `null` | 公司概况 |
| `sessions` | `ChatSession[]` | `[]` | AI 对话会话列表 |
| `currentSession` | `ChatSession\|null` | `null` | 当前选中会话 |
| `messages` | `ChatMessage[]` | `[]` | 当前会话消息列表 |
| `activeTab` | `string` | `"finance"` | 当前选中 Tab |
