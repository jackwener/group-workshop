## 1. 概念模型

```
ChatSession（AI 对话会话）1 ── * ChatMessage（对话消息）
   │                              │
   │  id (PK, UUID)               │  role (user/assistant)
   │  title                       │  content
   │  stock_code                  │  timestamp
   │  created_at                  │
   │  last_active                 │
   │  message_count               │
   └  messages[] (内嵌)            └

CacheEntry（缓存条目）
   │  key (PK)
   │  value (any)
   │  expires_at (timestamp)
   └
```

> **核心关系**：一个 ChatSession 包含零到多条 ChatMessage。消息以 list 形式内嵌在会话对象中（内存存储，无独立实体表）。

## 2. 存储引擎

| 项 | 说明 |
|----|------|
| 引擎 | 内存 dict（Python dict） |
| 会话存储 | `{session_id: ChatSession}` dict |
| 缓存存储 | `{cache_key: CacheEntry}` dict |
| 并发安全 | 单线程 Flask 开发服务器，无并发问题 |
| 持久化 | 无，进程重启数据丢失 |

## 3. 实体定义 — ChatSession

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `id` | `string` (UUID) | 是 | **PK** | 会话唯一标识 |
| `title` | `string` | 是 | ≤50 字符 | 默认为首条消息前 20 字 |
| `stock_code` | `string` | 是 | — | 关联股票代码 |
| `created_at` | `string` (ISO-8601) | 是 | UTC | 创建时间 |
| `last_active` | `string` (ISO-8601) | 是 | UTC | 最后活跃时间 |
| `message_count` | `integer` | 是 | >= 0 | 累计消息数 |
| `messages` | `list[ChatMessage]` | 是 | — | 对话消息列表 |

## 4. 实体定义 — ChatMessage

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `role` | `string` | 是 | 枚举: `user` \| `assistant` \| `system` | 消息角色 |
| `content` | `string` | 是 | user: 1–2000 字符 | 消息内容 |
| `timestamp` | `string` (ISO-8601) | 是 | UTC | 发送时间 |

## 5. 实体定义 — CacheEntry

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `key` | `string` | 是 | **PK** | 缓存键（如 `search:贵州茅台`） |
| `value` | `any` | 是 | — | 缓存值（API 响应数据） |
| `expires_at` | `float` | 是 | Unix timestamp | 过期时间 |

## 6. Service/Manager 方法清单

### 6.1 SessionManager（会话管理）

| 方法 | 签名 | 行为 | 关联 TC |
|------|------|------|---------|
| `create_session` | `(stock_code, title?) → dict` | 创建新会话，注入系统提示 | TC-SR-013 |
| `get_sessions` | `(stock_code?) → list` | 返回会话列表（可按 stock_code 过滤） | TC-SR-014 |
| `get_session` | `(session_id) → dict` | 获取单个会话详情含消息 | TC-SR-015 |
| `delete_session` | `(session_id) → None` | 删除会话及全部消息 | TC-SR-016 |
| `add_message` | `(session_id, role, content) → None` | 追加消息 + 更新 last_active + message_count | TC-SR-017 |
| `get_context_window` | `(session_id) → list` | 返回最近 20 条消息（滑动窗口） | TC-SR-018 |
| `cleanup_expired` | `() → int` | 清理 2 小时不活跃会话，返回清理数量 | TC-SR-019 |

### 6.2 CacheService（缓存服务）

| 方法 | 签名 | 行为 | 关联 TC |
|------|------|------|---------|
| `get` | `(key) → any\|None` | 获取缓存值，过期返回 None | TC-SR-020 |
| `set` | `(key, value, ttl_seconds) → None` | 设置缓存值 + TTL | TC-SR-021 |
| `delete` | `(key) → None` | 删除缓存条目 | TC-SR-022 |

### 6.3 EastmoneyService（东方财富 API 封装）

| 方法 | 签名 | 行为 |
|------|------|------|
| `search` | `(keyword) → list[dict]` | 搜索股票，返回匹配列表 |
| `get_quote` | `(secid) → dict` | 获取实时行情 |
| `get_profile` | `(secid) → dict` | 获取公司概况 |
| `get_quarterly_finance` | `(secid, years) → list[dict]` | 获取季度财务数据 |
| `get_news` | `(keyword) → list[dict]` | 获取相关新闻 |

### 6.4 DashScopeService（DashScope 封装）

| 方法 | 签名 | 行为 |
|------|------|------|
| `chat` | `(messages, model?) → string` | 多轮对话，返回 AI 回复 |
| `analyze_change` | `(quote, news) → string` | 行情+新闻→生成涨跌分析 |

## 7. 关键业务逻辑

| 逻辑 | 触发条件 | 行为 |
|------|----------|------|
| 会话自动命名 | 首条用户消息发送时 | 标题 = message 前 20 字 + `...` |
| 系统提示注入 | 创建会话时 | 注入股票基本面摘要作为 system message |
| 滑动窗口 | 每次调用 LLM | 仅传最近 20 条消息（约 7K tokens） |
| 会话自动清理 | 每次新请求时检查 | 清理 last_active 超过 2 小时的会话 |
| 缓存 TTL | 每次 cache.get() | 检查 expires_at，过期返回 None |
| 价格转换 | 东方财富行情数据 | 原始值需除以 100 得到真实价格 |

## 8. API 响应 DTO 概要

| API 端点 | 核心 DTO 字段 | 数据来源 |
|----------|---------------|----------|
| `GET /stock/search` | results[name, code, secid, market] | eastmoney_service.search() |
| `GET /stock/quote` | name, code, price, changePercent, volume, marketCap | eastmoney_service.get_quote() |
| `GET /stock/profile` | name, industry, mainBusiness, introduction | eastmoney_service.get_profile() |
| `GET /stock/change-analysis` | analysis, news[] | dashscope_service + eastmoney_service |
| `GET /finance/quarterly` | quarters[period, revenue, profit, yoy, qoq] | eastmoney_service + finance_calc |
| `POST /ai/chat` | reply, session_id, model | dashscope_service + session_manager |
| `GET /ai/sessions` | sessions[] | session_manager.get_sessions() |
| `GET /ai/sessions/:id` | session, messages[] | session_manager.get_session() |
