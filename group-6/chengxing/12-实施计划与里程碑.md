## 5. 依赖与风险

**依赖链**：

**S1 脚手架** → **S2 数据服务**（后端 Service 就绪后蓝图可测）→ **S3 前端页面**（API 就绪后前端联调）→ **S4 AI 功能**（需 DashScope Key 配置）→ **S5 联调完善**

| 风险 | 影响 | 应对 |
|------|------|------|
| 东方财富 API 变更或限流 | 搜索/行情/财报功能中断 | TTL 缓存兜底 + 接口封装层隔离变更 |
| DashScope API Key 配额耗尽 | AI 分析和问答不可用 | 返回明确错误提示 + 降级策略预留 |
| 前端组件库选型冲突 | Recharts 与 Tailwind 样式冲突 | 独立样式隔离 |
