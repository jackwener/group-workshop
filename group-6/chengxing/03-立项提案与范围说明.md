## 1. 背景与问题

| 痛点 | 来源 |
|------|------|
| 数据分散：股票行情、财务数据、新闻资讯分布在多个网站，无统一查询入口 | 用户访谈 S-03 |
| 分析困难：普通投资者难以快速理解股票涨跌的深层原因，缺乏专业分析工具 | 会议纪要 S-01 |
| 效率低下：查看一只股票的全面信息需要在多个页面间反复切换，耗时耗力 | 用户访谈 S-03 |

## 2. 提案概要

构建一个投研分析平台（StockResearch），在单个 Web 应用内交付股票搜索、财务数据可视化、涨跌原因分析、公司概况查询和 AI 问答五项核心能力。用户输入股票名称或代码即可在一个页面内获取该股票的全维度信息，并通过 AI 进行深入交互分析。后端代理东方财富公开 API 获取数据，集成 DashScope（qwen-plus）提供 AI 分析与对话能力。

## 3. 范围边界

| 做（范围内） | 不做（范围外） |
|-------------|---------------|
| 股票搜索：防抖自动补全，快速定位 A 股股票 | 多市场支持：不支持港股、美股、期货等 |
| 财务数据：季度营收/利润 + 同比/环比 + 图表可视化 | 实时交易：不提供买卖下单功能 |
| 涨跌分析：行情 + 新闻 → DashScope 生成分析报告 | 用户认证：无登录/注册/权限体系 |
| AI 问答：多轮对话，会话管理（创建/列表/切换/删除） | 数据持久化：会话数据仅内存存储，不做数据库持久化 |

## 4. 成功标准（可度量）

| 标准 | 度量方式 |
|------|----------|
| 搜索可用 | 输入"贵州茅台"后 3 秒内展示搜索建议并可点击进入详情页 |
| 财务可视化 | 详情页"财务数据" Tab 在 5 秒内渲染 Recharts 双柱图 + 数据表格 |
| AI 分析可用 | "涨跌分析" Tab 在 15 秒内返回 DashScope 生成的分析文本 |
| 问答可用 | "AI 问答" Tab 可完成"新建会话 → 提问 → 收到回复 → 切换会话"全链路 |

## 5. 风险（简表）

| 风险 | 影响 | 应对 |
|------|------|------|
| 东方财富 API 不可用或接口变更 | 搜索/行情/财报功能中断 | TTL 缓存兜底；接口封装层隔离变更 |
| DashScope API 不可用或配额耗尽 | AI 分析和问答功能不可用 | 返回明确错误提示；后续可增加降级策略 |
| 东方财富反爬限制 | 请求被拦截返回空数据 | 统一 User-Agent/Referer 头；TTL 缓存降低请求频率 |

## 6. 立项前置条件（Go / No-Go）

- ☑ 前后端可独立启动（Vite 5173 + Flask 5000）
- ☑ 东方财富公开 API 可正常访问
- ☑ DashScope API Key 已配置（环境变量 DASHSCOPE_API_KEY）
- ☑ Vite 代理 /api → localhost:5000 配置就绪
