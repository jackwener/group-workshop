## S-01 会议纪要 — 投研分析平台产品需求讨论

| 项 | 内容 |
|---|---|
| 时间 | 2026-04-08 14:00-16:00 |
| 地点 | 线上会议 |
| 参会人员 | 程星（开发）、导师（投研部）、课程助教（技术评审） |

### 痛点记录

| 痛点 | 优先级 | 负责人 |
|------|--------|--------|
| 股票数据分散：财务数据、行情、新闻分布在多个网站，无统一查询入口 | P0 | 程星 |
| 涨跌原因不透明：散户难以快速获取专业的涨跌原因分析 | P0 | 导师 |
| 信息获取效率低：查看一只股票需要打开多个页面反复切换 | P1 | 程星 |
| 缺少 AI 辅助：无法针对具体股票进行自然语言问答 | P1 | 导师 |

### 需求记录

1. **股票搜索**：支持按名称/代码搜索股票，防抖自动补全，快速定位目标
2. **财务数据可视化**：展示季度营收/利润数据，含同比/环比指标，以图表形式呈现
3. **涨跌原因分析**：结合实时行情和新闻资讯，利用 AI 生成涨跌分析报告
4. **公司概况查询**：展示公司主营业务、行业分类、公司简介等基本信息
5. **AI 问答**：基于股票上下文的多轮对话，支持会话管理

### 下一步行动

- ☑ 技术方案评估：确定 React + Flask + 东方财富 API + DashScope 技术栈
- ☑ 产品设计：双页面（首页搜索 + 详情页 4 Tab）交互设计
- ☑ API 设计：9 个后端端点规格定义

## S-02 邮件沟通 — 关于投研分析平台的数据源选择

| 项 | 内容 |
|---|---|
| 发件人 | 程星 <chengxing@student.edu> |
| 收件人 | 导师 <tutor@ira.edu> |
| 时间 | 2026-04-10 09:30 |

**问题1 — 数据源选择：** 比较了多个免费股票数据 API（Tushare、AKShare、东方财富），最终选择东方财富公开 API，原因：覆盖搜索/行情/财报/概况/新闻全链路，且无需注册 API Key，适合教学项目。

**问题2 — AI 模型选择：** 考虑了 OpenAI、智谱、DashScope 三个方案。选择 DashScope（qwen-plus），原因：国内访问稳定，API 成本低，中文能力强，适合投研场景。

**问题3 — 前端交互设计：** 详情页拟采用 4 Tab 布局（财务数据/涨跌分析/公司概况/AI 问答），顶部固定价格行情头部，用户可在不同维度间快速切换。

## S-03 用户访谈 — 个人投资者

| 项 | 内容 |
|---|---|
| 访谈对象 | 张同学（业余股票投资者） |
| 访谈人 | 程星 |
| 时间 | 2026-04-12 10:00-11:00 |
| 方式 | 线上访谈 |

| 问题 | 回答要点 |
|------|----------|
| Q1：平时研究股票最耗时的环节？ | 查数据最耗时。看一只股票要打开东方财富、同花顺、雪球好几个网站对比。 |
| Q2：最想看到哪些信息？ | ①实时价格和涨跌幅 → ②季度财报数据趋势 → ③为什么涨/跌的原因分析 |
| Q3：对 AI 分析股票的看法？ | 感兴趣，但希望能结合真实数据和新闻，不是纯 AI 编造。**必须有数据支撑。** |
| Q4：希望有什么样的交互体验？ | 搜索后一个页面看完所有信息，不用来回跳转。最好能直接问 AI 问题。 |

**总结：** ①统一入口 + 多维度数据整合为核心诉求 ②AI 分析需有数据支撑 ③一站式体验，减少页面跳转
