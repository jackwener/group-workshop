## 3. Sidebar 会话管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表 + 默认选中第一个 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 插入列表头部 + 自动选中 |
| 删除会话 | 点击 × | `DELETE /sessions/<id>` | 确认弹窗 → 从列表移除 |
| 选中会话 | 点击会话项 | `GET /sessions/<id>/records` | 1. 高亮当前选中项，取消其余高亮<br>2. 设置 `currentSession` 为该会话对象<br>3. 设置 `recordsLoading = true`，Main 区显示加载骨架屏<br>4. 调用 `GET /sessions/<id>/records` 获取问答记录<br>5. 成功后将 `records` 写入状态，`recordsLoading = false`<br>6. 若 `records.length === 0`，显示常见问题网格（B 状态）<br>7. 若 `records.length > 0`，显示对话历史卡片列表（C 状态）<br>8. 失败时显示错误提示，保留之前的 Main 内容不变 |

## 4. Main 内容区（三态渲染）

> 对齐 `05` US-002（问答提交）、US-003（历史记录）。描述三种条件下显示什么。

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `currentSession === null` | "请创建或选择一个会话开始" |
| **B 常见问题** | 有会话 && 无记录 | **网格布局**：3×2 卡片网格（响应式：移动端 1 列）<br>**卡片内容**（6 个热点问题）：<br>• "最近一周热门研报有哪些？"<br>• "某公司的最新评级和目标价是多少？"<br>• "对比两家公司的研报分析"<br>• "查看某行业的最新动态"<br>• "某股票的近期研报摘要"<br>• "研报中的关键财务指标解读"<br>**交互行为**：<br>1. hover 时卡片边框高亮<br>2. 点击卡片 → 自动填充 query 状态<br>3. 自动触发 `POST /ask`（同 §5 发送逻辑）<br>4. 发送成功后 Main 区切换到 C 状态 |
| **C 对话历史** | 有记录 | **列表布局**：垂直卡片列表，按 `timestamp` 正序排列（旧→新）<br>**每条记录卡片包含**：<br>• **问题气泡**（右侧）：用户提问原文 `query`<br>• **答案气泡**（左侧）：AI 回复内容 `answer`<br>• **来源标签**：根据 `answer_source` + `llm_used` 显示（见 §4.1）<br>• **时间戳**：格式化为 "HH:mm" 或 "MM-DD HH:mm"（`timestamp` 字段）<br>• **响应耗时**：`response_time_ms` + "ms"，灰色小字<br>• **模型标识**：`model` 非 null 时显示，灰色小字<br>**滚动行为**：新增记录后自动滚动到底部 |

### 4.1 记录卡片中的来源标签逻辑

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | Toast 提示："请输入问题"，输入框获得焦点 |
| `INVALID_QUERY` | 400 | Toast 提示："问题过长，请控制在 500 字符以内"，显示当前字符数 |
| `MISSING_SESSION_ID` | 400 | Toast 提示："请先选择或创建一个会话"，自动打开 Sidebar |
| `SESSION_NOT_FOUND` | 404 | Toast 提示："会话不存在，请重新选择"，刷新会话列表 |
| `INVALID_SESSION_TITLE` | 400 | Toast 提示："会话标题过长，请控制在 100 字符以内" |
| `INVALID_SEARCH_PARAM` | 400 | Toast 提示："搜索条件无效，请检查筛选参数" |
| `UPSTREAM_ERROR` | 500 | Toast 提示："服务器内部错误，请稍后重试"，记录 traceId 到控制台 |
| `NETWORK_ERROR` | 0/无网络 | 全局横幅提示："网络连接失败，请检查网络后重试" |
| `TIMEOUT_ERROR` | 408/504 | Toast 提示："请求超时，请稍后重试" |
| `RATE_LIMIT` | 429 | Toast 提示："请求过于频繁，请稍后再试" |
