## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| **问答端点 P95 延迟** | < **5000ms** | `response_time_ms` 字段 | `03` §4 |
| 会话管理端点延迟 | < 500ms | 服务端计时 | JSON I/O < 10ms |
| **关键信息提取延迟** | **< 3000ms** | **服务端计时** | `03` §4 |
| **页面加载延迟** | < **2000ms** | 浏览器 Performance API | `05` AC-001-02 |
| **研报列表查询延迟** | < **1000ms** | 服务端计时 | `05` AC-002-01 |
| **新闻推送延迟** | < **1000ms** | 服务端计时 | `05` AC-003-02 |
| **JSON 文件读写延迟** | < **100ms** | 服务端计时 | 本地存储约束 |
| **研报数据落库延迟** | < **3000ms** | 服务端计时 | `03` §4 |

### 1.2 降级策略

**示例 — 三级降级链**：

```
CoPawAgent.ask(query, session_id)
  ├─[1] CoPaw 桥接 → answer_source='copaw', llm_used=True
  ├─[2] 百炼 DashScope → answer_source='bailian', llm_used=True
  └─[3] 离线演示兜底 → answer_source='demo', llm_used=False
```

| 约束 | 说明 |
|------|------|
| 三级降级**不可跳级** | 必须按 CoPaw → 百炼 → Demo 顺序尝试 |
| 降级**静默执行** | 不抛异常，通过 `answer_source` 标识 |
| Demo 模式**始终可用** | 无外部依赖，纯字符串拼接 |

## 2. 可用性需求

### 2.1 可用性指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | **99%**（教学环境） | 单实例 Flask，不设 HA |
| MTTR | < 5 分钟 | 重启 Flask 进程即可恢复 |
| **外部资讯系统故障** | **从本地缓存获取** | `03` §5 |

### 2.2 故障模式与恢复方式

| 故障模式 | 影响范围 | 恢复方式 | 来源 |
|----------|----------|----------|------|
| **外部 LLM 服务不可用** | 问答功能降级 | 自动切换至百炼 → Demo 模式兜底 | `03` §5 |
| **研报数据源不可用** | 研报获取功能中断 | 从本地缓存获取历史研报数据 | `03` §5 |
| **新闻公告数据源不可用** | 新闻推送功能中断 | 提示用户数据源异常，保留本地历史数据 | `03` §5 |
| **Flask 进程崩溃** | 全服务中断 | 手动重启 Flask 进程，MTTR < 5 分钟 | `03` §5 |
| **JSON 文件损坏** | 会话/历史数据丢失 | 从备份恢复或重置数据文件 | `04` R-02 |
| **数据库连接失败** | 数据持久化失败 | 降级至内存存储，记录日志待恢复后同步 | `04` R-01 |

## 3. 可观测性需求

### 3.1 链路追踪

| 项 | 规格 |
|----|------|
| traceId 格式 | `tr_{uuid.hex}`（32 位十六进制） |
| 注入位置 | 所有成功响应顶层 + 错误响应 `error.traceId` |
| 上游透传 | 优先复用请求头 `X-Trace-Id`，缺省时本地生成 |

### 3.2 错误码体系

| HTTP | `error.code` | 触发条件 |
|------|--------------|----------|
| 400 | `EMPTY_QUERY` | query 为空/空白/null |
| 400 | `INVALID_QUERY` | query >500 字符 或 缺少 session_id |
| 500 | `UPSTREAM_ERROR` | Agent 编排内部异常 |

## 4. 安全需求

| 项 | 当前实现 | 说明 |
|----|----------|------|
| API 认证 | 无（开放访问） | Workshop 教学版 |
| CORS | 全开放 | 生产需白名单 |
| 速率限制 | 无 | 教学场景不限速 |

### 4.1 敏感数据保护

| 数据类型 | 保护方式 | 来源 |
|----------|----------|------|
| LLM API Key | 环境变量存储（`.env`），禁止硬编码 | `04` R-01 |
| 用户查询 | 仅存储在本地 JSON，不传输到第三方（LLM 除外） | `04` R-02 |
| **研报内容** | **本地存储，不缓存敏感信息** | `03` §3 |
| **用户会话数据** | **本地 JSON 文件存储，定期备份** | `04` R-01 |
| **股票代码及搜索条件** | **本地存储，不对外传输** | `04` R-02 |
| **新闻公告关键词** | **本地分析存储，原始内容不缓存** | `03` §3 |
| **系统日志** | **脱敏处理，不包含用户敏感查询内容** | `04` R-02 |

## 5. 数据约束

### 5.1 输入约束

| 约束 | 规格 | 来源 |
|------|------|------|
| `query` 最小长度 | 1 字符 | `04` R-02 |
| `query` 最大长度 | 500 字符 | `04` R-02 |
| `session_id` 必填 | 非空字符串 | `04` R-01 |
| **会话标题默认值** | **"新会话"** | **03 功能对齐** |

### 5.2 类型约束

| 字段 | 类型 | 约束 |
|------|------|------|
| `llm_used` | `boolean` | 必须为 True/False，不得为字符串 |
| `answer_source` | `string` | 枚举：copaw \| bailian \| demo |
| **股票代码格式** | **string** | **6位数字或字母组合** |
