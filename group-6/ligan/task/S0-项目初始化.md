## T-001 后端项目初始化

**对齐**：`08` §1 架构总览 · `08` §6 部署架构

```
backend/
├── app.py                  # Flask 入口
├── agent.py                # Agent 编排（空壳）

├── bailian_qa.py           # 百炼集成（空壳）
```

### 步骤

- [ ] 1. 创建 `backend/` 目录结构（如上）
- [ ] 2. 编写 `requirements.txt`：
  ```

  flask-cors
  python-dotenv
  dashscope
  pytest
  ```
- [ ] 3. 编写 `app.py` Flask 入口：
  - 加载 `.env`
  - 注册 Blueprint（`agent_bp`）
  - 启用 CORS（全开放，对齐 `08` §8）
  - 端口 **5000**
- [ ] 4. 创建 `blueprints/agent_bp.py` 空壳：注册 Blueprint `agent_bp`，url_prefix=`/api/v1/agent`
- [ ] 5. 创建 `storage.py` 空壳：`Storage` 类，`__init__` 中创建 `data/` 目录
- [ ] 6. 创建 `agent.py` 空壳：`CoPawAgent` 类骨架
- [ ] 7. 创建 `.env.example`：
  ```
  DASHSCOPE_API_KEY=
  IRA_COPAW_CHAT_URL=
  IRA_COPAW_SESSION_URL=
  ```
- [ ] 8. 创建 `data/sessions.json` 和 `data/qa_records.json`（初始为 `[]`）

### DoD（完成定义）

- [ ] `python -m flask --app app run --port 5000` 可启动
- [ ] `GET /api/v1/agent/capabilities` 返回 200（哪怕是空 JSON）
- [ ] `pip install -r requirements.txt` 无报错

## T-002 前端项目初始化

**对齐**：`08` §3 前端架构

### 步骤

- [ ] 1. 使用 Vite 创建 React 项目：`npm create vite@latest frontend -- --template react`
- [ ] 2. 安装依赖：`cd frontend && npm install`
- [ ] 3. 配置 `vite.config.js` 代理：
  ```js
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:5000',
        changeOrigin: true
      }
    }
  }
  ```
- [ ] 4. 创建 `src/api.js` 空壳：封装 fetch 函数，Base URL = `/api/v1/agent`
- [ ] 5. 清理默认模板，`App.jsx` 保留空壳
- [ ] 6. 创建 `src/App.css` 基础布局样式

### DoD

- [ ] `npm run dev` 可启动，浏览器访问 `http://localhost:5173` 显示页面
- [ ] 前端请求 `/api/v1/agent/capabilities` 可通过 Vite proxy 转发到后端

## T-003 traceId 工具函数

**对齐**：`09` §2 统一响应规范 · `07` §3.1 链路追踪

### 步骤

- [ ] 1. 在 `agent_bp.py` 或单独 `utils.py` 中实现：
  ```python
  def generate_trace_id():
      return f"tr_{uuid.uuid4().hex}"
  
  def get_trace_id(request):
      return request.headers.get("X-Trace-Id") or generate_trace_id()
  ```
- [ ] 2. 实现统一成功响应辅助函数：`_ok(data, trace_id, status=200)`
- [ ] 3. 实现统一错误响应辅助函数：`_error(code, message, details, trace_id, http_status)`

### DoD

- [ ] traceId 格式为 `tr_{32位hex}`
- [ ] 所有成功响应顶层含 `traceId`
- [ ] 所有错误响应含 `error.traceId`
