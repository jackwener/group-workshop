  - 若 `data_dir` 不存在，自动创建
  - 初始化 `sessions.json` 和 `qa_records.json`（不存在则写入 `[]`）
  - 关联 TC：**TC-M01-040**

- [ ] 2. 实现 `create_session(self, session_id: str, title: str = "新会话") → dict`：
  - 校验 title ≤ 100 字符（否则抛异常，对齐 `09` §8 INVALID_SESSION_TITLE）
  - 构造 Session dict：`session_id`, `title`, `created_at`(ISO-8601 UTC), `updated_at`, `query_count=0`
  - 读入 sessions.json → 追加 → 写回（RMW 模式）
  - 关联 TC：**TC-M01-041**

- [ ] 3. 实现 `get_sessions(self) → list`：
  - 读取 sessions.json，按 `created_at` 倒序返回
  - 关联 TC：**TC-M01-042**

- [ ] 4. 实现 `delete_session(self, session_id: str) → int`：
  - 先调 `delete_records_by_session(session_id)` 获取删除数
  - 再从 sessions.json 移除该会话

  - 关联 TC：**TC-M01-043**

- [ ] 5. 实现 `update_session(self, session_id: str, title: str) → dict`：
  - 查找会话（不存在抛 KeyError）
  - 校验 title ≤ 100 字符

  - 写回 JSON，返回更新后的 dict
  - 关联 TC：**TC-M01-046**

## T-012 路由层 — 会话 API（3 个端点）

**对齐**：`09` §4 POST /sessions · §5 GET /sessions · §6 DELETE /sessions

### 文件：`backend/blueprints/agent_bp.py`

### 步骤

- [ ] 1. `POST /sessions`（201）：
  - 读取可选 `title`（默认 "新会话"）
  - 校验 title ≤ 100 字符 → 失败返回 `INVALID_SESSION_TITLE`
  - 调用 `storage.create_session(uuid, title)`
  - 返回 `{traceId, session_id, title, created_at, query_count}`

- [ ] 2. `GET /sessions`（200）：
  - 调用 `storage.get_sessions()`
  - 返回 `{traceId, sessions: [...]}`

- [ ] 3. `DELETE /sessions/<id>`（200）：
  - 校验会话存在 → 不存在返回 404 `SESSION_NOT_FOUND`
  - 调用 `storage.delete_session(session_id)` 获取 deleted_records
  - 返回 `{traceId, message: "会话已删除", deleted_records}`

### DoD

- [ ] 三个端点返回字段与 `09` 完全一致
- [ ] 错误码对齐 `09` §2 错误码清单

## T-013 前端 — Sidebar 会话管理

**对齐**：`06` §3 Sidebar 会话管理

### 文件：`frontend/src/App.jsx` + `frontend/src/api.js`

### 步骤

- [ ] 1. `api.js` 实现：
  ```js
  export const getSessions = () => fetch('/api/v1/agent/sessions').then(r => r.json())
  export const createSession = (title) => fetch('/api/v1/agent/sessions', { method: 'POST', headers: {'Content-Type':'application/json'}, body: JSON.stringify({title}) }).then(r => r.json())
  ```
