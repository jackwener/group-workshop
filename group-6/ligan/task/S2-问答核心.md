## T-023 Agent 三级降级编排

**对齐**：`08` §4 降级链路 · `07` §1.2

### 文件：`backend/agent.py`

### 步骤

- [ ] 1. 在 `CoPawAgent.__init__` 中初始化三个 Provider：
  ```python
  self.copaw = CoPawBridge()
  self.bailian = BailianQA()
  ```

- [ ] 2. 完善 `ask()` 方法降级链：
  ```python
  def ask(self, query, session_id):
      start = time.time()
      # [1] CoPaw
      result = self.copaw.ask(query, session_id) if self.copaw.configured else None
      # [2] 百炼
      if result is None:
          result = self.bailian.ask(query) if self.bailian.configured else None
      # [3] Demo
      if result is None:
          result = self._demo_answer(query)
      
      result["response_time_ms"] = int((time.time() - start) * 1000)
      # 落库
      self.storage.add_record(session_id, query, **result)
      return result
  ```

- [ ] 3. 降级约束：
  - **不可跳级**：必须按 1→2→3 顺序
  - **静默执行**：不抛异常，通过 `answer_source` 标识

### DoD

- [ ] 三级降级链路正确：CoPaw → 百炼 → Demo
- [ ] 每次调用后 `response_time_ms` 正确计算
- [ ] 记录正确落库到 qa_records.json
