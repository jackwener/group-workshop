## 3. Sidebar 研报管理

> 对齐 `05` US-001。描述研报列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /reports` | 渲染研报列表 |
| 上传研报 | 点击"+ 上传" | `POST /reports` | 弹出文件选择 → 上传进度条 → 解析完成提示 |
| 删除研报 | 点击 × | `DELETE /reports/<id>` | 确认弹窗 → 从列表移除 |
| 选中研报 | 点击研报卡片 | — | 高亮选中 + 展示研报详情 |
| 筛选研报 | 选择筛选条件 | `GET /reports?subject_code=xxx` | 按股票代码/券商/关键词筛选 |
| 添加到对比 | 点击"对比"按钮 | — | 添加到对比列表，最多 10 个 |

## 4. Main 内容区（四态渲染）

> 对齐 `05` US-001（研报解析）、US-002（研报对比）、US-003（股价查询）。描述四种条件下显示什么。

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 空状态** | `reports.length === 0` | "请上传研报开始分析"，显示上传按钮 |
| **B 研报列表** | 未选中研报 | 研报卡片网格，每个卡片显示：标题、股票名称、券商、评级、创建时间 |
| **C 研报详情** | 选中单个研报 | 结构化数据展示：标题、研究对象、券商、评级、方向、目标价、核心观点 |
| **D 研报对比** | 点击"开始对比" | 表格对比视图，列：券商、评级、方向、目标价、核心观点 |

### 4.1 研报详情卡片元素

> 选中研报后展示的详情页面。

| 元素 | 类型 | 说明 |
|------|------|------|
| 标题 | `<h2>` | 研报标题 |
| 研究对象 | `<div>` | 股票名称 + 股票代码（可点击查询股价） |
| 券商 | `<span>` | 研报作者（券商公司） |
| 评级徽章 | `<badge>` | 买入(绿)/增持(蓝)/中性(灰)/减持(橙)/卖出(红) |
| 方向标签 | `<tag>` | 看涨(红)/看跌(绿)/中性(灰) |
| 目标价 | `<div>` | 目标价格（元） |
| 核心观点 | `<p>` | 摘要文本，最多显示 500 字，可展开 |
| 操作按钮 | `<button>` | 添加对比、下载原文、删除 |

### 4.2 解析状态标签逻辑

| `parse_status` | 显示文本 | 样式 |
|----------------|----------|------|
| `success` | 解析成功 | 绿色标签 |
| `partial` | 部分解析 | 橙色标签 |
| `failed` | 解析失败 | 红色标签 |

## 5. 股价查询面板

> 对齐 `05` US-003。描述股价查询的交互。

| 元素 | 类型 | 行为 |
|------|------|------|
| 股票代码输入 | `<input>` | placeholder "输入股票代码"，支持回车查询 |
| 查询按钮 | `<button>` | loading 时 disabled + 文案"查询中..." |
| 股价卡片 | `<div>` | 显示：股票名称、当前价、涨跌幅、开盘价、最高/最低、成交量 |
| 数据来源标签 | `<span>` | 显示数据来源：sina/tencent/mock |

### 5.1 股价数据展示

| 字段 | 格式 | 说明 |
|------|------|------|
| 当前价 | ¥1,856.50 | 保留两位小数，千分位 |
| 涨跌幅 | +1.55% / -0.82% | 涨红跌绿，带正负号 |
| 成交量 | 32,560 手 | 千分位格式 |
| 成交额 | 6.03 亿 | 超过亿显示"亿" |

## 6. 研报对比视图

> 对齐 `05` US-002。描述研报对比的界面。

| 元素 | 类型 | 说明 |
|------|------|------|
| 对比表格 | `<table>` | 行：对比维度；列：各券商研报 |

## 7. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_FILE` | 400 | 错误提示："请选择研报文件" |
| `INVALID_FILE_TYPE` | 400 | 错误提示："仅支持 PDF 格式" |
| `FILE_TOO_LARGE` | 400 | 错误提示："文件大小不能超过 20MB" |
| `PARSE_FAILED` | 500 | 错误提示："研报解析失败，请稍后重试" |
| `REPORT_NOT_FOUND` | 404 | 错误提示："研报不存在" |
| `INVALID_STOCK_CODE` | 400 | 错误提示："请输入正确的股票代码" |
| `STOCK_NOT_FOUND` | 404 | 错误提示："未找到该股票信息" |
| `STOCK_SERVICE_UNAVAILABLE` | 503 | 错误提示："股价服务暂不可用" |
