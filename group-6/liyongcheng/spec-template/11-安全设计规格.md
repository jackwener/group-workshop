## 1. 安全目标与合规要求

> 明确本模块需遵循的安全目标和外部合规标准。投研场景尤其关注数据隐私与内部信息防泄露。

| 安全目标 | 说明 | 对应合规 |
|----------|------|----------|
| 数据不出域 | 所有用户数据、研报内容、问答记录禁止传输至外部服务 | 内部信息安全规范 |
| 最小权限原则 | 每个组件只拥有完成任务所需的最低权限 | 安全设计最佳实践 |
| 研报内容保护 | 研报原文与解析数据仅存储于本地，传输加密 | 金融数据安全规范 |

## 2. 认证与授权

> 定义用户身份验证方式和权限控制模型。写出认证流程和角色划分。

### 2.1 认证机制

| 项目 | 规格 |
|------|------|
| 认证方式 | 教学版：无认证（开放访问）；生产版：内部 SSO 对接 |
| Token 有效期 | 生产版：Access Token 30min, Refresh Token 7d |
| 密码策略 | 生产版：最少 8 位，含大小写+数字，90 天强制更换 |
| 多因素认证 | 生产版：敏感操作需 MFA（如批量导出） |

## 3. 数据安全

> 定义数据分类分级、加密策略、存储安全规范。**投研场景核心关注点**。

### 3.1 数据分类与分级

| 数据类型 | 安全等级 | 示例 | 保护措施 |
|----------|----------|------|----------|
| 研报原文 | **机密** | PDF 研报文件 | 加密存储，访问审计 |
| 研报解析数据 | **机密** | 结构化字段（评级、目标价等） | 本地存储，传输加密 |
| 股价数据 | **内部** | 实时行情数据 | 实时查询，不持久化 |
| 系统配置 | 一般 | 模型参数、界面配置 | 版本控制，环境变量 |
| API 密钥 | **机密** | LLM API Key | 环境变量，禁止硬编码 |

### 3.2 加密策略

| 场景 | 加密方式 | 说明 |
|------|----------|------|
| 传输加密 | TLS 1.2+ | 所有 API 通信强制 HTTPS |
| 存储加密 | AES-256（生产版） | 研报文件与解析数据落盘加密 |
| 密钥管理 | 环境变量 / KMS（生产版） | 密钥不硬编码，定期轮转 |

## 4. 接口安全

> 与 `09` API 规格配合，定义 API 层面的安全防护措施。

| 防护措施 | 实现方式 | 说明 |
|----------|----------|------|
| 输入校验 | 服务端白名单校验 | 所有用户输入进行类型、长度、格式校验 |
| SQL 注入防护 | 不使用 SQL（JSON 存储） | 无 SQL 注入风险 |
| XSS 防护 | 输出转义 + CSP | 研报内容渲染时防止脚本注入 |
| CSRF 防护 | SameSite Cookie + CSRF Token | 状态变更接口需 CSRF Token |
| 速率限制 | 100 req/min/user（生产版） | 防止接口滥用 |
| 文件上传校验 | 类型白名单 + 大小限制 | 仅允许 PDF，限制 20MB |

## 5. LLM / AI 安全

> 针对大模型集成的专项安全措施。投研场景数据敏感，需严格管控数据流向。

| 风险点 | 防护措施 | 验收标准 |
|--------|----------|----------|
| 数据外泄至第三方模型 | 本地部署模型 / 内网百炼服务，禁止调用外网 API | 网络出口审计零外传记录 |
| Prompt 注入攻击 | 系统 Prompt 隔离，用户输入预处理过滤 | 无成功注入案例 |
| 模型幻觉 / 错误信息 | 回答标注来源引用，标识置信度 | 用户可识别 AI 生成内容 |
| 敏感信息泄露（模型回复） | 输出过滤层，正则匹配敏感信息并脱敏 | 敏感词过滤命中率 100% |

## 6. 审计与日志

> 定义安全审计日志的记录范围、保留策略。

| 事件类型 | 记录内容 | 保留期限 | 告警 |
|----------|----------|----------|------|
| 登录 / 登出 | 用户ID、时间、IP、结果 | 180 天 | 连续失败 ≥5 次告警 |
| 研报访问 | 用户ID、文档ID、操作类型 | 365 天 | 异常批量下载告警 |
| 研报上传 | 用户ID、文件名、大小、解析结果 | 365 天 | 解析失败告警 |
| 数据导出 | 导出内容摘要、目标 | 365 天 | 每次导出需审批 |
| 系统配置变更 | 变更人、变更前后值 | 永久 | 关键配置变更即时通知 |

## 7. 安全威胁清单（STRIDE 简表）

> 基于 STRIDE 模型，列出主要安全威胁与应对方案。

| 类型 | 威胁 | 风险等级 | 应对措施 | 负责人 |
|------|------|----------|----------|--------|
| S | 伪造用户身份访问研报 | **高** | 强认证 + Token 校验（生产版） | 后端团队 |
| T | 研报内容在传输中被篡改 | 中 | TLS + 文件哈希校验 | 运维团队 |
| I | 内部数据通过 AI 模型泄露 | **高** | 本地部署 + 输出过滤 | AI 团队 |
| D | 大量请求导致服务不可用 | 中 | 速率限制 + 降级策略 | 后端团队 |
| E | 攻击者提升权限访问敏感功能 | **高** | RBAC 权限控制 + 操作审计 | 后端团队 |
| R | 研报作者否认操作行为 | 低 | 完整操作日志 + 数字签名 | 运维团队 |

## 8. 部署安全

> 定义部署架构中的安全要求。

- [x] 生产/开发环境**严格隔离**，数据不互通
- [x] 数据库访问仅限应用服务器 IP 白名单
- [x] 敏感配置（API Key、密码）通过环境变量注入，不入代码仓库
- [x] 依赖包定期安全扫描（`pip audit` / `npm audit`）
- [x] 文件上传目录独立权限控制，禁止执行权限
- [x] 定期备份研报数据与解析结果，异地存储
