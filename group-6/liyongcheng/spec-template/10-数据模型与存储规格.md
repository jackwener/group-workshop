## 1. 概念模型

```
Report（研报）
   │
   │  id (PK)
   │  title                      ┌─────────────────┐
   │  subject_name               │  StockPrice     │
   │  subject_code               │  （实时查询，    │
   │  author                     │   不持久化）     │
   │  rating                     └─────────────────┘
   │  trend
   │  target_price
   │  summary
   │  file_path
   │  created_at
   │  parse_status
   └
```

> **核心关系**：研报（Report）是核心实体，股票价格（StockPrice）为实时查询数据不持久化。研报对比基于同一 `subject_code` 进行关联。

## 2. 存储引擎

| 项 | 说明 |
|----|------|
| 引擎 | JSON 文件（`json` 标准库） |
| 编码 | UTF-8，缩进 2 空格 |
| 读写模式 | RMW（全量读入 → 修改 → 全量写回） |
| 并发安全 | 无锁，不支持并发写入 |
| 文件布局 | `{DATA_DIR}/reports.json` |

## 3. 实体定义 — Report（研报）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `id` | `string` (UUID) | 是 | **PK** | 研报唯一标识，格式：`rpt_{uuid}` |
| `title` | `string` | 是 | ≤200 字符 | 研报标题 |
| `subject_name` | `string` | 是 | ≤50 字符 | 研究对象主体名称（上市公司） |
| `subject_code` | `string` | 是 | 6 位数字 | 研究对象股票代码（如：600519） |
| `author` | `string` | 是 | ≤50 字符 | 研报作者（券商公司） |
| `rating` | `string` | 是 | 枚举 | 评级：买入/增持/中性/减持/卖出 |
| `trend` | `string` | 是 | 枚举 | 看涨看跌方向：bullish/bearish/neutral |
| `target_price` | `number\|null` | 否 | ≥ 0 | 目标价（元），可为空 |
| `summary` | `string` | 是 | ≤2000 字符 | 核心观点摘要 |
| `file_path` | `string` | 是 | 有效路径 | 原始研报文件存储路径 |
| `created_at` | `string` (ISO-8601) | 是 | UTC+Z | 创建时间 |
| `updated_at` | `string` (ISO-8601) | 是 | UTC+Z | 最后更新时间 |
| `parse_status` | `string` | 是 | 枚举 | 解析状态：success/partial/failed |

## 4. 实体定义 — StockPrice（股价，非持久化）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `code` | `string` | 是 | 6 位数字 | 股票代码 |
| `name` | `string` | 是 | — | 股票名称 |
| `price` | `number` | 是 | ≥ 0 | 当前价格（元） |
| `change` | `number` | 是 | 可为负 | 涨跌幅（元） |
| `change_percent` | `number` | 是 | 可为负 | 涨跌幅（%） |
| `open` | `number` | 是 | ≥ 0 | 开盘价 |
| `high` | `number` | 是 | ≥ 0 | 最高价 |
| `low` | `number` | 是 | ≥ 0 | 最低价 |
| `volume` | `number` | 是 | ≥ 0 | 成交量（手） |
| `amount` | `number` | 是 | ≥ 0 | 成交额（万元） |
| `timestamp` | `string` (ISO-8601) | 是 | UTC+Z | 数据时间 |
| `source` | `string` | 是 | 枚举 | 数据来源：sina/tencent/mock |

## 6. 关键业务逻辑

**示例 — 解析状态判定**：

```python
def determine_parse_status(extracted_fields: dict) -> str:
    required = ['title', 'subject_name', 'subject_code', 'author']
    optional = ['rating', 'trend', 'target_price', 'summary']
    
    if all(extracted_fields.get(f) for f in required):
        if all(extracted_fields.get(f) for f in optional):
            return 'success'
        return 'partial'
    return 'failed'
```

| 逻辑 | 触发条件 | 行为 |
|------|----------|------|
| 解析状态判定 | 研报解析完成 | 必填字段完整 → success，部分缺失 → partial，必填缺失 → failed |
| 自动 ID 生成 | 创建研报 | 生成格式 `rpt_{uuid}` |
| 文件路径存储 | 上传研报 | 保存至 `{DATA_DIR}/files/{report_id}.pdf` |
