## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| **研报解析延迟** | < **30000ms** | `parse_time_ms` 字段 | `04` R-01 |
| **研报对比延迟** | < **5000ms** | 服务端计时 | 内存计算 |
| **股价查询延迟** | < **60000ms** | `response_time_ms` 字段 | `03` 4 |
| 研报列表延迟 | < 500ms | 服务端计时 | JSON I/O < 50ms |
| 研报详情延迟 | < 200ms | 服务端计时 | JSON I/O < 10ms |

### 1.2 降级策略

**三级降级链 — 研报解析**：

```
ReportParser.parse(file)
  ├─[1] CoPaw 桥接 → source='copaw',  llm=true
  ├─[2] 百炼 DashScope → source='bailian',llm=true
  └─[3] 离线演示兜底 → source='demo',   llm=false
```

**三级降级链 — 股价查询**：

```
StockService.get_price(code)
  ├─[1] 新浪财经 → source='sina'
  ├─[2] 腾讯财经 → source='tencent'
  └─[3] 模拟数据 → source='mock'
```

| 约束 | 说明 |
|------|------|
| 三级降级**不可跳级** | 必须按顺序尝试 |
| 降级**静默执行** | 不抛异常，通过 `source` 字段标识 |
| Demo/Mock 模式**始终可用** | 无外部依赖，保证基础功能 |

## 2. 可用性需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | **99%**（教学环境） | 单实例 Flask，不设 HA |
| MTTR | < 5 分钟 | 重启 Flask 进程即可恢复 |
| 研报解析成功率 | ≥ 95% | 包含降级后的成功率 |
| 股价查询成功率 | ≥ 99% | 多数据源保障 |

### 2.1 故障模式与恢复方式

| 故障模式 | 影响 | 恢复方式 | 恢复时间 |
|----------|------|----------|----------|
| LLM 服务不可用 | 研报解析降级 | 自动降级至 Demo 模式 | 0s（自动） |
| 单一股价接口失效 | 股价查询降级 | 自动切换备用接口 | 10s 内 |
| 所有股价接口失效 | 股价查询失败 | 返回模拟数据 | 0s（自动） |
| JSON 文件损坏 | 数据丢失 | 从备份恢复 | 5 分钟 |
| Flask 进程崩溃 | 服务不可用 | 重启进程 | < 1 分钟 |

## 3. 可观测性需求

### 3.1 链路追踪

| 项 | 规格 |
|----|------|
| traceId 格式 | `tr_{uuid.hex}`（32 位十六进制） |
| 注入位置 | 所有成功响应顶层 + 错误响应 `error.traceId` |
| 上游透传 | 优先复用请求头 `X-Trace-Id`，缺省时本地生成 |

### 3.2 错误码体系

| HTTP | `error.code` | 触发条件 |
|------|--------------|----------|
| 400 | `EMPTY_FILE` | 上传文件为空/null |
| 400 | `INVALID_FILE_TYPE` | 文件类型非 PDF |
| 400 | `FILE_TOO_LARGE` | 文件大小超过 20MB |
| 400 | `INVALID_STOCK_CODE` | 股票代码格式错误 |
| 404 | `REPORT_NOT_FOUND` | 研报 ID 不存在 |
| 404 | `STOCK_NOT_FOUND` | 股票代码不存在 |
| 500 | `PARSE_FAILED` | 研报解析内部异常 |
| 503 | `STOCK_SERVICE_UNAVAILABLE` | 股价服务全部不可用 |

## 4. 安全需求

| 项 | 当前实现 | 说明 |
|----|----------|------|
| API 认证 | 无（开放访问） | Workshop 教学版 |
| CORS | 全开放 | 生产需白名单 |
| 速率限制 | 无 | 教学场景不限速 |
| 文件上传校验 | 类型+大小限制 | 仅允许 PDF，≤20MB |

### 4.1 敏感数据保护

| 数据类型 | 保护方式 |
|----------|----------|
| LLM API Key | 环境变量存储（`.env`），禁止硬编码 |
| 研报内容 | 本地 JSON 存储，不传输到第三方（LLM 除外） |
| 股价查询记录 | 不持久化，仅实时查询 |
| 用户操作日志 | 本地存储，定期清理 |

## 5. 数据约束

### 5.1 输入约束

| 约束 | 规格 | 来源 |
|------|------|------|
| 研报文件格式 | PDF | `04` R-01 |
| 研报文件大小 | ≤ 20MB | `04` R-01 |
| 股票代码格式 | 6 位数字 | `09` API 规格 |
| 研报标题长度 | ≤ 200 字符 | `10` 数据模型 |
| 核心观点摘要长度 | ≤ 2000 字符 | `10` 数据模型 |
| 对比研报数量 | 2-10 个 | `09` API 规格 |

### 5.2 类型约束

| 字段 | 类型 | 约束 |
|------|------|------|
| `parse_status` | `string` | 枚举：success \| partial \| failed |
| `rating` | `string` | 枚举：买入 \| 增持 \| 中性 \| 减持 \| 卖出 |
| `trend` | `string` | 枚举：bullish \| bearish \| neutral |
| `target_price` | `number\|null` | ≥ 0 或 null |
| `price` | `number` | ≥ 0，保留两位小数 |
